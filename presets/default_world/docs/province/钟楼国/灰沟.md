# 灰沟

## 一、区域概览
- 区域名称：灰沟
- 所属王国：钟楼国
- 位置范围：自台心放射的七条深沟，最长十二里。
- 地形类型：被灰水冲出的沟壑。
- 海拔与地势：沟深一到三丈，年年加深。
- 气候特征：沟里闷，灰面浮着一层壳。
- 主要地貌：沟桥、灰瀑、半埋的旧城基。
- 水源分布：雨季过灰水，其余时候干。
- 与周边子区域的过渡：沟间是台地，沟尾散入落灰带。
- 交通难度：只能走桥，桥面一落灰就滑。

## 二、生态

### 子区域：灰沟
- 植被类型：沟壁的灰苔。
- 主要植物：灰苔、沟边硬草。
- 主要动物：灰鼠、沟鸦。
- 魔物分布：沟底灰蟒，吞过整支朝圣队。
- 生态链：灰苔—灰虫—沟鸦；灰蟒居顶。
- 季节变化：雨季成灰水，旱季见半埋的旧城基。
- 资源产出：旧城砖、埋掉的旧器、沟底细灰。
- 生态威胁：沟蟒、塌灰、桥断。
- 与人文的关系：刮灰工沿沟作业，挖出旧王朝的东西要上交，私下卖的也不少。
