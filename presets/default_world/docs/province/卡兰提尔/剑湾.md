# 剑湾

## 一、概览
- 名称：剑湾
- 所属：卡兰提尔
- 位置范围：王国西南的一片海湾与外海诸岛，风骸岛就在这一带。
- 地形类型：内海凹湾 → 外海礁岛；岸上是渔港与矿场，岛上是荒滩与坑地。
- 气候特征：常年有雾，潮线附近全是礁石；冬天海风能吹断桅杆。
- 主要地貌：岸线曲折，多半看不见对岸；离岸三里就有暗礁。
- 水源分布：淡水源都在岸上，岛上只有风骸岛后山那一处。
- 交通难度：靠船。海路比陆路快，也比陆路死人。

## 二、跨省难度
- 跨越难度：3（岛与岛之间要看天，过海峡要半天）

## 三、要注意的
- 剑湾的商船登记在卡兰提尔名下，走私最多。
- 风骸岛在剑湾最外一道，岛上没有官府，只有一个青铜龙修道院。
