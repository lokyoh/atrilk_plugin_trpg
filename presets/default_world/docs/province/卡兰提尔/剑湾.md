# 剑湾

## 一、区域概览
- 区域名称：剑湾
- 所属王国：卡兰提尔
- 位置范围：王国西南的整条海湾带，从外海三道礁岛到剑山脉北麓，东西四日路程。
- 地形类型：内海凹湾 → 外海礁岛；往内陆转起伏丘陵、稀疏林地与石灰岩露头。
- 海拔与地势：潮线到丘陵顶一百二十丈；海岸断崖与砂石滩相间，内陆坡缓，到剑山脉脚下陡然立起。
- 气候特征：常年有雾，秋冬更重；夏天海风带咸气，冬天海风能吹断桅杆。内陆比海边暖，但入夜起雾。
- 主要地貌：曲折岸线、暗礁脊、断崖、滩涂、连绵丘陵、干河床、山前碎石坡。
- 水源分布：淡水源都在岸上，溪流入湾，冬涨夏枯；岛上只有风骸岛后山那一处；内陆靠井，古枭井一带的井还出干净水。
- 与周边子区域的过渡：向东越断炉隘口接焦渣坡；向北出海三日抵泊银湾的湾口；向南翻剑山脉入无人处。
- 交通难度：海路比陆路快，也比陆路死人；陆上从一个去处到下一个要走一整天，丘陵里常有断路。
- 跨越难度：3（岛与岛之间要看天，过海峡要半天；内陆的丘陵路一天走不到下一个去处）

## 二、生态

### 子区域：外海礁岛
- 植被类型：岩缝里的硬草，没有乔木，树都长不到一人高。
- 主要植物：海石竹、盐草、礁苔。
- 主要动物：鸥、海燕、灰海豹、礁缝里的蟹。
- 魔物分布：沉船上盘旋的鸟妖、礁缝里的蕈人、岛上扎营的狗头人。
- 生态链：礁苔—蟹—鸥；海豹吃鱼，鸟妖吃落单的人。
- 季节变化：秋冬雾重，海豹上岸产仔；春夏礁上鸟巢密到不能落脚。
- 资源产出：鱼、海豹油、沉船里的铁与铜。
- 生态威胁：涨潮断路、暗礁、雾里辨不出方向。
- 与人文的关系：岛上的人按潮汐过日子，退潮才走礁；沉船是人人盯着的横财。

### 子区域：内湾岸线
- 植被类型：滩涂芦苇、岸边的柳与赤杨。
- 主要植物：芦苇、盐角草、柳。
- 主要动物：滩蟹、涉禽、内湾的鲱鱼群。
- 魔物分布：滩泥里偶有食腐的泥怪；夜里岸上不太平。
- 生态链：芦苇—蟹—涉禽；鲱鱼群引来海豹，也引来渔船。
- 季节变化：春天鱼汛，秋天蟹肥；冬天滩涂上冻，浅湾进不了船。
- 资源产出：鲱鱼、盐、芦苇（编筐与铺顶）、滩泥里翻出来的旧木料。
- 生态威胁：涨潮快，滩上的人跑不过水；雾天船会撞堤。
- 与人文的关系：渔户按鱼汛定休渔，谁在鱼汛里下网，明年就得饿一季。

### 子区域：内陆丘陵与林地
- 植被类型：丘陵草坡、稀疏的橡与松，往山脚转成密林。
- 主要植物：橡、松、石楠、山脚的蕨。
- 主要动物：鹿、野猪、狼、丘陵上空的鹰。
- 魔物分布：地精与兽人在小径蹲点；废墟里是枯枝怪与不死的东西；林深处有绿龙的传闻。
- 生态链：草—鹿—狼；野猪翻土，橡子喂猪也喂鹿。
- 季节变化：秋天橡子落，野猪下山拱地；冬天路边能捡到冻死的牲口。
- 资源产出：木材、木炭、铁矿（三十里外的旧坑）、鹿皮。
- 生态威胁：白天夜里各判一次遭遇；雾里不认路，走岔了就进别人的猎场。
- 与人文的关系：矿镇靠柴与炭活着，砍到林子边缘就有人拦。

## 三、地点

### 地点：凡达林（据点）
- 一句话：剑湾深处的一个小镇，矿工兑换所、旅店与镇长大厅围着一块告示板。

### 地点：崔森德庄园（地下城）
- 一句话：镇东的废弃庄园，地窖通到红标帮的地牢，玻璃手杖在那儿坐着。

### 地点：红标帮窝点（地下城）
- 一句话：崔森德庄园下的地牢复合体，玻璃手杖坐在最里面那间。

### 地点：三猪小径（野外地点）
- 一句话：从东边旅路穿过废弃村庄、伸向剑山脉的丘陵小径，路上不太平。

### 地点：克拉摩窝点（地下城）
- 一句话：碎颅部落的藏身处，熊地精克拉格称王，靠劫掠过路商队过活。

### 地点：无冬森林（野外地点）
- 一句话：丘陵北缘的密林，碎颅部落的王座在里头，还有一个德鲁伊结社盯着。

### 地点：克拉摩堡（地下城）
- 一句话：无冬森林深处的碎颅部落王座，七座塔楼只剩底层还立着。

### 地点：雷树废墟（地下城）
- 一句话：三十年前被天灾摧毁的伐木村，枯枝怪与丧尸占了废墟，绿龙在塔上。

### 地点：报丧妖的庇护所（地下城）
- 一句话：科尼伯里废墟镇外数英里的巢穴，报丧妖阿加莎只肯回答一个问题。

### 地点：古枭井（地下城）
- 一句话：早已消失的帝国留下的瞭望塔残基，庭院里还有一口能出干净饮水的古井。

### 地点：飞龙突岩（地下城）
- 一句话：三猪小径东端的一处岩地，兽人斥候蹲在这里劫旅人。

### 地点：剑山脉（野外地点）
- 一句话：南边的石头墙，旧矿、兽人营地与龙的传闻都在山脚一线。

### 地点：回声洞（地下城）
- 一句话：五百年前被兽人毁掉的富饶矿井，法术锻造炉可能还在矿底。

### 地点：旅路（野外地点）
- 一句话：沿山脚南北走的大车道，商队结伴才走，独行的活不到下一站。

### 地点：风骸岛（野外地点）
- 一句话：剑湾外海的近海小岛，岛上有龙的古战场遗迹。

## 四、要注意的
- 剑湾的商船登记在卡兰提尔名下，走私最多。
- 风骸岛在剑湾最外一道，岛上没有官府，只有一个青铜龙修道院。
- 内陆的凡达林一带没有领主：镇长是每年选出来的，矿工兑换所兼着不官方的记录处，矿坑在三十里外没人管。
- 丘陵小径上不太平：白天夜里各判一次遭遇，能看见路边躺着的东西就别绕路。
- 断炉隘口往东通炉心；出海三日可抵泊银湾的湾口。
