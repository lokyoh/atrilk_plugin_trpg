# 石台地

## 一、区域概览
- 区域名称：石台地
- 所属王国：灰岩原
- 位置范围：台原主体，东西四十里、南北三十里。
- 地形类型：石灰岩台地。
- 海拔与地势：高出盐道走廊百丈，顶面近乎水平。
- 气候特征：风硬，昼夜温差大。
- 主要地貌：石芽、采石阶、石栅。
- 水源分布：七口深井，凿到四十步才见水。
- 与周边子区域的过渡：东缘碎成台阶落入盐道走廊，北接天坑群。
- 交通难度：石面平，车可行，唯无水处难宿。

## 二、生态

### 子区域：石台地
- 植被类型：石生苔与稀草。
- 主要植物：石苔、岩艾、刺草。
- 主要动物：石鼠、岩鸽。
- 魔物分布：石背蜥，伏在石缝里晒太阳。
- 生态链：石苔—石鼠—岩鸽。
- 季节变化：冬落灰，石面滑；夏晒，正午无人上工。
- 资源产出：石料、石粉、井水。
- 生态威胁：井枯、塌方、石崩。
- 与人文的关系：采石人以「一斗盐换一车石」记账，认契约不认人。
