# 芦苇荡

## 一、区域概览
- 区域名称：芦苇荡
- 所属王国：盐沼渡
- 位置范围：三角洲外缘，环一圈约十五里。
- 地形类型：咸水芦苇荡。
- 海拔与地势：与潮位齐平，涨潮即没。
- 气候特征：闷湿，蚊虫成团。
- 主要地貌：苇墙、泥滩、鸟巢。
- 水源分布：全境都是水，淡水靠接雨。
- 与周边子区域的过渡：向内渐深为潮沟，向外出海口散为沙洲。
- 交通难度：只通平底船，认得水路才敢走。

## 二、生态

### 子区域：芦苇荡
- 植被类型：芦苇与咸水草。
- 主要植物：芦苇、咸草、水蓼。
- 主要动物：水鸟、滩蟹、水蛇。
- 魔物分布：沼泽蛰蛇，藏在苇根，咬了不疼只麻。
- 生态链：咸草—滩蟹—水鸟；苇根—水蛇。
- 季节变化：涨潮四成陆地消失，退潮见泥路。
- 资源产出：芦苇、鱼、蟹、盐霜。
- 生态威胁：涨潮迷路、蛰蛇、疟气。
- 与人文的关系：芦苇能编席能盖顶，也是藏船最好的地方。
