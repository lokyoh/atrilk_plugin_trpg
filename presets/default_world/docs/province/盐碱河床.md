# 盐碱河床

## 一、区域概览
- 区域名称：盐碱河床
- 所属王国：灰岩原
- 位置范围：台原东南，一条干涸的旧河道。
- 地形类型：干涸盐碱河床。
- 海拔与地势：低于台面二十丈，宽阔平坦。
- 气候特征：盐霜泛白，风一起白茫茫。
- 主要地貌：龟裂泥壳、盐壳、旧桥墩。
- 水源分布：雨季过水，其余时候只余咸洼。
- 与周边子区域的过渡：东南缓降，接盐道走廊入白港。
- 交通难度：最好走，也是盐车唯一的路。

## 二、生态

### 子区域：盐碱河床
- 植被类型：盐生草与碱蓬。
- 主要植物：碱蓬、盐蒿、白刺。
- 主要动物：盐鸦、滩蟹。
- 魔物分布：盐壳下的钻沙虫，踩破壳才现身。
- 生态链：碱蓬—滩蟹—盐鸦。
- 季节变化：雨季过水，其余时候泛白。
- 资源产出：碱、盐霜、硝。
- 生态威胁：钻沙虫、盐雾伤眼。
- 与人文的关系：河床是路也是盐，穷户刮碱卖，够买半斗盐。
