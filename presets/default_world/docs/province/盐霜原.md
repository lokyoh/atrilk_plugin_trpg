# 盐霜原

## 一、区域概览
- 区域名称：盐霜原
- 所属王国：霜牙岭
- 位置范围：山脊北侧，一片覆霜的开阔地。
- 地形类型：盐渍冻原。
- 海拔与地势：平，风把雪吹走只剩霜。
- 气候特征：极干，风如刀。
- 主要地貌：盐霜壳、刮盐沟、旧界石。
- 水源分布：盐泉三眼，是部盟的命。
- 与周边子区域的过渡：南接冰裂谷，北出岭外。
- 交通难度：地面滑，驮队要裹蹄。

## 二、生态

### 子区域：盐霜原
- 植被类型：盐霜草与矮苔。
- 主要植物：盐霜草、雪苔。
- 主要动物：霜羊、雪隼、霜鼠。
- 魔物分布：霜狼群，冬南下，饿时才扑人。
- 生态链：雪苔—霜鼠—雪隼；霜羊—霜狼。
- 季节变化：夏可牧，冬只刮霜。
- 资源产出：粗盐、盐霜、皮、毛。
- 生态威胁：霜狼、白毛风、盐泉枯。
- 与人文的关系：牲畜与盐霜就是全部家当，杀一人赔九头羊。
