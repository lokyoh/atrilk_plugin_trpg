# 熔岩沟

## 一、区域概览
- 区域名称：熔岩沟
- 所属王国：炉心
- 位置范围：裂谷南段底部，长四里。
- 地形类型：半凝固熔岩沟。
- 海拔与地势：全境最低处，沟底龟裂。
- 气候特征：热雾贴地，夜可见红光。
- 主要地貌：凝壳、气喷口、铁壳桥。
- 水源分布：无，雨水即沸。
- 与周边子区域的过渡：北接废炉群，南转窄出黑水渠。
- 交通难度：只走铁壳桥，桥面烫脚。

## 二、生态

### 子区域：熔岩沟
- 植被类型：耐硫苔藓。
- 主要植物：硫苔、铁线草。
- 主要动物：灰鼠、硫蝇、渣蜥。
- 魔物分布：熔渣蜥，昼伏夜出，护喷口。
- 生态链：硫苔—灰鼠—渣蜥。
- 季节变化：冬日落灰，沟面结壳可走人。
- 资源产出：铁、煤、硫、凝壳。
- 生态威胁：沟底喷气，久留伤肺。
- 与人文的关系：沟底班是学徒最苦的一班，疤最深的人从那儿出来。
