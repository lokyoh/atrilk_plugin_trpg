# 废炉群

## 一、区域概览
- 区域名称：废炉群
- 所属王国：炉心
- 位置范围：裂谷中段两岸，延七里。
- 地形类型：废弃炉体与渣堆。
- 海拔与地势：谷底至坡顶三十丈，坡面松散。
- 气候特征：终年热，硫气刺鼻。
- 主要地貌：炉壳、渣山、凝铁沟。
- 水源分布：硫泉两眼，不可饮。
- 与周边子区域的过渡：向南渐窄入熔岩沟，向北抬升为焦渣岭。
- 交通难度：渣路可行车，雨后成泥浆。

## 二、生态

### 子区域：废炉群
- 植被类型：几乎无，只炉缝里有灰藓。
- 主要植物：灰藓、锈草。
- 主要动物：炉鼠、铁喙鸦。
- 魔物分布：锈甲虫群，啃铁也啃人。
- 生态链：锈草—锈甲虫—铁喙鸦。
- 季节变化：雨季渣坡塌，炉体移位。
- 资源产出：废铁、炉渣、铜件。
- 生态威胁：塌方、硫气聚洼。
- 与人文的关系：孩子靠捡废铁换票，捡到铜件就算发财。
