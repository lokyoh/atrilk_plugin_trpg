# 西盐田

## 一、区域概览
- 区域名称：西盐田
- 所属王国：白港
- 位置范围：城西至黑水渠口，九里。
- 地形类型：人工盐田。
- 海拔与地势：低平，潮涨半没。
- 气候特征：日晒强，风大。
- 主要地貌：盐池、卤水沟。
- 水源分布：渠水混海水，卤度不稳。
- 与周边子区域的过渡：北接石堤，南连芦苇荡。
- 交通难度：堤路通车，池间单人。

## 二、生态

### 子区域：西盐田
- 植被类型：盐生草本。
- 主要植物：盐蒿、碱蓬。
- 主要动物：盐鸦、滩涂蟹。
- 魔物分布：卤水沟白蛭，不主动伤人。
- 生态链：盐蒿—蟹—盐鸦。
- 季节变化：盐飓后盐池必修。
- 资源产出：粗盐、卤水、芦苇。
- 生态威胁：卤水渗井，水变咸。
- 与人文的关系：盐工按池计酬，坏池要赔。
