# 落灰带

## 一、区域概览
- 区域名称：落灰带
- 所属王国：灰烬台
- 位置范围：台地外缘一圈，宽五到十里不等。
- 地形类型：常年落灰的无人区。
- 海拔与地势：缓缓向外降，灰没到膝盖。
- 气候特征：无风也落灰，滤布一时辰即堵。
- 主要地貌：灰丘、埋掉的旧路、露出的屋脊。
- 水源分布：无，露水也带灰。
- 与周边子区域的过渡：向外渐薄，接白港盐田与盐沼渡泥岸。
- 交通难度：走一日要换三次滤布，无滤布三日咳血。

## 二、生态

### 子区域：落灰带
- 植被类型：几乎无，只有灰下枯根。
- 主要植物：灰藓、耐灰的硬草。
- 主要动物：灰蛾、灰鼠、灰下的虫。
- 魔物分布：灰行者（埋在灰下的旧城居民），风起时立起来。
- 生态链：灰藓—灰虫—灰蛾；灰鼠吃虫，灰行者吃活物。
- 季节变化：秋冬落得最厚，春夏稍薄。
- 资源产出：圣灰（教团专用）、旧城遗物。
- 生态威胁：灰肺、迷路、灰行者。
- 与人文的关系：走一日换三次滤布；教团说灰是神罚，灰工说灰是活计。
