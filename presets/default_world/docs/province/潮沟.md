# 潮沟

## 一、区域概览
- 区域名称：潮沟
- 所属王国：盐沼渡
- 位置范围：三条主水道，交汇于三岔桩。
- 地形类型：潮汐通道。
- 海拔与地势：深一丈到三丈，随潮涨落。
- 气候特征：一日两涨落，落时见泥。
- 主要地貌：分水口、暗桩、沉船。
- 水源分布：咸淡交汇，盐度一日三变。
- 与周边子区域的过渡：上溯通盐霜河，下流出海，西接泥渡栈道。
- 交通难度：涨潮行船，落潮走泥，错一时辰就得等半天。

## 二、生态

### 子区域：潮沟
- 植被类型：水下藻与浮萍。
- 主要植物：绿藻、浮萍、咸水苔。
- 主要动物：鲻鱼、白虾、水獭。
- 魔物分布：沟底白蛭，落水即附。
- 生态链：藻—白虾—鲻鱼—水獭。
- 季节变化：冬水咸，鱼往上游；夏水暖，白蛭最凶。
- 资源产出：鱼虾、盐卤、冲上来的沉货。
- 生态威胁：白蛭、暗桩、潮水卷人。
- 与人文的关系：船帮按潮记时，「潮退三分」就是开门的口令。
