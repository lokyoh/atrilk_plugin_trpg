# 冻土台地

## 一、区域概览
- 区域名称：冻土台地
- 所属王国：霜牙岭
- 位置范围：山脊西侧的缓坡带，南北延二十里。
- 地形类型：冻土台地。
- 海拔与地势：高二百丈，夏融表层一尺，下永冻。
- 气候特征：常年风，夏短冬长。
- 主要地貌：草甸、冻胀丘、牧道。
- 水源分布：融雪溪十余条，冬封。
- 与周边子区域的过渡：向西缓降入冰裂谷，向北碎成乱石。
- 交通难度：牧道可骑，融雪期陷蹄。

## 二、生态

### 子区域：冻土台地
- 植被类型：短草甸。
- 主要植物：针茅、冻草、矮桦。
- 主要动物：牧马、霜羊、牧犬。
- 魔物分布：地穴熊，掘冻土而居。
- 生态链：针茅—霜羊—地穴熊。
- 季节变化：七月到九月才长草，其余时候啃干茬。
- 资源产出：牧草、马、羊。
- 生态威胁：连年灰霜，草一年比一年薄。
- 与人文的关系：草场就是命，两季无草即南下。
