# 泊银湾

## 一、地区概览
- 地区名称：泊银湾
- 大致形状：内海凹湾，城沿湾口堆成半月。
- 主要地形：深水湾、石堤、滩涂。
- 国都：泊银湾城，上城货栈、下城码头。
- 特殊地区：票号，唯一印发铁票处。
- 当前政治局势：会长商承弼专权二十年，教团禁售令使东市铁价翻倍。
- 在世界推力中的位置：铁票印钞口，四国都要看它脸色。
## 六、与周边地区的衔接
### 炉心
- 边界地形过渡：渠下游转窄，滩涂变焦渣坡。
- 生态变化：铁生植物绝迹，生耐硫苔。
- 交通线与关隘：三闸，第三闸归工坊。
- 人文与政治互动：工坊以铁换票，铁行会压价便卡闸。
### 霜牙
- 边界地形过渡：白喉隘以北抬升为冻土。
- 生态变化：芦苇让位霜草。
- 交通线与关隘：隘口设卡，收过霜钱。
- 人文与政治互动：铁行会扶两部压其余五部。
### 石冢原
- 边界地形过渡：走廊向西北升，淤泥转石屑。
- 生态变化：草木转稀，多石生苔。
- 交通线与关隘：无险，三处水源站。
- 人文与政治互动：石工欠铁债，铁行会借此压石价。
### 钟楼国
- 边界地形过渡：关门两侧覆灰，越东越厚。
- 生态变化：滩涂生物消失，只剩灰蛾。
- 交通线与关隘：铁行会与教团各派十人共守。
- 人文与政治互动：教团索灰税，双方互扣货物。

## 七、区域划分

### 区域：湾口深水区
- 大致位置：湾心至外海，宽两里。
- 地形底色：天然深水湾。
