# 石冢原

## 一、地区概览
- 地区名称：石冢原
- 大致形状：西北一片被风削平的灰白台原，方正得像块案板，边缘碎成一级一级的台阶。
- 主要地形：石灰岩台地、天坑群、干涸的灰河床，地表水极少，凿井要凿到四十步深。
- 国都：磨盘镇。围着万人磨盘建的采石镇，没有城墙，只有三道石栅和七口水井。
- 特殊地区：「七十二眼」天坑群。坑底有冷泉与旧王朝库房的残迹，绳索不够长的人下不去。
- 当前政治局势：七个采石行会轮流坐庄；炉心低价收石，泊银湾高价卖铁，两头欠账，行会攥着三张未兑铁票。
- 在世界推力中的位置：石与粮道的出处，也是全境最认契约的地方。铁价一动，原上最先受不住。
## 六、与周边地区的衔接
### 炉心
- 边界地形过渡：南缘焦渣岭一路抬升，灰白台原转为矿渣陡坡。
- 生态变化：石生苔绝迹，耐硫苔与锈草上来。
- 交通线与关隘：运石索道，日夜运石；石价由行会定，铁价由工坊定。
- 人文与政治互动：工坊低价收石，行会攥着三张未兑铁票，谁先兑谁吃亏。
### 泊银湾
- 边界地形过渡：东南沿灰河床缓降，台原落为滩涂。
- 生态变化：石鼠岩鸽不见，铁鸦与滩蟹上来，水多了。
- 交通线与关隘：石廊，无险，三处水源站。
- 人文与政治互动：泊银湾高价卖铁，石工欠铁债，铁行会借此压石价；走廊一断，原上先断粮。

## 七、区域划分

### 区域：石台地
- 大致位置：台原主体，东西四十里、南北三十里。
- 地形底色：石灰岩台地。

### 区域：天坑群
- 大致位置：台原北缘，方圆八里。
- 地形底色：塌陷漏斗群。
- 主要据点：七十二眼
