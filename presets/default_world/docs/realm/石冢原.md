# 石冢原

## 一、政体
- 地区类型：有政体
- 国名或通称：石冢原，文书里写「石冢原七行会」，原上人只说自己「原上的」
- 政体：行会共治，七个采石行会轮庄
- 统治者：磨主，七行会轮值，一任一年，在任者的名字不入判词
- 权力来源：契约与铁票，其次是水井
- 继承或更替方式：抽签定序，一年一换；三张未兑铁票未清之前，谁都不接庄
- 都城：磨盘镇
- 一句话性格：先立字据，再论亲疏

## 二、法度
- 通行法：一斗铁换一车石，立票为凭；嫁女陪一口井，井权随契走；断案在磨盘上，判词刻磨沿，刻了就算数
- 禁令：不得私兑三张未兑铁票；不得填井；不得在天坑私系长绳下坑采旧料
- 刑罚风格：欠账先夺井，再夺石场份额，最后逐出原上；杀人者系上绳放下天坑，绳收回，人留下
- 谁在执行：行会护院押人，磨盘公堂的判事断案，两者不是一批人
- 灰色地带：铁票在市面上折价转手，谁都装作没看见；夜里有人拿短绳下七十二眼，捞上来的东西没有一张契能对上

## 三、军力
- 常备兵力：无常备军，七行会护院合计约四百人，磨盘镇常驻不满一百
- 兵种与装备特点：石工改的短矛与撬棍，皮围上落满石屑；守井守栅尚可，列阵即散
- 要塞与关隘：三道石栅围磨盘镇，栅口窄得只容一辆石车；焦渣岭索道上站，管着南去炉心的石流；石廊站，东南走廊三处水源站之一
- 动员能力：敲磨聚众，一日可拉两千石工；三日之外自带的口粮吃完，人自己往回走
- 实际战力短板：无骑、无甲、无水；走廊一断先断粮，井一填先乱，打不了出境的一仗

## 四、外交
### 炉心
- 关系：通商，账上互为债主
- 争的是什么：石价与铁价的差，索道运价，以及三张未兑铁票由谁先兑
- 明面上的说法：石铁互市，两不相欠
- 私下在做什么：炉主李砧欠铁行会三万张票，却派人折价收原上的票；行会则把成色最好的石先赊给别处，让索道上站空转

### 泊银湾
- 关系：通商，兼债主
- 争的是什么：铁债折石价的算法，石廊三处水源站的过路钱，走廊维护由谁出
- 明面上的说法：走廊共护，水站共用
- 私下在做什么：会长商承弼在位二十年，铁债按年放，专挑换庄那年催；行会反手囤石不运，等铁价落到底再开口

## 五、要地
### 万人磨盘
- 类型：圣所
- 为什么重要：旧王朝碾铁的大磨，如今是原上唯一认账的地方，判词刻在磨沿上
- 谁在守：轮值行会的护院二十人，不带刃，只带账本
- 一句话现状：磨沿已经刻满，新判词开始往下层的石座刻

### 磨盘镇
- 类型：国都
- 为什么重要：七行会、三张未兑铁票、七口水井都在这里，原上所有契都在这儿落款
- 谁在守：三道石栅，栅口各十人；七口井各由一户世守，井户不归任何行会
- 一句话现状：没有城墙，来的人比走的多，井权官司已排到明年

### 石廊站
- 类型：关隘
- 为什么重要：东南往泊银湾的走廊无险，三处水源站就是这条路上全部的险
- 谁在守：泊银湾出五人、行会出五人，共守一井，水价按票结
- 一句话现状：断水一天，原上的粮车就掉头退回磨盘镇

### 七十二眼
- 类型：矿坑
- 为什么重要：坑底有冷泉，也有旧王朝库房的残迹，是原上唯一不必凿四十步就见水的地方
- 谁在守：无人长守，坑口系绳的几处石桩归天坑群的老绳户看
- 一句话现状：绳索不够长的人下不去，绳索够长的，也未必上得来

## 六、区域划分
### 区域：石台地
- 大致位置：都城脚下向东西铺开，东西四十里、南北三十里，磨盘镇居中
- 地形底色：石灰岩台地，被风削平，边缘碎成一级一级的台阶
- 主要据点：万人磨盘、磨盘镇、石廊站
- 这地方出的麻烦：井权与石场份额的官司压着换庄，七行会谁都不肯先兑票

### 区域：天坑群
- 大致位置：台原北缘，距磨盘镇约二十里，方圆八里
- 地形底色：塌陷漏斗群，坑底积水成冷泉
- 主要据点：七十二眼
- 这地方出的麻烦：私系短绳下坑的人越来越多，捞上来的旧库房器物没有一张契能对上
