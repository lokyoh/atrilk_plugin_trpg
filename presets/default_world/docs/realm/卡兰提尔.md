# 卡兰提尔

## 一、地区概览
- 地区名称：卡兰提尔
- 大致形状：西南一条贴着海的窄带——岸线曲折，往外是三道礁岛，往里是丘陵与林地，一直铺到剑山脉脚下；陆上没有纵深，走一天就到山。
- 主要地形：内海凹湾、外海礁岛、砂石岸与滩涂；内陆起伏丘陵、稀疏林地，山脚转成密林与碎石坡。
- 国都：无。国王住岸上的老宅；城镇全在岸上，靠船串起来，船期就是政令能走多远。
- 特殊地区：风骸岛——外海最后一道，龙战留下的火山岛，岛上百官不管；凡达林一带——内陆丘陵的矿镇，没有领主，镇长一年一选。
- 当前政治局势：商船尽登记在国王名下，走私比正经货多；剑湾诸岛名义纳贡，实际各行其是；内陆的矿坑与地精窝点谁也管不着。铁行会的票在这条湾里不好使——海商认船、认货单，不认纸。
- 在世界推力中的位置：全境唯一的海门。铁要出海、人要上岸，都得从这条湾里过；湾一封，泊银湾的票号就成了死账。

## 六、与周边地区的衔接
### 炉心
- 边界地形过渡：东越断炉隘口，丘陵渐高，林子转薄，露出焦渣坡。
- 生态变化：鸥与滩蟹绝迹，铁喙鸦与耐硫苔上来；水里的鱼少了，井水开始带味。
- 交通线与关隘：断炉隘口，一年里四个月雪封；赶时间的货宁可走海运，多绕三日。
- 人文与政治互动：剑湾的矿镇把矿石东运换铁，炉心只收铁片不收票；两边在隘口各摆一个过秤的人，秤上差一成是常事。

### 泊银湾
- 边界地形过渡：出湾口三日海路；湾外多雾，过湾心就得看天。
- 生态变化：近岸的礁鱼让位深水鱼群；雾里看不见岸，海鸟也不跟船。
- 交通线与关隘：湾口主航道，须引水员，夜航禁行。
- 人文与政治互动：铁行的票在剑湾不好使，两边的账要在湾心换一次手；海商宁可收三成现银，也不肯收一张兑不到的票。

## 七、区域划分

### 区域：剑湾
- 大致位置：王国西南整条海湾带，从外海礁岛到剑山脉北麓，东西四日路程。
- 地形底色：内海凹湾到外海礁岛，岸上是渔港与矿场；内陆是起伏丘陵与稀疏林地。
- 主要据点：巨龙之憩修道院（风骸岛）、凡达林镇（内陆丘陵）
- 这地方出的麻烦：矿镇没有领主，红标帮收保护费；丘陵小径上地精与兽人蹲点，货出了镇就不再是镇上的事。
