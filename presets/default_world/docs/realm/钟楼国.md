# 钟楼国

## 一、政体
- 地区类型：有政体
- 国名或通称：钟楼国
- 政体：教权，教团执令，守灰军执械，两下互不统属
- 统治者：大祭司 竺无咎
- 权力来源：神授，具体是他握着解释落灰的那一套话
- 继承或更替方式：由灰钟堂三位老祭司共推，钟声定则人定；推不出人，守灰军统领摄政，直到选出下一个
- 都城：灰台城，环天罚柱而建，屋顶全做斜面，街上每十步一口刮灰的槽
- 一句话性格：先问这灰是谁降的，再谈价钱

## 二、法度
- 通行法：灰是神罚，不得扫尽，只许刮入街槽归公；铁为赎罪之物，持铁须在教团挂号；晨昏钟响，行者停步低头
- 禁令：私铸铁器；私改灰税账；在落灰带留宿过一昼夜；口中直说「铁」字，须称赎罪之物
- 刑罚风格：罚灰。按罪令其刮灰若干日，重者缚在天罚柱下听钟三日，再重者逐入落灰带——不杀，等灰
- 谁在执行：教会执法队，人称灰手；关隘与街面由守灰军代行
- 灰色地带：赎罪铁可以买，斤两由灰手估，估多估少不入账；灰手的估法就是此地真正的法

## 三、军力
- 常备兵力：守灰军约两千四百，半数轮驻关隘，半数在灰台城刮灰兼操练
- 兵种与装备特点：重步为主，铁甲外罩灰布，甲缝塞麻絮挡灰；兵器全出炉心工坊，一断供，旧械回炉也回不出好铁
- 要塞与关隘：灰烬关，南门教团守、北门铁行会十人共守；断炉隘口，与炉心各派一人共守；灰门，落灰带外缘，出灰台地必经
- 动员能力：钟响三遍可聚台心丁壮三千，够守城，出境即散
- 实际战力短板：军械一断，守灰军先散；兵不识野地，出了灰壳地就迷向

## 四、外交
### 炉心
- 关系：通商，兼依附之实
- 争的是什么：军械的价与交期，炉主要订单，教团要货先到
- 明面上的说法：赎罪之物出于炉火，是神许过的
- 私下在做什么：以灰税折铁压价；四位炉主互不通婚，却轮流单独接教团的密使

### 霜牙
- 关系：停战，旧约已裂
- 争的是什么：灰往北落多少，部盟怕灰落进牧场，教团说那是神在挑拣
- 明面上的说法：灰风谷风大日短，一次只过一队，为的是两下清净
- 私下在做什么：萨满收灰样带回山里看；教团在谷口记每一队的来去，人多的那队记两笔

### 泊银湾
- 关系：通商，实为互扣
- 争的是什么：灰税的名分，铁行会斥赎罪铁是赎罪券，教团斥铁票是伪币
- 明面上的说法：朝圣季过关免三日税，是待客之礼
- 私下在做什么：互设禁售又互扣货物；灰烬关的账记两本，一本给钟，一本给票号

## 五、要地
### 灰台城
- 类型：国都
- 为什么重要：环天罚柱而建，教团、守灰军与圣殿地窖的账房都挤在这一圈里
- 谁在守：守灰军本部千二百人，另有灰手三十
- 一句话现状：屋顶全是斜面，灰滑到街心，每十步一口槽，刮灰的人比赶路的多

### 天罚柱
- 类型：圣所
- 为什么重要：插在台心的黑曜石柱，落灰在柱下堆成一环；教团说那是神的一根手指，灰税的轻重就按这环的厚薄定
- 谁在守：灰手十二人轮值，不许近柱三步
- 一句话现状：环一年厚过一年，教团说是神在加罚，别处说是柱子在往下沉

### 灰烬关
- 类型：关隘
- 为什么重要：南面通泊银湾的唯一口子，灰税在此收，朝圣季这条路最挤
- 谁在守：教团守南门，铁行会派十人共守北门
- 一句话现状：两把锁两道账，谁也开不了整扇门

## 六、区域划分
### 区域：台心
- 大致位置：高台正中，方圆二里，都城全在此
- 地形底色：被踩实的灰壳地
- 主要据点：灰台城、钟楼国圣灰广场
- 这地方出的麻烦：窖里的账与柱下的环对不上，三位老祭司各说各的

### 区域：灰沟
- 大致位置：自台心放射的七条深沟，最长十二里，一日可走来回
- 地形底色：被灰水冲出的沟壑
- 主要据点：无
- 这地方出的麻烦：沟底积灰成泥，刮灰队下去，常有人不上来

### 区域：落灰带
- 大致位置：台地外缘一圈，宽五到十里不等，绕都城一整圈
- 地形底色：常年落灰的无人区
- 主要据点：灰门
- 这地方出的麻烦：没人久住，走一日要换三次滤布，逐出的人只在此等灰
