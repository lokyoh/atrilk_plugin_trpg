# 霜牙

## 一、政体
- 地区类型：有政体
- 国名或通称：霜牙（七部合称霜牙部盟，外人也只叫霜牙）
- 政体：部族联盟
- 统治者：盟主呼延赤
- 权力来源：血统，须在双峰之间会誓才算数
- 继承或更替方式：盟主死后七部会誓，畜群与战士多者立誓；呼延赤年老，两个义子各拉三四部，位子至今没定
- 都城：无城，冬营骨帐随冰泉迁移，今冬扎在双峰下
- 一句话性格：先饮一碗霜水再开口，开口就按九头羊算账

## 二、法度
- 通行法：杀一人赔九头羊；偷牲畜断指或赔双倍；外人入盟先饮一碗霜水，饮了才算能说话的
- 禁令：禁在霜原私刮粗铁；禁越白喉隘不交过霜钱；禁把灰烬教团的灰带进牧场
- 刑罚风格：当众办，在双峰之间办，赔不起就抵人抵畜
- 谁在执行：盟主帐下亲兵与各部长者，会誓由萨满主持
- 灰色地带：过霜钱由守关人自收自分，盟主不过问；铁票能替羊顶账，也能替人顶罪

## 三、军力
- 常备兵力：盟主帐下三百骑，七部只有这一支常年吃粮
- 兵种与装备特点：轻骑、牧弓、短弯刀，皮甲覆霜；粗铁先打刀不打甲，无攻城器械
- 要塞与关隘：断齿关，白喉隘上唯一的关，关墙半塌靠木栅与冰墙补；霜牙哨站，南沿的耳目
- 动员能力：七部全征约三千骑，须会誓才能动；一年只聚得一次，聚久了牲畜先死
- 实际战力短板：铁不够，箭簇拿皮货去换；盟约一年比一年松，两个义子的部众不肯替对方死

## 四、外交

### 泊银湾
- 关系：通商
- 争的是什么：过霜钱，还有过冬的铁；泊银湾要北门，霜牙要铁
- 明面上的说法：白喉隘是两家共守的关口，铁行会年年赊铁给部盟
- 私下在做什么：铁行会用铁票常年扶两部压其余五部，买通其中一支；盟主帐下也有人在收票

### 钟楼国
- 关系：停战
- 争的是什么：灰风谷一线的牧道，以及灰落不落进牧场
- 明面上的说法：萨满与教团有旧约，谷口两边都不设兵
- 私下在做什么：教团差人越谷撒灰量地；部盟牧民把「铁」与「灰」都咽下去不提

## 五、要地

### 骨帐
- 类型：营地
- 为什么重要：部盟唯一的「都城」，盟主在哪儿，七部的会就在哪儿开
- 谁在守：盟主帐下三百骑轮班宿卫
- 一句话现状：今冬扎在双峰下，冰泉一移就得拔帐

### 断齿关
- 类型：关隘
- 为什么重要：白喉隘上唯一能收钱的地方，过霜钱都从这里出
- 谁在守：部盟派一部轮守，隘南木寨是泊银湾的人
- 一句话现状：关墙半塌，钱照收，守关人与木寨分账

### 誓骨窟
- 类型：圣所
- 为什么重要：部盟会誓与赔命的老地方，盟主的位子在这里才作数
- 谁在守：萨满与各部长者，不设兵
- 一句话现状：窟里的旧骨堆到膝盖，今年的誓还没立

### 霜原
- 类型：矿坑
- 为什么重要：部盟唯一的自采粗铁，刮一层少一层
- 谁在守：七部轮流看，看得比牧场还紧
- 一句话现状：为它打过三次，如今划了界，界石年年被挪

## 六、区域划分

### 区域：冻土台地
- 大致位置：都城骨帐以西，山脊西侧缓坡带，南北延二十里
- 地形底色：冻土台地
- 主要据点：霜牙哨站
- 这地方出的麻烦：七部牧道在这里交叠，越界放牧一年要告三次状

### 区域：冰裂谷
- 大致位置：双峰之间，深三里，都城就在其间
- 地形底色：冰川切割的裂谷
- 主要据点：断齿关、骨帐
- 这地方出的麻烦：谷底冰泉改道，帐随水走；采石场与誓骨窟抢同一段谷壁
