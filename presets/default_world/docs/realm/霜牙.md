# 霜牙

## 一、地区概览
- 地区名称：霜牙
- 大致形状：东北一列锯齿状山脊，从南到北拉着，像兽口咬着天，越往北越碎。
- 主要地形：冻土台地、冰裂谷、覆霜的牧道。
- 国都：无城，只有随冰泉迁移的冬营「骨帐」，今冬扎在双峰下。
- 特殊地区：霜原。覆霜的冻原，部盟唯一的自采粗铁，刮一层少一层。
- 当前政治局势：七部结盟，盟主呼延赤年老，两个义子各拉三四部；泊银湾常年用铁票买通其中一支，盟约一年比一年松。
- 在世界推力中的位置：皮货、肉干与战马的出处，也是泊银湾的北门。盟约一散，最先断的是冬储。
## 六、与周边地区的衔接
### 泊银湾
- 边界地形过渡：白喉隘一线切开山脊，隘北冻土，隘南滩涂。
- 生态变化：霜狼退到岭北，铁鸦与滩蟹上来。
- 交通线与关隘：白喉隘（部盟称断齿关），关墙半塌，隘南另有泊银湾木寨。
- 人文与政治互动：过隘收过霜钱，铁行会常年扶两部压其余五部；部盟要的从来不只是过路，还有过冬的铁。
### 钟楼国
- 边界地形过渡：西南沿灰风谷下行，冻土上开始覆灰。
- 生态变化：草甸转灰藓，牧道覆一层浮灰。
- 交通线与关隘：灰风谷，风大日短，一次只过一队。
- 人文与政治互动：萨满与教团的旧约已裂，牧民忌提「铁」字，也忌提灰。

## 七、区域划分

### 区域：冻土台地
- 大致位置：山脊西侧的缓坡带，南北延二十里。
- 地形底色：冻土台地。

### 区域：冰裂谷
- 大致位置：双峰之间，深三里。
- 地形底色：冰川切割的裂谷。
