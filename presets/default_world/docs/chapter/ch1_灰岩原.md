# 磨盘的节拍

骨架：调查
目标：弄清天坑底下为什么按磨盘的节拍敲，以及磨盘底下压着什么
缘由：镇上连着三夜听见北边天坑传来敲击，节拍和白天磨盘转的一模一样
去处：磨盘镇、七十二眼
人物：掌磨人老砚
完成条件：
- 问出铁楔是谁让嵌的
- 下到主坑底，用节拍与第九眼下面对上话
- 掀开粮仓，看清里面存的不是粮
没做完：老砚让人把第九眼灌了灰，井底再没声音，下一章只剩镇上流传的鬼话
难度：1（本章预算 4800 XP）
