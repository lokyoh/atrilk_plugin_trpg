# 第七层的火

骨架：调查
目标：查清千炉塔第七层为什么熄火，而工坊的账上记着它一直在烧
缘由：工坊的账房托人带话，说有人用第七层的炉号私炼，请他别声张地看一眼
去处：千炉塔、灰肺坑
人物：独眼戚
完成条件：
- 拿到「停火簿」或它被撕掉的三页
- 在灰肺坑找到带着七层炉号的铁片
- 让独眼戚承认炉号被改过
没做完：独眼戚连夜把坑口的渣推平，账房被调去守料场，下一章只能从灰肺坑底往上查
难度：1（本章预算 4800 XP）
