# 退潮的两个时辰

骨架：潜入
目标：趁退潮摸清沉盐塘里那批「全损」的盐，以及谁在替谁起货
缘由：栈道口一夜之间换了新板，渡夫说「这几天夜里别走水路」
去处：泥渡栈道口、沉盐塘
人物：渡夫阿灰
完成条件：
- 掀开新板，确认沉箱里是封蜡盐包
- 读到屋脊浮标上的木牌刻字
- 从水下取货人嘴里问出货主是谁
没做完：取货人弃货走人，屋里灌满水，下一章只能从渡口的账簿反推
难度：1（本章预算 4800 XP）
