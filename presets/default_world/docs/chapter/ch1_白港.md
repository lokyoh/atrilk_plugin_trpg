# 第二套账

骨架：调查
目标：拿到渡口那套不示人的账簿，弄清谁在用「不问货」换船钱
缘由：码头账房清点时发现，渡口报上来的泊位钱比往年少了一成，而水路照旧忙
去处：渡鸦渡口、旧盐井
人物：老鸦陈
完成条件：
- 从渡头棚隔板下取出第二套账簿
- 弄清免掉船钱的那张条子是谁签的
- 下到旧盐井底层，确认通海的窄道
没做完：渡口当夜换锁，第二套账被沉进水底，下一章只能从盐仓的私盐倒推货源
难度：1（本章预算 4800 XP）
