# 被关上的门

骨架：解读
目标：弄清灰门为什么关了三天、以及圣殿地窖里那股暖风从哪来
缘由：送灰的车队堵在门外三日，教团只说「神怒，暂闭」
去处：灰门、圣殿地窖
人物：守灯的老执事
完成条件：
- 从门吏老韩口中问出关门的令是谁下的
- 拓下地窖北壁被刮掉的旧壁画
- 确认暖风的来源不是神迹
没做完：教团封了圣殿并把地窖入口砌死，下一章只剩「神怒」这一个说法
难度：1（本章预算 4800 XP）
