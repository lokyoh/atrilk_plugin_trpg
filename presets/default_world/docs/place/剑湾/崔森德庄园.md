# 崔森德庄园

## 一、概览
- 名称：崔森德庄园
- 种类：dungeon（地下城）
- 所属：卡兰提尔 · 剑湾
- 一句话：镇东的废弃庄园，地窖通到红标帮的地牢，玻璃手杖在那儿坐着。
- 位置：凡达林镇东，走一刻钟；坡上，正门对着主街的尽头
- 类型：地面废墟加一处地窖口（往下才是地牢）
- 简介：庄园地上部分早塌了，墙基还在；红标帮把地窖往下凿通，接上了庄园底下的旧地牢
- 结构：塌掉的地上一层 → 地窖一间 → 尽头一道暗门通红标帮窝点
- 魔物分布：地面上没有人；地窖里有红标帮的哨，往下的一切见「红标帮窝点」
- 陷阱与机关：那道暗门；玻璃手杖的老鼠魔宠守着它
- 宝藏与资源：地面上没有值钱的；值钱的都在下面
- 势力介入：红标帮独占
- 危险等级：低（地面）；往下为高

## 二、往下
- 地面这一层没有可探索的房间：塌了，只剩墙基、几堵残墙和一个地窖口。
- 地窖尽头的暗门下去，就是红标帮窝点的十二个房间。

## 三、要注意的
- 玻璃手杖养着一只老鼠魔宠守着暗门——它一旦看见入侵者，会立刻传念给他。
