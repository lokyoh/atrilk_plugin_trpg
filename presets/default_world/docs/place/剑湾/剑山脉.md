# 剑山脉

## 一、概览
- 名称：剑山脉
- 种类：place（野外地点）
- 所属：卡兰提尔 · 剑湾
- 一句话：南边的石头墙，旧矿、兽人营地与龙的传闻都在山脚一线。
- 位置：剑湾南缘，从飞龙突岩往南；山脊东西拉着，把剑湾和无人处隔开
- 地形：石灰岩与碎页岩，山脚是碎石坡，山腰以上只剩岩缝里的松
- 规模：南北三十里；翻过去要三天，只有两条走得的兽径
- 气候：山上比山下冷一个季，雾到中午才散；冬天垭口雪封
- 通行：没有路，顺着干河床往上；驮畜上不去
- 水源：山泉多，都在南坡；北坡的沟里是苦水
- 栖居：兽人营地扎在东北的丘陵，旧矿在西坡，早塌了
- 危险：兽人斥候、山里的狼与鹰；落石，雾里走一步错一步
- 资源：铁与铜（旧矿留下的）、石料、山羊毛
- 谁的：没人。山脚以下的矿有人认，山上的事没人认
