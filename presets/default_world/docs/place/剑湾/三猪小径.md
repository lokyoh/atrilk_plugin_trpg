# 三猪小径

## 一、概览
- 名称：三猪小径
- 种类：place（野外地点）
- 所属：卡兰提尔 · 剑湾
- 一句话：从东边旅路穿过废弃村庄、伸向剑山脉的丘陵小径，路上不太平。
- 位置：从凡达林出镇向东折，接上旅路；往南是剑山脉，往北是无冬森林
- 走向与长度：东西三十来里，沿丘陵腰线走，一路过三个废村
- 路面：车辙早被草吃掉，多数地方只容两人并行；雨后是齐踝的泥
- 沿途：塌掉的石桥、路边的浅坟、旧营火的灰；废村里还有能挡风的屋架
- 通行：走一趟一天；车过不去，驮畜能过
- 季节：冬天雪压断枝，得看树上的记号；春天溪涨，有两处要涉水
- 危险：白天夜里各判一次遭遇；地精与兽人在弯道后面蹲点
- 谁在走：矿镇的货、兽人的斥候、红标帮的信使
- 资源：沿路的柴、废村里的旧木料、被丢下的货

## 三、要注意的
- 白天夜里各判一次遭遇：掷 d20，出 17-20 就有东西从暗处走出来。
- 往东是旅路，往南进剑山脉，往北进无冬森林。
