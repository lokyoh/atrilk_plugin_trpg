# 凡达林

## 一、概览
- 名称：凡达林
- 种类：city（据点）
- 所属：卡兰提尔 · 剑湾
- 一句话：剑湾深处的一个小镇，矿工兑换所、旅店与镇长大厅围着一块告示板。
- 据点类型：矿镇，无领主；镇长一年一选，矿工兑换所兼着不官方的记录处
- 地理位置：剑湾内陆丘陵，三猪小径东段的尽头；离海岸一天，离剑山脉山脚半天
- 面积：一条主街加一圈屋，走一圈两刻钟；镇界就是那圈屋外的一步
- 人口：四百来口；矿工、伐木烧炭的、贩子各占一份，矿坑开了又停，人跟着来去
- 势力归属：名义上归卡兰提尔，实际谁都不管；镇东的崔森德庄园下面住着红标帮
- 势力结构：镇长 + 矿工兑换所（记账兑货）+ 石丘旅馆（消息都在这儿换）+ 红标帮（收保护费）
- 经济基础：铁矿、木炭、鹿皮；兑换所按票换货，票出了镇就不好使
- 军事力量：没有兵，只有十来个巡夜人拿棍与弩；真出事靠告示板雇人
- 与周边的关系：矿坑在三十里外没人管；山脚有兽人，林子里有地精；货要运到旅路才有商队收
- 特殊之处：告示板就是全镇的官报——谁往上贴一张纸，第二天全镇都知道了

## 三、要注意的
- 镇长哈宾·威斯特在告示板上贴了「奖励——飞龙突岩附近的兽人」。
- 狮盾小贩莱妮·灰风的商队被峭壁地精劫了，货还没回来。
- 红标帮的据点在镇东的崔森德庄园**下面**——庄园本身是地面上的废弃建筑。
