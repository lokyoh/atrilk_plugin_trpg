# 克拉摩堡

## 一、概览
- 名称：克拉摩堡
- 种类：dungeon（地下城）
- 所属：卡兰提尔 · 剑湾
- 一句话：无冬森林深处的碎颅部落王座，七座塔楼只剩底层还立着。
- 位置：无冬森林深处，从三猪小径往北一天半；林子密到看不见天
- 类型：城堡废墟（现存底层与几段墙）
- 简介：碎颅部落的总窝，君王格罗尔坐在倒数第二间；前朝的样子只剩石头
- 结构：十四处：入口、陷阱大厅、两处箭垛岗哨、数间营房、宴会厅、黑暗大厅、地精圣坛、后门、塔楼废墟、枭熊塔楼、王之居所
- 魔物分布：地精二十余、大地精六名、君王格罗尔与他的狼、关着的枭熊、黑暗大厅里的穴居攫怪、变形怪维耶里斯
- 陷阱与机关：入口箭垛的交叉火力、陷阱大厅、后门的哨；警营房会有人跑去报信
- 宝藏与资源：格罗尔的战利品与部落的贡物；储藏室里那桶矮人白兰地，地精嫌它小，没动
- 势力介入：碎颅部落；黑蜘蛛与格罗尔有来往
- 危险等级：高（3–4 级）
