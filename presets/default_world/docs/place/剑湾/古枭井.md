# 古枭井

## 一、概览
- 名称：古枭井
- 种类：dungeon（地下城）
- 所属：卡兰提尔 · 剑湾
- 一句话：早已消失的帝国留下的瞭望塔残基，庭院里还有一口能出干净饮水的古井。
- 位置：三猪小径南侧半日，旧瞭望塔的残基；井在庭院中间
- 类型：塔基废墟加一口井，不是洞窟
- 简介：塔塌了半截，墙基还在；井壁是帝国的手艺，井水到现在还是清的
- 结构：一处场地：塌塔、庭院、井；塔下有一间半埋的地下室
- 魔物分布：十二个丧尸藏在塔的废墟里，外面看不见，闻得到
- 陷阱与机关：没有机关；气味就是唯一的警告
- 宝藏与资源：干净的水——在这一带比钱值钱
- 势力介入：一个自称哈蒙·科斯特的法师在庭院里扎了营
- 危险等级：中（3 级）

## 三、要注意的
- 哈蒙·科斯特愿意交易：他想要飞龙突岩的兽人清干净，还想知道建塔法师的名字。
