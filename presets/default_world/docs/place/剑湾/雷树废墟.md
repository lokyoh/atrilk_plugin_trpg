# 雷树废墟

## 一、概览
- 名称：雷树废墟
- 种类：dungeon（地下城）
- 所属：卡兰提尔 · 剑湾
- 一句话：三十年前被天灾摧毁的伐木村，枯枝怪与丧尸占了废墟，绿龙在塔上。
- 位置：三猪小径以北，往无冬森林方向的旧伐木村；村东就是旅路
- 类型：废弃村庄（地面废墟，不是洞窟）
- 简介：一场天灾把村子埋了一半，树又长回来；如今枯枝怪混在灌木里，龙占了塔
- 结构：十三处：西边两间小屋、棕马酒馆、德鲁伊哨点、枯萎的农舍、商店废墟、龙之塔、旧铁匠铺、草药店、城镇广场、旧卫戍营、织布工小屋、邪教徒的屋子
- 魔物分布：枯枝怪成片（十六只）、灰烬丧尸九只、两只巨蜘蛛、青年绿龙毒牙、六名龙之邪教徒
- 陷阱与机关：没有机关；危险全在埋伏——枯枝怪贴地长着，蜘蛛贴在屋子的内墙上
- 宝藏与资源：龙之塔里旧木箱的法师遗物；邪教徒的行装与黑面具
- 势力介入：龙之邪教徒想拉拢毒牙；德鲁伊雷多斯守在外围
- 危险等级：高（3 级；绿龙不能硬拼）
