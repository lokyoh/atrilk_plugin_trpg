# 无冬森林

## 一、概览
- 名称：无冬森林
- 种类：place（野外地点）
- 所属：卡兰提尔 · 剑湾
- 一句话：丘陵北缘的密林，碎颅部落的王座在里头，还有一个德鲁伊结社盯着。
- 位置：剑湾内陆丘陵的北缘，从凡达林往北一天
- 地形：密林与起伏的林地，林间空地散着旧石圈与塌掉的猎屋
- 规模：东西三十里，南北更宽；穿林两天，绕林走旅路要三天
- 气候：林里比林外冷，日头一过就起雾；落叶季地上盖一层叶子，看不出路
- 通行：没有官道，只有猎径与兽径；带斧带绳，别指望车
- 水源：溪流密，水干净；下游的潭子常是地精取水的地方
- 栖居：碎颅部落的王座在林子深处；猎人、烧炭人只在外缘活动
- 危险：地精与熊地精的巡逻、绿龙的传闻；砍过的树有人记着
- 资源：橡木与木炭、鹿与野猪、林下的药草
- 谁的：名义上归卡兰提尔。实际归林子和盯着它的人——一个德鲁伊结社在赶地精，也赶砍树人
