# 旅路

## 一、概览
- 名称：旅路
- 种类：place（野外地点）
- 所属：卡兰提尔 · 剑湾
- 一句话：沿山脚南北走的大车道，商队结伴才走，独行的活不到下一站。
- 位置：沿剑湾东缘南北走，从湾口一路通到断炉隘口
- 走向与长度：南北百来里，一天走两站；压实的碎石路面，宽处能并两车
- 沿途：三处水源站、两处收钱的卡子、若干废弃的营盘
- 通行：车能走，商队结伴才走；单人走要交钱，不交就自己绕
- 季节：春天翻浆，秋天最好走；冬天隘口一封，只到最后一站
- 危险：劫道的——地精、兽人，也说不清来路的武装人；路边隔几里就有浅坟
- 谁在走：商队、运矿的车、传信的、往东去炉心换铁的人
- 资源：没有资源，只有流言；消息比货走得快
- 谁的：名义上归卡兰提尔。卡子上收钱的人自己说是国王的人
