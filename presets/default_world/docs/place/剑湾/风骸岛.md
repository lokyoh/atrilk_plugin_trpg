# 风骸岛

## 一、概览
- 名称：风骸岛
- 种类：place（野外地点）
- 所属：卡兰提尔 · 剑湾
- 一句话：剑湾外海的近海小岛，岛上有龙的古战场遗迹。
- 位置：剑湾最外一道，出湾口半日船程；岛北是撞船成礁的浅滩
- 地形：龙战留下的火山岛，南崖立陡，北坡是碎石与礁盘，岛心塌了半截
- 规模：绕岛步行半天；岛上没有路，只有几条走惯的兽径
- 气候：海上常年有雾，风从西北来；秋冬的浪能打过南崖顶
- 通行：只有南崖一处能靠船；退潮时礁上能走，涨潮就断
- 水源：后山一处淡泉，其余是雨水积的坑
- 栖居：修道院里住着狗头人与一位青铜龙老者；东南崖顶是蓝龙雏龙的巢；洞里是蕈人
- 危险：暗礁、雾、鸟妖；涨潮断路，雾里辨不出方向
- 资源：沉船里的铁与铜、海豹油；岛上没有矿
- 谁的：没有官府。修道院说了算，出了修道院就只看谁的爪子硬

## 二·巨龙之憩修道院（place）
- 一句话：风骸岛上唯一的落脚点：青铜龙茹娜拉建的修道院，住户大多是狗头人。
- 房间顺序：
  1. 登山路与修道院前厅
  2. 打水房
  3. 厨房
  4. 图书馆
  5. 巴哈姆特神殿
- 邻接：
  登山路与修道院前厅：打水房
  打水房：登山路与修道院前厅、厨房
  厨房：打水房、图书馆
  图书馆：厨房、巴哈姆特神殿
  巴哈姆特神殿：图书馆
