# 克拉摩窝点

## 一、概览
- 名称：克拉摩窝点
- 种类：dungeon（地下城）
- 所属：卡兰提尔 · 剑湾
- 一句话：碎颅部落的藏身处，熊地精克拉格称王，靠劫掠过路商队过活。
- 位置：三猪小径中段北侧的溪谷里，洞口藏在灌木后；溪东有一处暗哨
- 类型：类地精窝点（洞窟群，一路单线）
- 简介：碎颅部落的一个分支，八个洞室；克拉格把劫来的货都堆在自己那间
- 结构：洞口 → 地精暗哨 → 犬舍 → 天桥 → 陡峭的通道 → 双子池 → 地精休息室 → 克拉格的洞穴
- 魔物分布：地精十余（二把手耶米克带六只）、三只狼、熊地精克拉格与他的狼「撕裂者」；洞里还扣着一个人质
- 陷阱与机关：水坝（拉开后水顺主通道冲回来）、天桥上的岗哨、溪东的暗哨
- 宝藏与资源：上月劫下的商队货全在克拉格的洞穴里
- 势力介入：碎颅部落的一支；与红标帮有地精信使往来
- 危险等级：中（1–2 级队伍的主线第一场）

## 二、房间顺序
1. 洞口
2. 地精暗哨
3. 犬舍
4. 陡峭的通道
5. 天桥
6. 地精休息室
7. 双子池
8. 克拉格的洞穴

## 三、要注意的
- 洪水在克拉摩窝点里是有机制的一部分：拉开水坝，水会顺着主通道冲回来。
