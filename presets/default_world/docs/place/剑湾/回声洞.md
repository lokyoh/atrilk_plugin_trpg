# 回声洞

## 一、概览
- 名称：回声洞
- 种类：dungeon（地下城）
- 所属：卡兰提尔 · 剑湾
- 一句话：五百年前被兽人毁掉的富饶矿井，法术锻造炉可能还在矿底。
- 位置：剑山脉北麓的山脚，从凡达林往东南一日；旧入口早被塌方埋了
- 类型：矿井废墟（二十处，上下三层）
- 简介：凡德尔矮人与侏儒开的矿，五百年前被兽人攻破；死的人还在原来的位置
- 结构：新入口 → 矿道 → 旧入口与警卫室 → 南北营房 → 大洞窟与黑水池 → 冶炼洞窟 → 明亮的洞窟 → 法师居所 → 法术工厂 → 古老河床 → 崩塌的洞窟 → 杜马松神庙 → 祭司居所
- 魔物分布：蚊蝠十只、骷髅九具、食尸鬼十余、赭果冻、燃焰之颅、缚灵墨梅斯克、观察者眼魔；下层是熊地精八只、变形怪、卓尔涅兹纳尔与他的巨蜘蛛
- 陷阱与机关：塌方、十尺深的黑水池、崩掉的河床（可以绕开不死生物）、神庙的门
- 宝藏与资源：法术锻造炉、矿里遗留的矮人器物、黑水池底那具法师的遗骨与戒指
- 势力介入：黑蜘蛛的人占了矿底；矮人南卓被扣在祭司居所
- 危险等级：极高（4–5 级）
