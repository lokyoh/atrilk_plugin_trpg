# 红标帮窝点

## 一、概览
- 名称：红标帮窝点
- 种类：dungeon（地下城）
- 所属：卡兰提尔 · 剑湾
- 一句话：崔森德庄园下的地牢复合体，玻璃手杖坐在最里面那间。
- 位置：凡达林镇东，崔森德庄园的地窖之下
- 类型：地下复合体（旧地牢改建，底下一道天然的裂隙）
- 简介：十二个房间，两条入口；一半是旧庄园的地牢，一半是红标帮自己凿的
- 结构：地窖与营房在上，陷阱走廊、墓室、奴隶围栏、军械库、工作间绕着裂隙排一圈，玻璃手杖在最后一间
- 魔物分布：红标帮恶霸十来名（四名常在公共休息室喝酒）、三具骷髅、裂隙里的诺斯怪、玻璃手杖（法师伊阿诺）
- 陷阱与机关：陷阱走廊、要念「伊勒芬」才不动的墓室骷髅、暖房暗门与老鼠魔宠
- 宝藏与资源：恶霸腰带上的小包、军械库、法师工作坊的卷轴
- 势力介入：红标帮独占；玻璃手杖在替黑蜘蛛办事
- 危险等级：高（2–3 级）

## 二、房间顺序
1. 地窖
2. 营房
3. 陷阱走廊
4. 崔森德墓室
5. 奴隶围栏
6. 军械库
7. 储藏室和工作间
8. 裂隙
9. 红标帮警卫营房
10. 公共休息室
11. 法师的工作坊
12. 玻璃手杖的居所

## 三、要注意的
- 玻璃手杖养着一只老鼠魔宠守着暗门——它一旦看见入侵者，会立刻传念给他。
- 从庄园地窖（area 1）进来，或从卡普发现的秘密隧道（area 8）进来。
