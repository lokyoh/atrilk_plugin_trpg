# 报丧妖的庇护所

## 一、概览
- 名称：报丧妖的庇护所
- 种类：dungeon（地下城）
- 所属：卡兰提尔 · 剑湾
- 一句话：科尼伯里废墟镇外数英里的巢穴，报丧妖阿加莎只肯回答一个问题。
- 位置：科尼伯里废墟镇外数英里，林子深处；从三猪小径往东北岔出去
- 类型：林间巢穴（树下空地加一处树屋，没有房间）
- 简介：阿加莎把巢筑在一棵老树的根上，四周的树都长得歪
- 结构：一处场地：林间空地、老树下的巢、几处挂着的东西
- 魔物分布：阿加莎一只（报丧妖）；其余是林子的东西
- 陷阱与机关：没有机关；她的话才是唯一的机关
- 宝藏与资源：她收着的东西——问到点子上才拿得出来
- 势力介入：无；她不结盟，也不欠谁
- 危险等级：中（看问什么）

## 三、要注意的
- 阿加莎只会回答**一个**问题——问错了就没机会了。
