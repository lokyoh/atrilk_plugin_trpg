# 飞龙突岩

## 一、概览
- 名称：飞龙突岩
- 种类：dungeon（地下城）
- 所属：卡兰提尔 · 剑湾
- 一句话：三猪小径东端的一处岩地，兽人斥候蹲在这里劫旅人。
- 位置：三猪小径东端，剑山脉东北的崎岖丘陵；从二十里外就看得见那块突岩
- 类型：露天岩地营地，不是洞窟
- 简介：突岩曾是飞龙的巢，多年前被一队冒险者清了；如今换成兽人蹲在上面看路
- 结构：一处场地：突岩下的营地、岩缝里的哨位、拴兽栏的地方
- 魔物分布：无常者箭部落的兽人一队，带座狼；首领在突岩顶上
- 陷阱与机关：哨位与绊索，夜里换双岗
- 宝藏与资源：劫来的货；镇长出的赏格，拿兽人的头去换
- 势力介入：无常者箭部落；凡达林的告示板上写着他们的名字
- 危险等级：中（3 级）
