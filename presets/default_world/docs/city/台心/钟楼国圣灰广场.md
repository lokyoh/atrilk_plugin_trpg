# 钟楼国圣灰广场

### 据点：钟楼国圣灰广场
- 据点类型：城镇据点（广场），朝圣与交易的实际中心。
- 地理位置：灰台城内城，圣殿前，殿阶下九级。
- 面积：圆场约六亩，四面回廊。
- 人口：常住百余，朝圣日逾千。
- 势力归属：灰烬教团直辖，灰卫日夜巡。
- 势力结构：净灰执事三人轮值、灰卫十二、香市由教团抽头。
- 经济基础：赎罪铁、香市、捐灰、记名的愿牌。
- 军事力量：灰卫十二人，持杖与短刀，可召守灰军一哨。
- 与周边的关系：泊银湾斥之为赎罪券，教团反指铁行会卖的铁不净；互设禁售，货却照走。
- 特殊之处：像肩不落灰，池水浮油；愿墙上有同一个名字写了十七次，牌背刻着泊银湾仓号。
