# 故事档案
- 故事名称：草枯之盟
- 一句话简介：草场枯死，霜牙部盟南下讨盐路，白港战或让？

# 世界起点与推力设定

## 一、世界起点

### 时间背景
灰烬历四十七年深秋。霜牙岭连遭两季灰霜，牧草枯死，牲畜倒毙。

### 整体格局
白港靠北边皮货肉干过冬，部盟靠南边盐与铁过冬，互为命脉。

### 近期大事
部盟九帐聚议，三帐已越界；首批难民抵白港西门；公会拒开仓。

### 未解悬念
部盟主战与主和两派谁占上风？谁在把兵器卖给牧民？

### 玩家切入点
城门吏雇玩家清点难民，玩家在队伍里认出一个部盟探子。

## 二、世界推力

### 主要威胁
战争与难民潮同时压城，白港须在让路与开战之间选。

### 威胁来源
草场枯萎逼部盟南下，公会不肯让盐路，还把军械当筹码。

### 威胁进度
先遣牧队已越界；十日后主力抵断齿关；月内定战和。

### 影响范围
白港北郊最先，盐沼渡被借道，灰岩原粮道受扰。

### 紧迫程度
高。断齿关一开，十日之内见分晓。

## 三、势力动机

### 势力一：霜牙部盟
- 所在地：霜牙岭
- 核心目标：拿到过冬的盐粮，和一条能走的盐路。
- 当前行动：三帐南下，两帐绕盐沼渡，另派使者入城谈。
- 对玩家的态度：重誓约与勇武，收人质谈判，轻视怯者。
- 与其他势力的关系：与走私客旧交，向工坊买兵器，与教团敌对。
- 不干预后果：抢盐仓、烧北郊，白港冬储尽失。

### 势力二：盐务公会
- 所在地：白港
- 核心目标：不割盐路、不让外军进城，保住裁决权。
- 当前行动：雇佣兵守隘，私下与部盟谈，向市民瞒报军情。
- 对玩家的态度：先雇为佣兵或信使，局势一坏便推责。
- 与其他势力的关系：向工坊买械，与教团争权，靠部盟的皮货。
- 不干预后果：城防尽归公会私兵，市民离心，粮价失控。

### 势力三：熔渣工坊
- 所在地：熔渣渠
- 核心目标：两边卖军械，把铁价抬到最高。
- 当前行动：双份接单、拖延交货、囤铁囤煤。
- 对玩家的态度：只认钱，也收人命抵账。
- 与其他势力的关系：同时供公会与部盟，与走私客共运。
- 不干预后果：战事拖长，工坊坐大，公会欠下还不清的债。

## 四、事件触发条件

### 事件一：断齿关第一箭
- 触发条件：玩家护送商队过隘，或参与守关。
- 前置条件：部盟先遣已抵关下，双方尚未宣战。
- 涉及势力：部盟、公会佣兵、商队。
- 可能后果：冲突升级，和谈窗口关闭；或压下第一箭争到谈判。
- 玩家影响方式：拦射、嫁祸、传讯、以身挡阵。

### 事件二：难民冲西门
- 触发条件：第五日，或玩家开仓放粮。
- 前置条件：北郊村落被占，难民已聚数千。
- 涉及势力：难民、公会、部盟探子。
- 可能后果：城门被撞开、守军屠杀，或有序入城。
- 玩家影响方式：开门、疏导、甄别探子、征召壮丁。

### 事件三：工坊双卖
- 触发条件：玩家查验箭矢来源，或随商队进熔渣渠。
- 前置条件：战场上出现带工坊印记的箭。
- 涉及势力：工坊、公会、部盟。
- 可能后果：公会与工坊翻脸，部盟断供，战局逆转。
- 玩家影响方式：要挟、公开、坐地起价、截货。

## 五、关键节点

### 节点一：断齿关
- 所在地区：霜牙岭与白港之间
- 节点内容：两山夹一线，关墙半塌，守军不足百人。
- 与推力的关系：战和开关，谁占关谁定条件。
- 可能作用：挡住主力，或放其南下。
- 多种通过方式：守、弃、炸塌、绕行、夜袭夺关。

### 节点二：白港西门难民营
- 所在地区：白港
- 节点内容：数千难民挤在墙外，公会给粥不给城。
- 与推力的关系：人道压力，也是情报与兵源。
- 可能作用：开门则乱，闭门则怨。
- 多种通过方式：开仓、征召、驱逐、甄别、交给教团。

## 六、结局倾向

### 倾向一：城下之盟
- 形成条件：公会割盐路使用权与冬储粮，部盟退兵。
- 主要特征：盐路设双岗，部盟持通行木牌，白港割肉换安。
- 受益方：部盟、白港市民。
- 受损方：公会威信、灰岩原粮道。
- 玩家角色可能的位置：谈判中人、人质、破坏盟约者。

### 倾向二：血战守城
- 形成条件：公会拒让，佣兵与市民守关守城。
- 主要特征：断齿关血战，难民营被卷入，盐路断绝数月。
- 受益方：公会、熔渣工坊。
- 受损方：部盟、难民、白港商户。
- 玩家角色可能的位置：守城队长、逃兵、开城者。

## 七、Agent 使用原则
- 部盟不是野蛮人，公会不是正义方，双方都有过冬的理由。
- 军事推进按日计，玩家不谈不打，主力按期抵关。
- 难民既是压力也是资源：情报、兵源、人质、道义。
- 玩家可主战、主和、借道、开城或带人逃走，结局掷骰裁定。
