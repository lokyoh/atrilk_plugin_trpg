# 场景详细文档：灰肺坑

## 一、场景概览
- 场景名称：灰肺坑
- 地点类型：废弃塌陷坑 / 地下渣道
- 所在位置：废炉群北端塌陷处，坑口半掩
- 一句话定位：塔里倒下来的东西，都在这儿落地
- 场景功能：追踪、取证、危险探索

## 二、第一印象
- 视觉：坑口像一口被砸歪的锅，边缘全是半熔的渣壳。
- 听觉：底下有细碎的水滴声，和很远的风声。
- 嗅觉：湿灰、硫、冷掉的铁。
- 触觉：渣壳一脚下去会碎，缝隙里冒热气。
- 整体氛围：所有东西都是「倒下来」的形状
- 直觉：有人定期来这儿翻东西。

## 三、可感知信息
- 可见物：渣壳坡、废斗、断链、坑壁上的旧支撑木。
- 可听声：滴、风、偶尔的塌落。
- 可闻味：硫、湿灰、酸。
- 可触物：脆渣、铁丝、黏手的灰泥。
- 异常之处：渣堆顶上一层是新的，颜色比下层浅。
- 动态信息：正午之后坑口会起对流，灰往上冒。

## 四、场景布局
- 整体形状：上宽下窄的漏斗，底有一条横巷。
- 边界与出口：北接塔的渣道竖井，南为一处塌死的旧口。
- 主要区域：坑口缓坡、半腰平台、坑底横巷。
- 通道与路径：沿渣壳之字下行；横巷向东北延伸约四十步。
- 光线与声音：只在正午有直光，其余时候靠灯。

## 五、可交互元素
### 元素：新渣堆
- 位置：坑口缓坡中段
- 状态：表面平整，显然被翻过
- 操作：挖开可见七层炉的打号铁片
- 后果：挖动会滑塌，半坡随之落下

### 元素：坑底横巷
- 位置：漏斗最底
- 状态：一半被渣填死，仅容侧身
- 操作：可通向塔的渣道
- 后果：巷内积气，火把会先灭

## 六、在场者
### 在场者：翻渣人
- 类型：无籍拾渣者
- 数量：2
- 位置：半腰平台
- 外观：脸和渣一个色，背篓里全是打号铁片
- 当前行为：筛渣找可卖的号铁
- 态度：见人就跑，跑不掉才谈
- 可交流性：低；先说不抢他的货
- 关联信息：他知道「七层的东西是最近才开始倒下来的」

## 七、可能发生的事
### 事件：半坡塌落
- 条件：挖新渣堆或有人急下
- 内容：整片渣壳滑到坑底，通道被埋一半
- 回应空间：抱住废斗、退回平台、或顺势滑到底

### 事件：巷内积气
- 条件：进入横巷且用明火
- 内容：火把先灭，随后人开始头晕
- 回应空间：立刻退出、贴着地爬、或改用冷光

## 八、隐藏信息
- 七层的打号铁片出现在这里，说明「第七层的产出被当成渣倒了」。
- 翻渣人手上的号铁是新的，他一天能捡几十片——产量与账上完全不符。
- 横巷尽头堵着的东西不是渣，是封死的旧炉门，门后有铁锭。

## 九、场景变化
- 半坡塌落：坑底横巷完全埋死，只能从塔内竖井下去。
- 翻渣人被抓：他会在塔里咬出「谁让他只捡七层的」。
- 铁锭被取出：灰肺坑会被工坊封口，坑口立牌。
