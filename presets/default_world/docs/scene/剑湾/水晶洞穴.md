## 三、可感知信息
- 可见物：
  - B6: 水晶洞穴
  - 问题的核心在于岛屿地底的红龙沙鲁斯墓穴，这般强大的巨龙在地底引发的火山活动制造了这些毒烟。此外，巨龙的能量偶尔会在主物质位面撕开一道连通火元素位面的裂隙，那是另一个真实的位面，也是多元宇宙的炽热能量之源。堵塞通风口的橙色水晶（实际蛋壳）和本岩洞内的生物皆来源于此。
  - 打破火焰水晶也揭示了蕈人避免这个洞穴的原因：洞穴立即被通过通风口排列的水晶折射出的闪烁阳光所充满。明亮光照充满了整个区域。
