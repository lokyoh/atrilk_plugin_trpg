# 场景详细文档：霜牙岭哨站

## 一、场景概览
- 场景名称：霜牙岭哨站
- 地点类型：边地哨所
- 所在位置：霜牙岭与白港交界隘口
- 一句话定位：白港末桩，霜牙首门。
- 场景功能：过关、补给、换信

## 二、第一印象
- 视觉：木栅埋雪，旗撕成条。
- 听觉：风啸、栅响、马息。
- 嗅觉：冻土、马汗、松脂。
- 触觉：风如砂纸刮脸。
- 整体氛围：紧，人人听门外。
- 直觉：撑不过下场白毛风。

## 三、可感知信息
- 可见物：木栅、望楼、界碑。
- 可听声：风、铃、劈柴。
- 可闻味：冻土、马汗、焦脂。
- 可触物：冰栅、粗毡、冻绳。
- 异常之处：栅外有绕行脚印。
- 动态信息：三骑守门不下马。

## 四、场景布局
- 整体形状：方形木寨，临崖。
- 边界与出口：北通岭道，南通大道。
- 主要区域：门楼、望楼、火塘。
- 通道与路径：北门—院心—火塘。
- 高低差：寨高大道五尺。
- 遮蔽物：栅墙、雪堆、草棚。
- 光源分布：火塘、两盏油灯。
- 地形特征：院心雪成冰壳。
- 关键位置：门楼、界碑、草堆。
