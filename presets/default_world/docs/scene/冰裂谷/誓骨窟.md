# 场景详细文档：誓骨窟

## 一、场景概览
- 场景名称：誓骨窟
- 地点类型：冰壁洞窟 / 藏物点
- 所在位置：霜牙双峰之间的冰壁半腰
- 一句话定位：誓言刻在骨头上，骨头埋在冰里
- 场景功能：探索、取证、危险环境

## 二、第一印象
- 视觉：一道竖裂的蓝冰缝，缝口钉着一圈风化的兽骨。
- 听觉：风穿过骨缝的哨音，像有人在低声数数。
- 嗅觉：几乎没有味道，冷得鼻腔发疼。
- 触觉：冰面滑，骨钉扎手。
- 整体氛围：安静得让人不敢大声说话
- 直觉：这些骨头是被人摆过的。

## 三、可感知信息
- 可见物：骨钉、冰龛、旧绳梯、冻在冰里的布片。
- 可听声：骨哨、冰裂、自己的呼吸。
- 可闻味：无；偶有一丝铁味从深处上来。
- 可触物：骨、冰、绳梯的硬结。
- 异常之处：一处冰龛被凿开过，边缘还有新茬。
- 动态信息：正午后冰缝里会起雾，十步外看不清。

## 四、场景布局
- 整体形状：一条向上收窄的冰缝，两侧凿出若干冰龛。
- 边界与出口：下接雪坡，上不通；侧龛中有一处可侧身进洞。
- 主要区域：缝口骨圈、三层冰龛、侧龛内洞。
- 通道与路径：绳梯上下；侧龛内洞向后延伸十余步。
- 光线与声音：蓝光漫射，正午过后转暗。

## 五、可交互元素
### 元素：被凿开的冰龛
- 位置：第二层东侧
- 状态：龛内空了一半，凿痕新
- 操作：可取残留的草包绳头
- 后果：绳头能对上矿场的草包

### 元素：侧龛内洞
- 位置：第三层西侧
- 状态：洞口结着薄冰，里面堆着草包
- 操作：搬开草包可见池册正本与铁袋
- 后果：搬动会碰落冰柱，声响能在缝里回很久

## 六、在场者
### 在场者：守誓人
- 类型：霜牙的旧俗守誓者
- 数量：1
- 位置：缝口骨圈
- 外观：披兽皮，脸罩霜，脖子上挂一串小骨
- 当前行为：往骨钉上补新刻
- 态度：不问来意，只问「你许过什么」
- 可交流性：低；答错一句就不再说
- 关联信息：他知道谁在洞窟里藏东西——因为藏东西的人也要许誓

## 七、可能发生的事
### 事件：冰柱塌落
- 条件：在内洞搬动草包
- 内容：顶部冰柱断落，洞口被堵一半
- 回应空间：从缝里挤出去、挖开、或等守誓人来

### 事件：守誓人问誓
- 条件：与他正面相遇
- 内容：他要玩家对着骨钉说一句必须做到的话
- 回应空间：说实话、编一句、或沉默（沉默等于拒绝通行）

## 八、隐藏信息
- 骨钉上刻的不是名字，是「欠了多少铁」——这是霜牙的老账方式。
- 藏东西的人确实许过誓，内容与「不承认这批铁」有关。
- 守誓人记得那句誓的原文，但他只肯在有人先许誓时说出来。

## 九、场景变化
- 冰柱塌落：内洞暂时封死，下一章要另找入口。
- 守誓人认可：他会替玩家刻一枚骨钉，之后在霜牙各处都容易被认出来。
- 池册正本被取走：矿场的账彻底对不上，副管事会被王国带走。
