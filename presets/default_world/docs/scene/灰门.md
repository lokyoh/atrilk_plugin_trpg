# 场景详细文档：灰门

## 一、场景概览
- 场景名称：灰门
- 地点类型：关隘 / 灰烬台南门户
- 所在位置：台地南缘，出落灰带即灰烬关
- 一句话定位：门关了三天，门上没有一道新痕
- 场景功能：守点、交涉、起点

## 二、第一印象
- 视觉：两扇灰石大门嵌在台地边缘，门楣上覆着厚厚一层灰。
- 听觉：风过门缝的细响，像有人在里面吹口哨。
- 嗅觉：灰、冷石、一点焦味。
- 触觉：门上灰一按一个手印，指腹发涩。
- 整体氛围：这里本该有人，现在只剩风
- 直觉：门是从里面关上的。

## 三、可感知信息
- 可见物：门扇、门轴、门吏的空凳、挂在钉上的号旗。
- 可听声：风、门下碎石滚动。
- 可闻味：灰、焦、冷石。
- 可触物：厚灰、冰凉门钉、粗麻绳。
- 异常之处：门轴上新上了油，说明最近有人动过门。
- 动态信息：日落前后，门缝里的风会停一阵。

## 四、场景布局
- 整体形状：一道横跨台地缺口的双扇石门，两侧是陡坡。
- 边界与出口：门内上台地，门外进落灰带。
- 主要区域：门前石坪、门轴侧道、门吏房、坡下的弃车。
- 通道与路径：正门与一条绕到门后的窄侧道。
- 光线与声音：台地边缘常年灰雾，正午才见日。

## 五、可交互元素
### 元素：双扇石门
- 位置：缺口正中
- 状态：紧闭，门轴上油
- 操作：可推、可撞、可从侧道绕
- 后果：推门声在缺口里回响很远

### 元素：门吏房
- 位置：门内西侧
- 状态：空，桌上摊着半张值房表
- 操作：可读、可取
- 后果：值房表缺了最后三天的名字

### 元素：坡下的弃车
- 位置：门外落灰带边缘
- 状态：车辕断了，车上盖着草席
- 操作：掀开草席可见未及运走的灰罐
- 后果：灰罐一开，灰会顺风散开

## 六、在场者
### 在场者：门吏老韩
- 类型：守门吏
- 数量：1（离岗躲着）
- 位置：门内坡上，藏在一块界石后
- 外观：公服上落满灰，靴子磨破
- 当前行为：盯着门，不敢近前
- 态度：心虚，怕担「私关城门」的罪名
- 可交流性：中；先说明自己不是来查他的
- 关联信息：他知道是谁下的关门的令

## 七、可能发生的事
### 事件：门后被顶住
- 条件：用力推门
- 内容：门只开一条缝，缝里露出横着的门闩与几根木柱
- 回应空间：撞、从侧道进、或在门外谈条件

### 事件：灰罐散开
- 条件：掀开草席后开罐
- 内容：灰顺风漫过石坪，所有人呛得睁不开眼
- 回应空间：退到坡上、用湿布、或趁乱过门

## 八、隐藏信息
- 关门不是怕外面进来，是怕里面出去。
- 门闩是从内侧上的，木柱是台上的人抬下来的。
- 弃车上的灰罐装的不是灰，是要运下台地的东西。
- 值房表最后三天没人签，说明守门的人那时已经不在了。

## 九、场景变化
- 门被撞开：台上会派人下来查看，之后门吏重新上岗。
- 与老韩谈成：他会带路走侧道，但要求「别提我今晚在这」。
- 灰罐被打开：风一散，台上会知道有人动过弃车。
