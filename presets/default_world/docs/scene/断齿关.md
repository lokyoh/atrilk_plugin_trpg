# 场景详细文档：断齿关

## 一、场景概览
- 场景名称：断齿关
- 地点类型：关城（两山夹一线）
- 所在位置：白喉隘最窄处，白港与霜牙岭交界
- 一句话定位：墙塌了一半，税照收，人照拦。
- 场景功能：过关、验票、避风

## 二、第一印象
- 视觉：半塌石墙卡在两山之间，关楼只剩骨架。
- 听觉：风穿过墙洞，像有人在吹口哨。
- 嗅觉：松脂、冻土、马汗。
- 触觉：石面粗砺，风刮脸。
- 整体氛围：破，但不乱。
- 直觉：这道墙是靠收钱撑住的，不是靠石头。

## 三、可感知信息
- 可见物：半塌墙、断齿石、关楼残梁、界碑。
- 可听声：风、铃、算盘、吆喝。
- 可闻味：冻土、马汗、焦油。
- 可触物：粗石、断索、冷铁。
- 异常之处：塌口的碎石被人摆整齐过。
- 动态信息：过关的人都要在关旗下停一次。

## 四、场景布局
- 整体形状：一线关城，南北两山夹一道墙。
- 边界与出口：南通白港大道，北通霜牙岭道。
- 主要区域：关楼、验票棚、马厩、塌口。
- 通道与路径：南门—验票棚—关楼—北门。
- 高低差：关墙比道高两丈，北门下坡。
- 遮蔽物：残墙、马厩、垛口。
- 光源分布：关楼两盏，风大时只剩一盏。
- 地形特征：道宽只容两车并行，崖侧无路。
- 关键位置：关楼、界碑、塌口。

## 五、可交互元素
### 元素：界碑
- 类型：地标
- 位置：北门内侧
- 外观：半人高，字迹磨平
- 交互方式：验看（调查 DC 13）
- 可能结果：碑座是新土
- 关联信息：碑被挪动过，风雪位移报过
- 隐藏内容：碑底压着一枚旧铜扣

### 元素：验票棚
- 类型：信息点
- 位置：南门内
- 外观：油布顶，木栏排队
- 交互方式：核票（察言观色 DC 12）
- 可能结果：票号不对，或对得太齐
- 关联信息：过关的人十个里有一个说不清货名
- 隐藏内容：棚后夹着一本单独的货单簿

### 元素：塌口
- 类型：隐患
- 位置：关墙东段
- 外观：碎石堆齐，可容一人侧身
- 交互方式：攀爬（力量 DC 13）
- 可能结果：能过去，也能摔进沟里
- 关联信息：碎石齐是被特意码的
- 隐藏内容：塌口后是一条绕过验票棚的旧道

## 六、在场者
### 在场者：关尹阮九郎
- 类型：白港关吏
- 数量：1
- 位置：关楼
- 外观：须修得整，眼睛只看票不看人
- 当前行为：盖章、报数
- 态度：守规矩，但规矩由他念
- 可交流性：中
- 关联信息：报过三次风雪移位，界碑的事他知道

### 在场者：驿卒老涧
- 类型：传令驿卒
- 数量：1
- 位置：马厩
- 外观：半边脸冻烂，围巾结霜
- 当前行为：刷马，看天
- 态度：话少，怕误时辰
- 可交流性：中高，一碗热水就开口
- 关联信息：知道北门什么时候能过整队

### 在场者：岭下行商陶二娘
- 类型：行商
- 数量：1，商队四人
- 位置：验票棚前
- 外观：皮袄油亮，怀里抱账匣
- 当前行为：讲价，翻货单
- 态度：精明，讲信
- 可交流性：高
- 关联信息：货单上的数与车上对不上

## 七、可能发生的事
### 事件：整队过岭
- 触发条件：北门开且驿卒放行
- 事件内容：一队人马挤进北门，道窄只能慢行
- 涉及元素：验票棚、界碑、塌口
- 涉及在场者：老涧、阮九郎、陶二娘
- 可能走向：让路、卡住、趁乱夹带
- 持续时间：一时辰
- 后续影响：让了路，南门就得堵一会儿

### 事件：塌口塌石
- 触发条件：风急或有人动塌口的碎石
- 事件内容：碎石滑落，堵住半个道
- 涉及元素：塌口、关墙
- 涉及在场者：阮九郎、老涧
- 可能走向：清石、绕行、报损
- 持续时间：半日
- 后续影响：关墙再少一截，过关的照收钱

## 八、隐藏信息
- 隐藏内容：①界碑被挪过，碑底压着旧铜扣；②验票棚后夹着一本单独的货单簿；③塌口后是绕过验票棚的旧道
- 隐藏方式：碑座新土、油布夹角、碎石被码齐
- 发现方式：验碑（调查 DC 13）；核票（察言观色 DC 12）；攀爬（力量 DC 13）
- 发现难度：13 / 12 / 13
- 关联信息：同指关吏吃的一贯小钱
- 可能影响：可拿来换过关，也可替商队省下一道税

## 九、场景变化
- 时间变化：日落关北门，只开南门小窗
- 事件变化：塌石后关墙只剩半人高
- 角色行为变化：帮驿卒牵马则老涧肯带路走旧道
- 在场者变化：风一起，行商全躲进马厩
- 环境变化：雪埋塌口，碎石与雪混成一处
- 状态变化：货单簿曝光则阮九郎停笔三日
