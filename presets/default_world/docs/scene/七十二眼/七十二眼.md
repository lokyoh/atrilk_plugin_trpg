# 场景详细文档：七十二眼

## 一、场景概览
- 场景名称：七十二眼
- 地点类型：天坑群 / 竖井迷宫
- 所在位置：台原北缘天坑群，最大一眼的坑底
- 一句话定位：七十二口井，只有一口是通的
- 场景功能：探索、解谜、危险下降

## 二、第一印象
- 视觉：一片被戳出七十多个洞的灰白地面，像筛子，最大的那个能装下半座镇。
- 听觉：风从各个洞口进来，在井下合成一种低频的嗡。
- 嗅觉：石灰尘、湿土，偶尔一股铁锈味。
- 触觉：坑沿酥脆，一眼踩下去就塌。
- 整体氛围：每走一步都在赌这块地承不承重
- 直觉：这些洞不是天然的。

## 三、可感知信息
- 可见物：坑口、塌边、旧木架、垂下的绳。
- 可听声：风、落石、深处规律的敲击。
- 可闻味：石灰、湿土、铁锈。
- 可触物：酥沿、硬绳、冷石。
- 异常之处：几口小坑的边上有新的凿痕，像被人特意打通。
- 动态信息：起风时所有坑口一起扬灰，能见度骤降。

## 四、场景布局
- 整体形状：七十余个大小不一的漏斗，彼此井壁有暗道相连。
- 边界与出口：南接磨盘镇的北街，北面是断崖。
- 主要区域：主坑口、绳架、第九眼的横巷、被封的旧井道。
- 通道与路径：主坑绳降；坑底横巷通向相邻的井。
- 光线与声音：坑底常年昏暗，声音在井间回声交错。

## 五、可交互元素
### 元素：主坑绳架
- 位置：最大一眼的坑口
- 状态：两副旧木架，绳是新的
- 操作：绳降到底约十五丈
- 后果：绳是中段接的，超重会断

### 元素：第九眼
- 位置：主坑底向东北三十步
- 状态：井口被石板盖着，石板一侧有缝
- 操作：可撬开缝用手电/冷光窥视
- 后果：石板下面有支撑木，撬动会整片塌

### 元素：被封的旧井道
- 位置：主坑底正南
- 状态：砖堵，砖缝里透风
- 操作：拆砖可通磨盘镇方向
- 后果：拆砖会放出井下积的气

## 六、在场者
### 在场者：井底的人
- 类型：被困者 / 身份不明
- 数量：3
- 位置：第九眼之下
- 外观：看不真切，靠火光才能分辨轮廓
- 当前行为：按固定节拍敲击井壁
- 态度：听见人声会先停，再敲得更急
- 可交流性：低，要先用节拍回应
- 关联信息：他们从磨盘镇失踪了近二十天

## 七、可能发生的事
### 事件：绳断
- 条件：多人同时绳降
- 内容：绳在中段断开，一半人掉到坑底平台
- 回应空间：从横巷找路、呼救、或放弃上面的人

### 事件：气涌
- 条件：拆开南面砖堵
- 内容：积气冲出，明火会爆，人能晕
- 回应空间：先放火把试、退到上风、或用湿布

## 八、隐藏信息
- 七十二眼里大部分是采石留下的旧坑，只有九口是后来为了藏人挖的。
- 第九眼下面不是井，是一间用旧井壁改出来的屋子，有门有闩。
- 敲击节拍与磨盘一致的真正原因：井里的人能听见磨盘的转动，用它计时。
- 有人在按时送水下去——说明这不是绑架，是「关着等某件事办完」。

## 九、场景变化
- 绳断：主坑短期不可用，只能从磨盘镇的旧竖井下去。
- 井底的人被救出：磨盘镇会炸开锅，掌磨人老砚当晚失踪。
- 南面砖堵拆开：旧井道通了，但积气会伤到附近坑口的人。
