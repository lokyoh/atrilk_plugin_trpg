# 场景详细文档：沉盐塘

## 一、场景概览
- 场景名称：沉盐塘
- 地点类型：水下废墟 / 沉船仓
- 所在位置：旧盐仓沉没处，潮沟西侧水下
- 一句话定位：盐沉下去的时候，账也跟着沉了
- 场景功能：水下探索、取证、限时

## 二、第一印象
- 视觉：退潮后露出一角屋脊与半扇门框，水面下还有成排的柱。
- 听觉：水拍屋脊的空响，退潮时像有人在里面走动。
- 嗅觉：浓重的咸腥与烂木。
- 触觉：水下能见度极低，手指先于眼睛知道东西在哪。
- 整体氛围：整片地方都在缓慢地下沉
- 直觉：屋脊上的绳是新的。

## 三、可感知信息
- 可见物：屋脊、门框、木柱、水面的浮标。
- 可听声：水拍、木裂、退潮的吸吮声。
- 可闻味：咸、烂木、硫。
- 可触物：滑木、缠脚的绳、滑腻的盐壳。
- 异常之处：屋脊被人系了浮标绳，绳上打的是新结。
- 动态信息：一天两次露头，各约一个半时辰。

## 四、场景布局
- 整体形状：半沉的方院，四面屋，中庭是盐池。
- 边界与出口：东面接潮沟，其余三面临深水。
- 主要区域：露头的屋脊、中庭盐池、后屋的仓、水下通道。
- 通道与路径：露头时可从屋脊下到中庭；水下需沿柱走。
- 光线与声音：退潮时天光够用，水下全靠摸索。

## 五、可交互元素
### 元素：中庭盐池
- 位置：方院正中
- 状态：盐壳封住池口，浮着碎木
- 操作：破壳可下到池底仓
- 后果：破壳后潮水会灌得更快

### 元素：后屋仓门
- 位置：西北
- 状态：门被从里面顶住
- 操作：可撞、可撬、可从屋顶进去
- 后果：撞门会惊动水下的回声，传得很远

### 元素：浮标绳
- 位置：屋脊
- 状态：新结，绳头系着一块刻字的木牌
- 操作：解下可读木牌
- 后果：绳一松，浮标会漂走，别人就知道有人来过

## 六、在场者
### 在场者：潜水的收账人
- 类型：受雇的水下取货人
- 数量：2
- 位置：中庭水下
- 外观：只看得见一根呼吸用的苇管露出水面
- 当前行为：一趟趟往船上搬封蜡的盐包
- 态度：见人就沉下去，不与人正面接触
- 可交流性：低；断他们的苇管才肯谈
- 关联信息：他们知道仓里还剩多少包没起

## 七、可能发生的事
### 事件：涨潮封口
- 条件：在中庭逗留过久
- 内容：水位上涨，屋脊只剩半人高，退路被水封
- 回应空间：抢在中庭灌满前上屋脊、潜水走东口、或钻进后屋

### 事件：撞开仓门
- 条件：强行撞开后屋门
- 内容：门内积水涌出，带出成堆的封蜡盐包与一具旧尸
- 回应空间：抢货、先看尸、或退出去等水退

## 八、隐藏信息
- 沉下去的盐仓从来没被清空，账上记的是「全损」。
- 后屋里的旧尸是当年管仓的人，不是溺死的，胸口有伤。
- 水下的取货人不是盗贼，是有账的人派来的：他们按包数交货。
- 浮标绳是外人系的，说明还有第三方在盯着这批货。

## 九、场景变化
- 涨潮封口：这一处要等下一轮退潮才能再进，耽误的时间会被人利用。
- 仓门被撞开：取货人会弃货离开，货主会换人来查。
- 旧尸被发现：盐仓旧案被翻出来，王国会介入。
