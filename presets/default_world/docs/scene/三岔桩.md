# 场景详细文档：三岔桩

## 一、场景概览
- 场景名称：三岔桩
- 地点类型：城镇据点（分水口交割处）
- 所在位置：盐沼渡，三条潮沟交汇处
- 一句话定位：桩上刻着谁欠谁，货就归谁。
- 场景功能：交割、还债、问路

## 二、第一印象
- 视觉：一根黑木桩立在交汇处，水从三面来。
- 听觉：水声撞桩、算盘、讨价还价。
- 嗅觉：咸腥、柴油、湿木。
- 触觉：桩身湿滑，缆绳勒手。
- 整体氛围：吵，且每句话都留着后手。
- 直觉：这里的账没有对错，只有谁说了算。

## 三、可感知信息
- 可见物：黑木桩、缆桩、账棚、五条船。
- 可听声：点数、争执、桩首的木梆。
- 可闻味：咸腥、柴油、油布。
- 可触物：缆绳、船板、刻痕。
- 异常之处：桩上刻痕最深的三个名字，是外来的。
- 动态信息：船一靠桩，围上来的人先看桩首脸色。

## 四、场景布局
- 整体形状：一桩居中，三条水道呈扇形散开。
- 边界与出口：北通桩上，西接栈道口，南出海口。
- 主要区域：桩、账棚、泊位、候船的芦排。
- 通道与路径：船—桩—账棚，水上无路。
- 高低差：船面与岸差三尺，涨潮时齐平。
- 遮蔽物：账棚、油布、苇排。
- 光源分布：两盏防风灯，桩上无灯。
- 地形特征：水流三向交汇，船难停稳。
- 关键位置：桩身、账棚、桩首的坐凳。

## 五、可交互元素
### 元素：黑木桩
- 类型：地标
- 位置：交汇处水中央
- 外观：漆黑，刻满名字，深浅不一
- 交互方式：摸刻痕（察觉 DC 12）
- 可能结果：最新的名字还没刮平
- 关联信息：刻名的是欠债的人自己
- 隐藏内容：最深的三个名字都姓白港的官姓

### 元素：账棚
- 类型：信息点
- 位置：西岸高台
- 外观：油布顶，木板桌五张
- 交互方式：翻账（调查 DC 14）
- 可能结果：押金与抽头对不上
- 关联信息：五条船帮各记一本
- 隐藏内容：另有一本只记「谁替谁押的」

### 元素：候船的芦排
- 类型：人群
- 位置：东侧泊位
- 外观：苇排捆得极紧
- 交互方式：搭话（察言观色 DC 12）
- 可能结果：问出今日潮位与开价
- 关联信息：排上人多半不识字
- 隐藏内容：排底压着两条快船的桨

## 六、在场者
### 在场者：桩首阮九娘
- 类型：船帮头目
- 数量：1
- 位置：账棚正中
- 外观：三十上下，赤脚踩凳
- 当前行为：听，不插话
- 态度：笑面，记账极狠
- 可交流性：中高，肯谈价钱
- 关联信息：白港三名税吏的账在她手里

### 在场者：记账人胡三七
- 类型：船帮记账人
- 数量：1
- 位置：账棚东桌
- 外观：瘦，笔杆咬在牙间
- 当前行为：写，偶尔抬头
- 态度：怕事，只认账本
- 可交流性：中
- 关联信息：知道押金里混了私钱

### 在场者：把头莫大
- 类型：船工把头
- 数量：1，船工十余
- 位置：泊位
- 外观：赤膊，肩上搭着缆
- 当前行为：撑船，等派活
- 态度：直，敬说话的
- 可交流性：高，请碗酒更好
- 关联信息：潮退三刻必须走人

## 七、可能发生的事
### 事件：撞桩
- 触发条件：风向变或有人抢泊位
- 事件内容：两条船在交汇处互撞，船帮立刻围上来
- 涉及元素：黑木桩、候船的芦排
- 涉及在场者：莫大、胡三七
- 可能走向：捞人、索赔、械斗
- 持续时间：一刻钟
- 后续影响：桩首出面才收得住，欠账的趁机加名

### 事件：刻名
- 触发条件：有人当众还不起账
- 事件内容：桩首亲笔添名，债主守在旁边
- 涉及元素：黑木桩、账棚
- 涉及在场者：阮九娘、胡三七
- 可能走向：当场还清、当场翻脸、找人代还
- 持续时间：片刻
- 后续影响：上了桩的人，全渡口都认得

## 八、隐藏信息
- 隐藏内容：①桩上最深的三个名字都属白港官吏；②账棚另有一本只记代押的账；③芦排底下藏着快船的桨
- 隐藏方式：刻痕深浅、油布压角、排底压桨
- 发现方式：摸桩（察觉 DC 12）；翻账（调查 DC 14）；搭话（察言观色 DC 12）
- 发现难度：12 / 14 / 12
- 关联信息：同指一条绕过白港税口的私货线
- 可能影响：可拿去向官府换赏，也可卖给阮九娘换路

## 九、场景变化
- 时间变化：退潮时桩露全，落潮桩只剩三尺
- 事件变化：撞桩后五条船帮各出一人看着
- 角色行为变化：替人说项则莫大肯带路走夜水路
- 在场者变化：外乡人多了，账棚会加暗哨
- 环境变化：起雾时桩位只能靠喊
- 状态变化：代押账曝光则全渡口封账三日
