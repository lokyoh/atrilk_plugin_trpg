# 场景详细文档：泥渡栈道口

## 一、场景概览
- 场景名称：泥渡栈道口
- 地点类型：渡口 / 栈道关隘
- 所在位置：泥渡栈道东端，接潮沟
- 一句话定位：水涨的时候这里是个岛，水落的时候这里是个坟
- 场景功能：过路、交涉、踩点

## 二、第一印象
- 视觉：半没在水里的木栈道从芦苇里伸出来，尽头一块歪斜的收钱牌。
- 听觉：木桩在水里咯吱，芦苇一直在响。
- 嗅觉：淤泥、腐草、鱼腥。
- 触觉：栈板滑，扶手上全是青苔。
- 整体氛围：所有东西都像随时会被水收走
- 直觉：收钱的人不在，牌子却擦得很干净。

## 三、可感知信息
- 可见物：栈板、木桩、收钱牌、系着的小划子。
- 可听声：桩响、芦苇、远处的潮声。
- 可闻味：淤泥、腐草、鱼腥。
- 可触物：滑板、湿绳、冰凉的铜钱匣。
- 异常之处：栈道有一节换过新板，钉子还是亮的。
- 动态信息：每次涨潮，栈道最东一节会没入水中。

## 四、场景布局
- 整体形状：一条三里长的木栈道，东端接潮沟，西端没入芦苇。
- 边界与出口：向东上船进潮沟，向西沿栈道进内陆。
- 主要区域：收钱棚、换过的新板、系船的桩。
- 通道与路径：只能沿栈道走；两侧是踩不得的浮泥。
- 光线与声音：芦苇遮住大半视线，声音传得远。

## 五、可交互元素
### 元素：收钱棚
- 位置：栈道东端
- 状态：空着，铜钱匣半开
- 操作：可翻匣、可查看登记的木牌
- 后果：匣里钱数不对，会被下一班渡夫咬住

### 元素：新换的栈板
- 位置：栈道中段
- 状态：木色浅，钉子新
- 操作：掀开可见下面的水下木箱
- 后果：掀板会让这一节沉下去

### 元素：系船桩
- 位置：东端水里
- 状态：系着两只划子，一只吃水很深
- 操作：可解缆、可翻查船底
- 后果：吃水深的船底绑着东西

## 六、在场者
### 在场者：渡夫阿灰
- 类型：栈道渡夫
- 数量：1
- 位置：系船桩旁
- 外观：裤脚永远湿到膝盖，脚上是草鞋
- 当前行为：蹲着刮船底的泥
- 态度：和气，但一问账就装听不见
- 可交流性：中；先给一趟船钱
- 关联信息：他知道最近谁在夜里运过重货

### 在场者：守栈的老妇
- 类型：栈道看棚人
- 数量：1
- 位置：收钱棚
- 外观：披着蓑衣，眼很亮
- 当前行为：把木牌上的字一遍遍描深
- 态度：不冷不热，只认规矩
- 可交流性：中；按规矩办事就好说话
- 关联信息：她记得每一趟过栈的船号

## 七、可能发生的事
### 事件：涨潮断路
- 条件：在栈道上停留过久
- 内容：东段没入水中，退路只剩芦苇里的浮泥
- 回应空间：上船、退回棚里、或冒险踩浮泥

### 事件：沉箱被发现
- 条件：掀开新换的栈板
- 内容：水下木箱浮起一角，里面是封着蜡的盐包
- 回应空间：立刻盖回、拖上岸、或装作没看见

## 八、隐藏信息
- 收钱匣里少掉的钱，与夜里过栈的重货对得上：有人免了这笔船钱。
- 新换的栈板不是为了修路，是为了盖住沉箱。
- 吃水深的那只划子，船底绑的是要送往沉盐塘的蜡封盐包。
- 守栈老妇知道，但她的规矩是「只记账，不问货」。

## 九、场景变化
- 沉箱被发现：夜里会有人来起货，栈道口多两个生面孔。
- 涨潮断路：栈道要半日才通，耽误的时间会被记进账。
- 与老妇谈妥：她会给出夜里过栈的船号与时辰。
