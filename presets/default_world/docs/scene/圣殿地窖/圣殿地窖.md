# 场景详细文档：圣殿地窖

## 一、场景概览
- 场景名称：圣殿地窖
- 地点类型：神殿地下层 / 禁地
- 所在位置：圣殿之下，圣像基座的风口通进去
- 一句话定位：教团说这底下是神的伤口，所以谁都不许看
- 场景功能：潜入、揭秘、危险探索

## 二、第一印象
- 视觉：一道从圣像基座斜下去的窄缝，缝里透出暖色的光。
- 听觉：很低的风声，夹着像呼吸的节律。
- 嗅觉：热灰、香烛、还有一丝铁。
- 触觉：石壁微温，往下越走越热。
- 整体氛围：像走进一头还在呼吸的东西体内
- 直觉：这底下的暖风不是地热，是有人在烧什么。

## 三、可感知信息
- 可见物：窄缝、铁箍、风道口、墙上被磨平的旧壁画。
- 可听声：风、节律性的轻响、远处的水滴。
- 可闻味：热灰、香烛、铁。
- 可触物：温壁、粗铁箍、地上的灰。
- 异常之处：壁画上有一块被反复刮过，露出底下的另一层画。
- 动态信息：每过一阵，风口会猛地一吸，再缓缓呼出。

## 四、场景布局
- 整体形状：一段斜缝下行，接一间圆形地室，另有两条风道。
- 边界与出口：上通圣像基座；风道一条向灰沟，一条向台外。
- 主要区域：斜缝、圆形地室、祭台、被刮过的壁画墙。
- 通道与路径：斜缝单行；地室内绕祭台一圈。
- 光线与声音：地室自有一种暖光，来源不明。

## 五、可交互元素
### 元素：祭台上的灰瓮
- 位置：圆形地室正中
- 状态：瓮口半开，里面积着温灰
- 操作：可取灰样、可翻看瓮底刻字
- 后果：瓮一移，风口的风向就变

### 元素：被刮过的壁画
- 位置：地室北壁
- 状态：表层被刮，底层还留着线条
- 操作：可辨出旧图：一群人把什么东西抬下去
- 后果：刮擦声在地室里放大

### 元素：向台外的风道
- 位置：地室东南
- 状态：窄，能容一人爬行
- 操作：可爬到台地外缘的落灰带
- 后果：爬动会带起积灰，留下清楚痕迹

## 六、在场者
### 在场者：守灯的老执事
- 类型：教团老执事
- 数量：1
- 位置：祭台侧
- 外观：一身素灰，眼被烟熏得常年流泪
- 当前行为：守着一盏不灭的灯，按时添灰
- 态度：不驱赶，只反复说「这里不该有人」
- 可交流性：中；安静坐下来他才肯多说一句
- 关联信息：他知道「神的伤口」这个说法是哪一年开始的

## 七、可能发生的事
### 事件：风口反转
- 条件：移动灰瓮
- 内容：地室由呼转吸，暖光骤暗，积灰倒卷
- 回应空间：立刻扶正瓮、退到斜缝、或趁暗穿过风道

### 事件：教团查夜
- 条件：在地室停留过久且弄出声响
- 内容：上面下来两个执事，提着灯逐段查看
- 回应空间：躲进风道、混作守灯人、或正面应对

## 八、隐藏信息
- 地室里的暖风来自一处没熄的旧炉，不是神迹。
- 被刮掉的壁画画的正是当年把东西抬下来封住的事。
- 「神的伤口」这个说法，是在那件事之后才有的：它是一句封锁令。
- 老执事守的灯不是为了供奉，是为了让外人看不见地室真正的光源。

## 九、场景变化
- 风口反转：地室要半日才恢复，这几天没人敢下来。
- 壁画被拓下来：教团会封锁整座圣殿，转而对外宣称「神怒」。
- 老执事松口：他会给出当年抬东西下去的人名，但要求替他熄灯。
