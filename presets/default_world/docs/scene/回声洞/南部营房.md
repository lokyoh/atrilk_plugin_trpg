# 南部营房

## 一、场景概览
- 场景名称：南部营房
- 所在地点：回声洞（6 号房间）
- 一句话定位：这里曾是矿工的营房，在回声洞中工作的熟练矿工们在此轮班休息。任何角色若在部分开启的门边倾听，并通过DC 10的感知（察觉）检定，就能听到微弱…
- 场景功能：战斗（食尸鬼）

## 二、第一印象
- 古老的岩石床铺整齐排列在这个房间的墙壁旁，一个装满旧煤块的腐蚀铁火盆立在房间中央附近。六七个矮人和兽人的骨骸散落各处，身上还挂着护甲碎片。三个灰色、驼背的身影蹲在遗骸中，翻找着碎片并啃咬着骨头。
