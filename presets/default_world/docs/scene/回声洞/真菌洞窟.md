# 真菌洞窟

## 一、场景概览
- 场景名称：真菌洞窟
- 所在地点：回声洞（8 号房间）
- 一句话定位：这个洞穴阻碍了内兹纳的探索。卓尔怀疑矿井的魔法工坊就在附近，但他不愿冒险对付这里的怪物。
- 场景功能：探索

## 二、第一印象
- 怪异的真菌在这座洞窟的地面上形成了密集的覆盖层。这些生长物包括直径一英尺的马勃菌、生长在石笋上的奇异层菌，以及高达五英尺的大型菌柄和菌盖。部分马勃菌散发着诡异的绿色磷光。

## 三、可感知信息
- 这个洞穴阻碍了内兹纳的探索。卓尔怀疑矿井的魔法工坊就在附近，但他不愿冒险对付这里的怪物。
- 大部分真菌是无害的，而发绿光的真菌能让生物无需借助黑暗视觉或光源就能看清整个洞窟。
- 每当一个生物试图穿过洞窟时，覆盖大部分地面的真菌毯会向空气中释放毒气。洞窟内的每个生物必须成功通过DC 11的体质豁免检定，否则受到3d6毒素伤害并陷入中毒状态10分钟（关于中毒状态的更多信息请参阅规则书）。毒气会在1分
