# 古老河床

## 一、场景概览
- 场景名称：古老河床
- 所在地点：回声洞（17 号房间）
- 一句话定位：从area 10流向area 18的溪流曾流经这条低矮通道，最终注入area 16。
- 场景功能：探索

## 二、第一印象
- 这条通道仅有四英尺高，被圆形的巨石和鹅卵石所阻碍。它可能曾是一条河床，尽管现在这里没有水流。
- 

## 三、可感知信息
- 从area 10流向area 18的溪流曾流经这条低矮通道，最终注入area 16。
- 矮人们将溪流改道引入通往area 12的渠道，以驱动冶炼厂的水车。后来兽人入侵期间，在最后的法术战斗中震撼回声洞的地震使area 18的地面坍塌，再次改变了溪流方向。古老的河床仍然可作为一条避开area 12不死生物的可
