# 旧入口

## 一、场景概览
- 场景名称：旧入口
- 所在地点：回声洞（3 号房间）
- 一句话定位：向南延伸的隧道曾是回声洞的原始入口，但在数个世纪前被摧毁矿山的灾难所掩埋。当兽人突袭矿山时，这里曾发生过一场激烈的战斗。死者仍躺在他们倒下的…
- 场景功能：战斗（蚊蝠）

## 二、第一印象
- 许多隧道在这个天然的三十尺高洞窟中交错。墙壁上雕刻着简易浮雕，展示着矮人和侏儒矿工辛勤工作的场景。在他们下方，近二十具穿着锈蚀护甲碎片的骷髅散落在洞窟地面上。有些是矮人骷髅，其他则是兽人遗骸。六个大型黄铜灯笼放置在洞窟壁龛或岩架上，但全都未被点亮。
- 

## 三、可感知信息
- 向南延伸的隧道曾是回声洞的原始入口，但在数个世纪前被摧毁矿山的灾难所掩埋。当兽人突袭矿山时，这里曾发生过一场激烈的战斗。死者仍躺在他们倒下的地方。
- 像蝙蝠一样倒挂在洞顶的是十只**蚊蝠们**。这些怪物在矿坑里几乎找不到活物作为猎物，因此它们饥肠辘辘。如果角色们正低头查看地上的骷髅，蚊蝠们很可能会突袭他们。任何没有留意洞顶的角色都将突袭，除非其被动感知（察觉）值高于蚊
- 那些矿工工作的灯笼和雕刻是为了欢迎新来者。
