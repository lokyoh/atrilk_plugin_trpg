# 法术工厂

## 一、场景概览
- 场景名称：法术工厂
- 所在地点：回声洞（15 号房间）
- 一句话定位：这里是法师们与法德尔契约的矮人和侏儒结盟的地方，他们引导这些洞穴的魔法来为矮人武器和侏儒装置附魔。最北边的门被烧焦并裂开，其铁铰链部分熔化；…
- 场景功能：战斗（观察者眼魔）

## 二、第一印象
- 这个大型工坊被远古法术战斗严重破坏，导致矿井荒废。占据房间两个对角的操作台被烧焦，灰泥从砖石墙壁上剥落。房间中央的石制基座上放着一个小火盆，诡异的绿色火焰在其中舞动并发出噼啪声。火盆及其基座似乎未受摧毁该区域的力量影响。
- 
- 在绿焰的火盆后方漂浮着一个直径约四英尺的球形生物。四根眼柄从其主体两侧各伸出两根。身体中央有一只大眼睛凝视着你。"你好，"一个厚重而冒泡的声音在你脑海中响起。

## 三、可感知信息
- 这里是法师们与法德尔契约的矮人和侏儒结盟的地方，他们引导这些洞穴的魔法来为矮人武器和侏儒装置附魔。最北边的门被烧焦并裂开，其铁铰链部分熔化；强行打开它需要通过一个DC 15的力量检定。西边的双开门同样受损，但微微敞开。
- 守卫这个房间的怪物是一只**观察者眼魔**。曾在法术锻造厂工作的人类法师之一召唤了这个生物来守护这里创造和储存的魔法物品。当矿井被洗劫时，兽人们扰乱了区域内的微妙魔法，动摇了观察者眼魔对现实的掌控。它变得精神错乱，认为矿
- 邪灵（area 14）想要驱逐或杀死观察者眼魔，但到目前为止，这个生物轻松应对了墨梅斯克的丧尸们和食尸鬼们的攻击，同时对不死生物在矿井中游荡毫无察觉。如果队伍试图从这个区域带走任何东西，观察者眼魔会发动攻击。如果观察者眼
- 通过一次成功的DC 15魅力（欺瞒）检定，角色可以欺骗观察者眼魔使其认为一名或多名队友是为回声洞主人工作的法师或矿工，被派来终止观察者眼魔的雇佣关系。如果欺瞒成功，观察者眼魔会认为自己已从义务中解脱，随后消失并返回其家乡
