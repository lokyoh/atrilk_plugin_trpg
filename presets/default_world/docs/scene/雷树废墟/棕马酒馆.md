# 棕马酒馆

## 一、场景概览
- 场景名称：棕马酒馆
- 所在地点：雷树废墟（3 号房间）
- 一句话定位：这里曾是棕马酒馆，一家以优质麦芽酒闻名的酒馆。
- 场景功能：战斗（灰烬丧尸）

## 二、第一印象
- 这座大型建筑门旁的一块风化招牌上，显示着一匹驮马叼着麦芽酒壶的褪色图像。建筑已经倾斜破败，但比起旅路对面的遗迹要完整些。

## 三、可感知信息
- 这里曾是棕马酒馆，一家以优质麦芽酒闻名的酒馆。

- 建筑的东半部分是旧的大厅，而西侧则是厨房和酿酒师的大桶。巨大的木桶矗立在西部，空气中仍弥漫着淡淡的酵母味。麦芽酒早已不复存在。
