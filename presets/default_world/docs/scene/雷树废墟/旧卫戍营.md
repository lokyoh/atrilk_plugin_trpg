# 旧卫戍营

## 一、场景概览
- 场景名称：旧卫戍营
- 所在地点：雷树废墟（11 号房间）
- 一句话定位：对于桑达树的居民来说，生活在如此靠近无冬森林的地方需要时刻保持警惕。
- 场景功能：战斗（灰烬丧尸）

## 二、第一印象
- 这座兵营似乎比小镇上大多数建筑物更能经受岁月的洗礼。它的屋顶设有简易的城垛，箭缝窗户证实了它是为在紧急事件发生时充当小型要塞而建造的。
- 

## 三、可感知信息
- 对于桑达树的居民来说，生活在如此靠近无冬森林的地方需要时刻保持警惕。
- 五只**灰烬丧尸**（见"灰烬僵尸"边栏）潜伏在这栋建筑内。这些曾是驻军成员的丧尸仍穿着生锈锁子甲和士兵罩袍的残片。不过这些护甲碎片并未提升它们的护甲等级。若有任何活体生物惊扰其安眠，丧尸们就会苏醒并发动攻击。
- 建筑内部仍保留着家具，主房间有一个梯子通向屋顶的活板门。北面的房间有两张双层床，南面的房间有三张双层床，总共可容纳十名士兵。军营主区域的西北部曾是一个厨房和储藏室，现在堆满了腐烂的麻袋和木桶，这些容器曾经装着腌肉。所有食
