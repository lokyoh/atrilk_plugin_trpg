# 王之居所

## 一、场景概览
- 场景名称：王之居所
- 所在地点：克拉摩堡（14 号房间）
- 一句话定位：任何在门边聆听的角色都会听到两个声音在激烈讨论——一个响亮、咆哮的声音要求为某事支付报酬，以及一个柔软平滑的回应。
- 场景功能：战斗（熊地精、变形怪、大地精）

## 二、第一印象
- 这个房间被布置成一个简陋的生活空间，厚毛皮被扔在地上当作地毯，旧战利品挂在墙上，北边有一张大床，还有一个燃烧着明亮煤炭的火盆。南边靠近门的地方有一张圆桌和几把椅子。桌子附近的地板上躺着一个昏迷的矮人，看起来被打得很惨。
