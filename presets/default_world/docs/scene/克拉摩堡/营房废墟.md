# 营房废墟

## 一、场景概览
- 场景名称：营房废墟
- 所在地点：克拉摩堡（4 号房间）
- 一句话定位：峭壁地精们充分利用了城堡中的每一寸可用空间。
- 场景功能：探索（地精）

## 二、第一印象
- 城堡的西南塔楼几乎只剩一堆瓦砾。几张破旧的铺盖散落在剩余的地板空间上，一条小型蜿蜒的通道向东穿过废墟。

## 三、可感知信息
- 峭壁地精们充分利用了城堡中的每一寸可用空间。
