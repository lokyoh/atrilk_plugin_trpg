# 克拉摩堡警卫营房

## 一、场景概览
- 场景名称：克拉摩堡警卫营房
- 所在地点：克拉摩堡（12 号房间）
- 一句话定位：这里的生物从箭缝处守卫，所以任何在城堡东侧潜行的角色都可能被发现并遭到攻击。
- 场景功能：战斗（大地精）

## 二、第一印象
- 一个装满煤炭的石制火盆在这个小型营房中央发光。四张草垫沿着东墙排列。南面的墙已经倒塌，但那个方向上一扇上了闩的木门仍然清晰可见。北面的拱门上挂着一幅帘子。
