# 宴会厅

## 一、场景概览
- 场景名称：宴会厅
- 所在地点：克拉摩堡（7 号房间）
- 一句话定位：城堡领主曾在此招待宾客，举办奢华宴会和舞会。如今这地点成了污秽的地精餐厅。
- 场景功能：战斗（地精）

## 二、第一印象
- 这个大型大厅的西部尽头是一堵瓦砾墙，但其余部分仍然完好无损。这里曾经一定是城堡的宴会厅，有着高达二十五英尺的挑高天花板。房间中央摆放着两张大型木桌和普通长凳，角落里放着一个装满炽热煤炭的黄铜火盆。肮脏的餐具、半满的炖锅、发霉的面包头和啃过的骨头覆盖在桌面上。
- 

## 三、可感知信息
- 城堡领主曾在此招待宾客，举办奢华宴会和舞会。如今这地点成了污秽的地精餐厅。
- 这个大厅里有七个可怜的**地精**和它们的首领——一个肥胖暴躁、拥有12点生命值的**地精**，名叫耶格。耶格是裂颅部落的主厨，当他的助手们不情愿地为部落准备食物时，他会残忍地欺负他们。如果耶格被杀，任何幸存的地精都会向
- 如果队伍击败了这个房间里的地精，将400点经验值平均分配给所有角色。
