# 陷阱大厅

## 一、场景概览
- 场景名称：陷阱大厅
- 所在地点：克拉摩堡（2 号房间）
- 一句话定位：这座宽阔的大厅曾是城堡的门厅，如今成为了危险的战场。
- 场景功能：探索

## 二、第一印象
- 北面和南面的门紧闭着，一堆摇摇欲坠的瓦砾部分遮挡了南面的走廊。东面，一条宽阔的走廊尽头有两扇门分别通向南方和东方。走廊上散落着满是灰尘的瓦砾和天花板上部分坍塌掉落的灰泥。

## 三、可感知信息
- 这座宽阔的大厅曾是城堡的门厅，如今成为了危险的战场。
- 如果在area 3的地精哨兵发出了警报，区域4和6的地精和大地精会同时从北门和南门冲出来。他们会从两个方向发起攻击，试图压制冒险者并将他们赶出城堡。
- 通往area 8的门前布满灰尘的石膏和瓦砾中隐藏着一根连接着受难者天花板内暗栓的赤铜绊线。发现这根绊线需要被动感知（察觉）属性值至少达到20，或者如果角色正在主动搜索该区域的陷阱，则需通过一次DC 10的感知（察觉）检定
- 任何生物在不避开绊线的情况下走过或穿过瓦砾会触发木梁和重石的坍塌。（坍塌区域在地图上标出。）当陷阱触发时，区域内的任何生物必须成功通过DC 10的敏捷豁免检定，否则会受到坠落瓦砾造成的3d6钝击伤害（成功通过豁免则伤害减
