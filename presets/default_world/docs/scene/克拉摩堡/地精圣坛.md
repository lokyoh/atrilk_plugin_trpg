# 地精圣坛

## 一、场景概览
- 场景名称：地精圣坛
- 所在地点：克拉摩堡（9 号房间）
- 一句话定位：地精对人类的神明毫无兴趣，因此裂颅部落将此地重新献给了地精与大地精之神马格鲁比耶。
- 场景功能：战斗（地精）

## 二、第一印象
- 这个房间占据了城堡的北塔楼。一座岩石祭坛矗立在房间中央，上面覆盖着血迹斑斑的黑布。金色仪式器具——一个圣杯座、一把刀和1个香炉——被精心摆放在祭坛上。南面的两个拱门覆盖着重型帷幕。
