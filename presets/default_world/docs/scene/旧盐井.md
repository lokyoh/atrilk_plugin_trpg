# 场景详细文档：旧盐井

## 一、场景概览
- 场景名称：旧盐井
- 地点类型：废弃矿盐井 / 地下仓
- 所在位置：盐仓区下方，入口在三号仓地窖
- 一句话定位：账上写着已填，可井里的风一直在吹
- 场景功能：潜入、取证、危险探索

## 二、第一印象
- 视觉：地窖地面掀开一块石板，露出向下的黑井口，井壁有旧的凿痕。
- 听觉：很轻的风声，从下面往上顶。
- 嗅觉：干盐、陈年的汗、还有一点水腥。
- 触觉：井壁粗粝，绳梯的木档被人摸得发滑。
- 整体氛围：这里被封过，但封得不彻底
- 直觉：绳梯是最近换的。

## 三、可感知信息
- 可见物：石板、绳梯、旧矿灯、地上的盐屑。
- 可听声：风、绳梯的吱、偶尔的水滴。
- 可闻味：干盐、汗、水腥。
- 可触物：粗壁、滑木档、脆盐壳。
- 异常之处：盐屑是从井里带上来的，一路洒到地窖门口。
- 动态信息：每隔一会，井底会有一阵风往上涌。

## 四、场景布局
- 整体形状：三层竖井，每层四条横巷。
- 边界与出口：上通三号仓地窖；底层有一条巷通向海。
- 主要区域：第一层平台、第二层旧矿灯位、底层巷口、通海的窄道。
- 通道与路径：绳梯下到第一层；层间凿有踏窝。
- 光线与声音：全黑，风声在巷里拐弯。

## 五、可交互元素
### 元素：三号仓地窖的石板
- 位置：入口
- 状态：掀开一半，边上压着新土
- 操作：盖回去可遮掩行踪，全掀开能放下绳子
- 后果：全掀开时光会漏下去，井里看得见

### 元素：第二层的旧矿灯位
- 位置：第二层南巷
- 状态：有一盏灯还是温的
- 操作：可判断最近有人来过
- 后果：灯油一动，气味会留在巷里

### 元素：通海的窄道
- 位置：底层东北
- 状态：尽头有水声，地上有拖痕
- 操作：可跟随拖痕、可堵住水口
- 后果：堵水口会让上游水位涨

## 六、在场者
### 在场者：搬盐的阿城
- 类型：临时雇工
- 数量：2
- 位置：第一层平台
- 外观：一身盐粉，手上戴着厚麻布手套
- 当前行为：把盐包从横巷搬到竖井底
- 态度：怕，只想拿钱走人
- 可交流性：高，吓一下就全说
- 关联信息：他不知道盐要运去哪，只知道「三号仓的人发钱」

## 七、可能发生的事
### 事件：风涌灭灯
- 条件：在横巷里用明火
- 内容：井底一阵风上来，灯灭，回声把方位搅乱
- 回应空间：原地不动等风过、改用冷光、或顺着风走

### 事件：水口反涌
- 条件：堵住通海窄道
- 内容：底层积水，横巷灌水，盐包溶了一半
- 回应空间：撤到第二层、开另一头、或放弃这批货

## 八、隐藏信息
- 井从来没被填过，「已填」是三年前账上的一句话。
- 底层通海的窄道不是天然塌出来的，是有人特意凿通的：为了从海上运货。
- 井里搬的盐，与沉盐塘那批是同一批货的两个去处。
- 教团说「井底是神的伤口」，是为了让人不要下来看。

## 九、场景变化
- 石板被发现了：三号仓当夜换人，入口改到别处。
- 窄道被打通或堵死：海上的运货路线断一次，下一章会换路子。
- 雇工被吓跑：消息会传到渡口，老鸦陈提前防备。
