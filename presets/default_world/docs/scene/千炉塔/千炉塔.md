# 场景详细文档：千炉塔

## 一、场景概览
- 场景名称：千炉塔
- 地点类型：大型工坊据点
- 所在位置：废炉群北端，九层铁塔
- 一句话定位：这座塔有几层在烧，有几层在装作在烧
- 场景功能：打听、交易、下矿、找线索

## 二、第一印象
- 视觉：九层铁壳在灰雾里发热，每层窗口的亮度都不一样。
- 听觉：风箱的低喘压着一切人声，偶尔一声闷爆。
- 嗅觉：焦炭、热铁、酸洗液三重压迫，近了呛眼。
- 触觉：扶手烫手，铁梯上落着一层温热的灰。
- 整体氛围：所有声音都被炉火盖住，人说话像在密谋
- 直觉：第七层的窗比别处黑。

## 三、可感知信息
- 可见物：铁梯、炉门、吊渣斗、层号铁牌。
- 可听声：风箱、铁锤、传话的小铜铃。
- 可闻味：焦炭、酸洗、汗。
- 可触物：烫扶手、粗铁链、湿炭渣。
- 异常之处：第七层的层号牌被反钉过去；吊渣斗停在三层不动。
- 动态信息：每过一刻钟，三层铃响一次，响完有人换岗。

## 四、场景布局
- 整体形状：正八角，九层，每层四道炉门。
- 边界与出口：底层东门通渣城，北门通灰肺坑渣道。
- 主要区域：底层卸料场、三层调风廊、七层熄火层、九层账房。
- 通道与路径：铁梯上下；渣斗另有一条竖井。
- 光线与声音：低层橙亮高热，越高越暗，七层近乎全黑。

## 五、可交互元素
### 元素：七层层号牌
- 位置：七层铁梯口
- 状态：被反钉，正面朝墙
- 操作：撬开可取下一枚旧标牌，背面刻着炉号与日期
- 后果：撬动会惊动巡层火工

### 元素：停火簿
- 位置：九层账房的铁柜第二格
- 状态：摊着，最后三页被撕
- 操作：带走或被抄录
- 后果：账房一旦发现丢页，全塔会封层查人

### 元素：吊渣斗
- 位置：三层竖井
- 状态：停在半空，斗里是湿渣
- 操作：放下去会直达坑底渣道
- 后果：放斗的响动能传遍三层

## 六、在场者
### 在场者：独眼戚
- 类型：火工头目
- 数量：1
- 位置：七层铁梯口
- 外观：一只眼窝凹陷，围裙被烧出许多小洞
- 当前行为：拎着长钎子逐层锁炉门
- 态度：敌视外人，但对工坊账房有怨
- 可交流性：中；给他「不是来查炉」的台阶才肯开口
- 关联信息：他知道第七层停火是从哪天开始的

### 在场者：巡层火工
- 类型：工坊杂役
- 数量：6，轮班
- 位置：各层铁梯
- 外观：一律短打、戴厚布手套
- 当前行为：换岗、传铃、抬渣
- 态度：麻木，怕扣工钱
- 可交流性：高，给几个铜子就说话
- 关联信息：他们只记得「七层那阵子没人叫铃」

## 七、可能发生的事
### 事件：封层查人
- 条件：被发现动过停火簿
- 内容：底三层同时落闸，火工从下往上搜
- 回应空间：退回渣道、躲进调风廊、或直接找账房对质

### 事件：渣斗下放
- 条件：玩家选择从竖井下去
- 内容：斗到底时撞出一声闷响，坑下有人应了一声
- 回应空间：立刻上去、熄灯听声、或顺着渣道往里

## 八、隐藏信息
- 第七层不是熄火，是被人把风道改接去了九层账房后面的小炉。
- 改风道的活是火工做的，但改炉号的是账房：账上第七层一直在产，产出的铁直接记成九层。
- 三层调的渣里掺着七层的量，所以渣斗停在三层不是坏了，是不敢再往上吊。

## 九、场景变化
- 停火簿被带走：全塔对账，独眼戚被关在七层。
- 玩家给出「不查炉」的说法：独眼戚会带路走一次渣道。
- 塔内落闸：底层东门的闸吏连带被换。
