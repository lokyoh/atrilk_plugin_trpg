# 场景详细文档：渣城

## 一、场景概览
- 场景名称：渣城
- 地点类型：城镇据点（炉都）
- 所在位置：炉心腹地，废炉群裂谷中段，中央大炉四周
- 一句话定位：全境的铁都在这几座炉子里铸出来，炉主不管账，只管铸。
- 场景功能：交涉、买铁、见证铸铁

## 二、第一印象
- 视觉：十几座炉壳连成一片，壳上结着灰白的渣壳，像结了痂的铁。
- 听觉：风箱昼夜不停，鼓风时整条街的地面发颤。
- 嗅觉：硫气呛人，混着铁屑的腥与新铸件的焦味。
- 触觉：地面烫，冬天也烫；铁件一摸就粘手。
- 整体氛围：忙，且响。没人说话，声音太大。
- 直觉：这里的每一笔钱都要先过炉。

## 三、可感知信息
- 可见物：炉壳、风箱、淬火池、堆成山的铁锭、墙上挂的炉主牌。
- 可听声：鼓风、锤击、号子、金属冷却的爆响。
- 可闻味：硫、铁腥、汗、焦炭。
- 可触物：热风、粗糙的锭面、烫手的铁钩。
- 异常之处：三号炉今夜没开火，炉口的余烬是冷的。
- 动态信息：学徒换班，风箱没停。

## 四、场景布局
- 整体形状：环形，中央大炉，街市绕炉一圈。
- 边界与出口：东街通向黑水渠，西巷出裂谷，南门是货运口。
- 主要区域：炉台、料场、淬火池、锤铺。
- 通道与路径：南门—料场—炉台—淬火池—东街。
- 高低差：炉台比街面高三尺，热浪往上翻。
- 遮蔽物：料堆、木板棚、烟囱影。
- 光源分布：炉火为主光，街上有两排油灯。
- 地形特征：地面开裂，裂缝里是暗红的余烬。
- 关键位置：中央大炉、炉主牌、料场账房。

## 五、可交互元素
### 元素：炉主牌
- 类型：记录
- 位置：中央大炉旁的木牌
- 外观：漆字斑驳，只剩「李」字看得清
- 交互方式：细看（调查 DC 12）
- 可能结果：牌上的年号比李砧接任早了四十年
- 关联信息：炉主之名是祖传的
- 隐藏内容：牌背刻着历任炉主的欠账数

### 元素：料场账房
- 类型：记录
- 位置：料场东角
- 外观：半间屋，一本摊开的厚账
- 交互方式：翻账（调查 DC 14）
- 可能结果：出入料数与锭数对不上，差在熔损
- 关联信息：熔损这一栏被人改过
- 隐藏内容：改账的人是李砧的徒弟

### 元素：三号冷炉
- 类型：机关
- 位置：裂谷北侧第三座炉
- 外观：炉口余烬冷透，炉门虚掩
- 交互方式：推炉门（力量 DC 13）
- 可能结果：门后不是炉膛，是一间藏东西的石屋
- 关联信息：这炉的料不登记
- 隐藏内容：石屋里堆着没有票号的铁锭

## 六、在场者
### 在场者：炉主李砧
- 类型：炉主
- 数量：1
- 位置：中央大炉
- 外观：矮壮，两条手臂比常人的腿还粗
- 当前行为：抡锤，一句话不说
- 态度：不谈价，只谈量
- 可交流性：低，得由徒弟传话
- 关联信息：欠着票号三万张

### 在场者：学徒头秦七
- 类型：炉工学徒头
- 数量：1，学徒二十余
- 位置：料场
- 外观：满身烫痕，用疤记年资
- 当前行为：分料，骂人
- 态度：认铁不认票
- 可交流性：中，用铁片换话
- 关联信息：认得哪些锭没登记

### 在场者：票号伙计宋宜
- 类型：票号派驻伙计
- 数量：1
- 位置：炉台外
- 外观：白袖套，抱账匣
- 当前行为：等着交货
- 态度：客气，但寸步不让
- 可交流性：中，需公事由头
- 关联信息：认得几路票号的票

## 七、可能发生的事
### 事件：冷炉里的私铁
- 触发条件：查了三号炉，或与秦七谈拢
- 事件内容：三号炉不烧，是在藏没票号的铁
- 涉及元素：三号冷炉、料场账房
- 涉及在场者：秦七、宋宜
- 可能走向：举报、合伙、抢在封炉前搬走
- 持续时间：到天亮
- 后续影响：炉主与票号彻底翻脸，炉子可能被封

### 事件：撞上封炉
- 触发条件：动过炉主牌或账房
- 事件内容：工坊的人把风箱停了，炉前围满人
- 涉及元素：炉主牌、料场账房
- 涉及在场者：李砧、秦七
- 可能走向：硬闯、认栽、供出幕后
- 持续时间：一夜
- 后续影响：全城铁价停摆，货压三天

## 八、隐藏信息
- 隐藏内容：①三号冷炉是藏私铁的石屋；②熔损一栏被人改过，改账的是李砧的徒弟；③炉主牌背刻历任炉主的欠账，李砧那行是空的
- 隐藏方式：冷炉、涂改的账栏、牌背刻痕
- 发现方式：推炉门（力量 DC 13）；翻账（调查 DC 14）；细看炉主牌（调查 DC 12）
- 发现难度：13 / 14 / 12
- 关联信息：炉心不欠票号的钱，票号却一直压着炉心的货
- 可能影响：可换一大笔铁，也可换来一整城的敌意

## 九、场景变化
- 时间变化：每日三班换风箱，夜里那一班人最少
- 事件变化：封炉后炉前堆满等货的船
- 角色行为变化：帮秦七说话，他会让你看账房
- 在场者变化：封炉后宋宜带人撤走，炉前只剩工坊的人
- 环境变化：三号炉重新点火后，整条街热到脱衣
- 状态变化：私铁被搬空后，石屋会被人翻一遍
