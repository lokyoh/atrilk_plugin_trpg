# 场景详细文档：磨盘镇

## 一、场景概览
- 场景名称：磨盘镇
- 地点类型：台原小镇 / 补给据点
- 所在位置：万人磨盘四周，向东散开
- 一句话定位：整镇靠一块石头吃饭，石头底下的账没人敢翻
- 场景功能：补给、打听、起点

## 二、第一印象
- 视觉：灰白的石屋挤成一圈，中央那块磨盘像一枚被放大的钱。
- 听觉：磨石转动时全镇都在嗡，停下时安静得反常。
- 嗅觉：石灰、面粉、牲口味。
- 触觉：墙上落的粉一摸一手，风一过又白回来。
- 整体氛围：所有事都按磨盘的节拍走
- 直觉：磨盘停过。

## 三、可感知信息
- 可见物：磨盘、拉磨的牲口、粮仓、石屋的矮门。
- 可听声：磨石、牲口铃、掌磨人的短喝。
- 可闻味：石灰、麦粉、汗。
- 可触物：粉墙、铁磨轴、粗麻袋。
- 异常之处：磨盘边缘新嵌了一圈铁楔，是最近加的。
- 动态信息：每转满一百圈，掌磨人会敲一下铜片记数。

## 四、场景布局
- 整体形状：以磨盘为心的环形镇，三条街向外岔开。
- 边界与出口：东街出台原，北街通七十二眼，南街下盐碱河床。
- 主要区域：磨盘台、粮仓院、掌磨人屋、北街口。
- 通道与路径：环街绕磨盘一圈；北街尽头有一道石栅。
- 光线与声音：台原日照平，正午无影。

## 五、可交互元素
### 元素：磨盘铁楔
- 位置：磨盘外缘
- 状态：新嵌，楔口还有毛刺
- 操作：可拔出，看楔下压着的旧刻痕
- 后果：拔楔会让磨盘失衡，当日全镇停工

### 元素：粮仓院
- 位置：镇西
- 状态：门锁着，锁是新的
- 操作：可撬、可问钥匙在谁身上
- 后果：撬锁会被当作贼，镇上会围人

### 元素：北街石栅
- 位置：北街尽头
- 状态：落下，栅上挂着干草束
- 操作：抬起可通七十二眼
- 后果：抬栅要两个人，声音传得远

## 六、在场者
### 在场者：掌磨人老砚
- 类型：镇上掌磨的师傅
- 数量：1
- 位置：磨盘台
- 外观：一身白粉，只有眼周是干净的
- 当前行为：盯着磨盘听声，不时敲铜片
- 态度：客套但戒备，尤其是问铁楔
- 可交流性：中；先夸磨盘再问
- 关联信息：铁楔是他让人嵌的，因为磨盘「听了不该听的声」

### 在场者：磨坊伙计
- 类型：镇民
- 数量：5
- 位置：磨盘台周围
- 外观：短褂、布鞋、手上全是粉
- 当前行为：填料、扫粉、赶牲口
- 态度：话多，爱传闲话
- 可交流性：高
- 关联信息：他们说北边天坑夜里会有「敲东西」的声，和磨盘一样

## 七、可能发生的事
### 事件：磨盘停工
- 条件：拔楔或伤到磨轴
- 内容：全镇人聚到磨盘台，要求照「停工一日赔一日」的旧例处理
- 回应空间：赔钱、替他们转磨、或找出「磨盘本来就要停」的证据

### 事件：夜里的敲声
- 条件：入夜后留在镇上
- 内容：北面天坑传来规律敲击，鼓点与白日磨盘一致
- 回应空间：立刻去北街、找老砚问、或等到没声

## 八、隐藏信息
- 磨盘底下压着一条向下的旧竖井——七十二眼之一，被当成地基用了。
- 铁楔不是为了加固，是为了让磨盘压得更死，不再「响」。
- 敲声是井底的人在按磨盘的节拍发信号，节拍就是他们约定的暗号。
- 粮仓锁着的原因不是防贼，是里面存的不是粮。

## 九、场景变化
- 磨盘停工：镇上停市，玩家会被要求赔，或被当成惹事的人记住。
- 铁楔被拔：磨盘重新「响」，井底的敲声连夜变了节拍。
- 北街石栅抬起：通往七十二眼的路打开，但镇民会知道是谁抬的。
