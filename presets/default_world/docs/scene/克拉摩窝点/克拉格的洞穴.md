# 克拉格的洞穴

## 一、场景概览
- 场景名称：克拉格的洞穴
- 所在地点：克拉摩窝点（8 号房间）
- 一句话定位：类地精的首领坚持将掠夺者的大部分赃物留在自己的巢穴中。克拉摩帮派上个月袭击和伏击商队所得的掠夺品都在这里。
- 场景功能：战斗（熊地精、地精、狼）

## 二、第一印象
- 掠夺来的物资袋子和板条箱堆积在这个大型洞穴的南端。向西，地面向一个狭窄的开口倾斜，通向黑暗。一个更大的开口向北延伸，沿着一组天然岩石台阶向下，坠落水流的咆哮声从远处传来。在洞窟中央，一堆大火的余烬在闷烧。
