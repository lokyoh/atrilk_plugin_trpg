# 场景详细文档：盐霜原刮盐场

## 一、场景概览
- 场景名称：盐霜原刮盐场
- 地点类型：露天盐场据点
- 所在位置：盐霜原中部，靠盐泉
- 一句话定位：池子里的盐是真的，账上的盐是另一个数
- 场景功能：调查、交涉、取证

## 二、第一印象
- 视觉：一片被刮出白痕的冻土，几十口浅池排成棋盘，池边插着编号木牌。
- 听觉：铁刮板刮过盐壳的沙沙声，像有人在不停磨牙。
- 嗅觉：咸得发苦的冷空气，混一点盐泉的硫味。
- 触觉：盐壳割手，池边的木牌冻得粘手。
- 整体氛围：所有人都在忙，但没人往七号池那边看
- 直觉：七号池今天不该是这个样。

## 三、可感知信息
- 可见物：浅池、刮板、编号木牌、堆盐的草包。
- 可听声：刮板、风、盐泉的咕嘟。
- 可闻味：咸、硫、冻土。
- 可触物：脆盐壳、湿草包、冻硬的绳。
- 异常之处：七号池的盐壳被人重新压过，边上有新脚印。
- 动态信息：日落后盐工会把池口的草帘放下。

## 四、场景布局
- 整体形状：不规则长方形，池子按七行四列排开。
- 边界与出口：北面是盐泉，南面接通往霜牙岭哨站的雪道。
- 主要区域：盐泉口、七号池、堆盐场、池租棚。
- 通道与路径：池埂纵横，宽处两人并行。
- 光线与声音：高原日照强，正午反光刺眼。

## 五、可交互元素
### 元素：七号池
- 位置：池阵西北角
- 状态：盐壳被重新压过，下面垫着东西
- 操作：破壳可挖出用草包埋的私盐
- 后果：破壳动静大，池租棚能听见

### 元素：池租棚
- 位置：堆盐场旁
- 状态：门虚掩，桌上摊着半本池册
- 操作：可翻阅、可带走
- 后果：带走池册会让副管事连夜报官

### 元素：盐泉口
- 位置：场北
- 状态：结着白霜的石缝，水还在冒
- 操作：可取水、可查看谁最近来打过水
- 后果：无

## 六、在场者
### 在场者：巴音
- 类型：盐场副管事
- 数量：1
- 位置：池租棚
- 外观：皮袍袖口磨得发白，手指常年裂口
- 当前行为：把池册一页页对着日照看
- 态度：客气，但每句话都留半句
- 可交流性：中；提到「死掉的管事」会僵住
- 关联信息：他知道管事死前在查哪一口池

### 在场者：刮盐工
- 类型：盐场雇工
- 数量：9
- 位置：各池埂
- 外观：脸和手套都糊着盐，眉毛结霜
- 当前行为：刮盐、压壳、抬草包
- 态度：不愿惹事，怕扣口粮
- 可交流性：高，但只肯说「七号池不归我们管」
- 关联信息：他们记得管事死那晚有人在池埂上走

## 七、可能发生的事
### 事件：连夜报官
- 条件：池册被带走且被发现
- 内容：副管事带两个盐丁追上雪道，一路咬定「外人偷册」
- 回应空间：还册换话、在半路谈条件、或直接跑

### 事件：盐壳崩塌
- 条件：多人同时踩上七号池边
- 内容：池底冻土塌下一层，埋住一半私盐
- 回应空间：抢挖、放弃、或反过来指控别人埋的

## 八、隐藏信息
- 死掉的管事不是冻死的，是被人按在七号池里呛了卤水。
- 七号池底下埋的私盐数量，正好等于账上「损耗」三年的总和。
- 副管事手里的池册是抄本，正本在誓骨窟的盐袋里一起藏着。

## 九、场景变化
- 池册被动过：副管事会把七号池重新填平。
- 巴音松口：他会给一条去誓骨窟的暗路，但要求「别把我写进账」。
- 私盐被起出：盐场会被王国派员接管，池租棚换人。
