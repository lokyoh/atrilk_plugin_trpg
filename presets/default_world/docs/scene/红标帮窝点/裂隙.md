# 裂隙

## 一、场景概览
- 场景名称：裂隙
- 所在地点：红标帮窝点（8 号房间）
- 一句话定位：角色们可以通过三条路线之一到达这里：来自area 1的隧道、area 7的储藏室，或是向南延伸的粗凿通道，这条通道在地图上继续延伸约一百英尺…
- 场景功能：战斗（诺斯怪）

## 二、第一印象
- 一阵冷风充满了这个大型天然洞窟，带着淡淡的腐烂血肉气味。一道裂隙将洞窟一分为二，两侧各有一根粗糙的岩石柱支撑着二十尺高的天花板。两座拱形木桥横跨深坑。

## 三、可感知信息
- 角色们可以通过三条路线之一到达这里：来自area 1的隧道、area 7的储藏室，或是向南延伸的粗凿通道，这条通道在地图上继续延伸约一百英尺，从崔森德庄园南面树林中的一个隧道出现。这条通道是偷偷将人或商品运入和运出凡达林
- 这个洞穴的守护者是一只**诺斯怪**，一种渴望血肉的疯狂地下怪物。这只生物被裂隙中散发出的微弱魔法效应所吸引，在红标帮进驻时就已占据该区域。伊阿诺设法与怪物达成协议，说服它协助守卫要塞以换取宝藏和偶尔的新鲜肉食馈赠。然而
