# 公共休息室

## 一、场景概览
- 场景名称：公共休息室
- 所在地点：红标帮窝点（10 号房间）
- 一句话定位：该区域作为红标帮的总部和会议室使用。当没有正式事务需要讨论时，这里会兼作警卫们下岗时休息的公共休息室。
- 场景功能：探索（红标帮恶霸）

## 二、第一印象
- 这个大型房间里散落着几张破旧的桌子和椅子。木制长凳靠着装饰有棕色和红色帷幔的墙壁摆放，几个麦芽酒桶被支起并打开了龙头。

- 四个看起来健壮的人类战士穿着猩红斗篷围坐在一张桌子旁。一堆钱币和饰品堆在他们之间的桌面上。
