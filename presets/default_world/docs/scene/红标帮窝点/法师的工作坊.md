# 法师的工作坊

## 一、场景概览
- 场景名称：法师的工作坊
- 所在地点：红标帮窝点（11 号房间）
- 一句话定位：通过成功的DC 15感知（察觉）检定，可以听到这个房间的任一扇门外传来微弱的气泡声和滴水声。
- 场景功能：探索

## 二、第一印象
- 这个房间看起来像是一个法师的工坊。一只老鼠在地板上匆匆跑过，躲在一张大型工作台下，工作台上摆满了蒸馏器、曲颈瓶、蒸馏管和其他炼金设备，所有这些东西都在沸腾冒泡。书架上堆满了羊皮纸卷和看起来很奇怪的大部头书籍。

## 三、可感知信息
- 通过成功的DC 15感知（察觉）检定，可以听到这个房间的任一扇门外传来微弱的气泡声和滴水声。
- 伊阿诺将他的老鼠魔宠留在此处监视入侵者。这只老鼠与其大师有着传念联结，一旦发现入侵者就会立即向伊阿诺发送简短警告传讯。老鼠的速度为20尺，护甲等级10，生命值1点，且没有有效攻击手段。如果老鼠被杀死，它会消失。
- 如果角色们没有伤害这只老鼠，它会像出于好奇或饥饿一样跟着他们。它甚至可能假装对喂食它的角色表示好感，尽管它仍然绝对忠诚于伊阿诺。
- 伊阿诺正试图掌握酿造药水和配制炼金混合物的技艺。散落在房间各处的书籍和笔记是关于炼金术的基础文本。任何精通奥秘技能的角色都能看出伊阿诺的装置似乎是为了酿造*隐形药水*而设置的，不过他目前尚未成功。
