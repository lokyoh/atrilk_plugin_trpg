# 兽人营地

## 一、场景概览
- 场景名称：兽人营地
- 所在地点：飞龙突岩
- 一句话定位：这座突岩是剑山东北部崎岖丘陵中显著的地标，从二十英里外就能轻易看到。沿着三猪小径旅行的人们在康尼贝里附近行进时，会瞥见南方的飞龙突岩。这里曾…
- 场景功能：战斗（食人魔、兽人）

## 二、第一印象
- 当你爬上丘陵下坡处崎岖的山脊时，空气中飘荡着淡淡的烟味。五十码外，一个洞穴口在峡谷底部张开。在洞穴外二十码处的巨石旁蹲伏着一名独自守卫的兽人。

## 三、可感知信息
- 这座突岩是剑山东北部崎岖丘陵中显著的地标，从二十英里外就能轻易看到。沿着三猪小径旅行的人们在康尼贝里附近行进时，会瞥见南方的飞龙突岩。这里曾是一大群危险飞龙的巢穴，但多年前一队勇敢的冒险者解决了这些怪物。虽然飞龙再未归来
- 这些兽人是无常者箭矢部落的斥候。这些兽人经常游荡到北方更文明的区域，侦察人类聚居地，伏击旅人，并在机会出现时进行掠夺和抢劫。关于凡达林附近新定居者和古老的三猪小径上交通恢复的故事吸引了这群兽人来到该区域。他们的首领是布鲁
- 飞龙突岩是一座巨大的丘陵，其两侧和斜坡上延伸着数英里的崎岖地形。寻找隐藏的兽人营地需要时间。队伍每小时可以尝试进行一次DC 15感知（察觉）检定或DC 10感知（求生）检定来寻找营地，由领路的角色进行检定。
- 如果角色们能悄无声息且迅速地解决掉那个落单的**兽人**，他们就有机会对洞穴中的兽人们发动突袭。如果哨兵发现了潜行接近的角色，或是在突袭轮中未被沉默，这个兽人就会退回洞穴警告其他同伴。
