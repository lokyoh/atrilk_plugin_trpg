# 灰岩原

## 一、地区概览
- 地区名称：灰岩原
- 大致形状：西北一片被风削平的灰白台原，方正得像块案板，边缘碎成一级一级的台阶。
- 主要地形：石灰岩台地、天坑群、干涸的盐碱河床，地表水极少，凿井要凿到四十步深。
- 国都：磨盘镇。围着万人磨盘建的采石镇，没有城墙，只有三道石栅和七口水井。
- 特殊地区：「七十二眼」天坑群。坑底有冷泉与旧王朝库房的残迹，绳索不够长的人下不去。
- 当前政治局势：七个采石行会轮流坐庄；熔渣渠低价收石，白港高价卖盐，两头欠账，行会攥着三张未兑盐票。
- 在世界推力中的位置：石与粮道的出处，也是全境最认契约的地方。盐价一动，原上最先受不住。

## 二、详细地形分布

### 子区域：石台地
- 位置范围：台原主体，东西四十里、南北三十里。
- 地形类型：石灰岩台地。
- 海拔与地势：高出盐道走廊百丈，顶面近乎水平。
- 气候特征：风硬，昼夜温差大。
- 主要地貌：石芽、采石阶、石栅。
- 水源分布：七口深井，凿到四十步才见水。
- 与周边子区域的过渡：东缘碎成台阶落入盐道走廊，北接天坑群。
- 交通难度：石面平，车可行，唯无水处难宿。

### 子区域：天坑群
- 位置范围：台原北缘，方圆八里。
- 地形类型：塌陷漏斗群。
- 海拔与地势：坑口直径三到三十步不等，深不见底。
- 气候特征：坑底比地面凉，积雾不散。
- 主要地貌：竖井、石桥、旧库房残墙。
- 水源分布：坑底冷泉两眼，绳不够长取不到。
- 与周边子区域的过渡：由石台地边缘忽然陷落，无缓坡。
- 交通难度：绕行半日，下坑需绳与绞盘。

### 子区域：盐碱河床
- 位置范围：台原东南，一条干涸的旧河道。
- 地形类型：干涸盐碱河床。
- 海拔与地势：低于台面二十丈，宽阔平坦。
- 气候特征：盐霜泛白，风一起白茫茫。
- 主要地貌：龟裂泥壳、盐壳、旧桥墩。
- 水源分布：雨季过水，其余时候只余咸洼。
- 与周边子区域的过渡：东南缓降，接盐道走廊入白港。
- 交通难度：最好走，也是盐车唯一的路。

## 三、城镇据点

### 据点：万人磨盘
- 据点类型：地标兼行会公堂。
- 地理位置：台原中央，磨盘镇围着它建。
- 面积：磨盘直径三十步，盘面即是公堂。
- 人口：无常驻，断案日聚数百。
- 势力归属：七行会共认，谁坐庄谁主断。
- 势力结构：断案时七行会各出一席，坐庄行会坐盘心。
- 经济基础：断案费、契约存底、罚没的石料。
- 军事力量：无建制，行会各带石工，一呼数百。
- 与周边的关系：熔渣渠的石价与白港的盐价都在这儿被记成契约。
- 特殊之处：旧王朝碾盐用，如今碾的是账；盘心刻着旧斗数，行会断案仍照它。

### 据点：磨盘镇
- 据点类型：国都，采石镇。
- 地理位置：万人磨盘四周，向东散开。
- 面积：百二十亩，三道石栅。
- 人口：三千六百，石工占半。
- 势力归属：七行会轮流坐庄，一季一换。
- 势力结构：行会各领一片采区，井由行会共管。
- 经济基础：石料、石粉、井水、契约。
- 军事力量：无兵，只有护井队三十，持撬棍与石斧。
- 与周边的关系：石卖给熔渣渠，盐买白港的，两头都被欠。
- 特殊之处：没有城墙，只有三道石栅和七口水井；嫁女陪一口井，比陪钱体面。

### 据点：盐道走廊石廊站
- 据点类型：盐道上的补给站。
- 地理位置：东南缘，盐道走廊入原处。
- 面积：六亩，石屋一圈。
- 人口：常住六十，车夫往来不计。
- 势力归属：行会共管，站头由坐庄行会派。
- 势力结构：站头一人、脚夫二十、护井两人。
- 经济基础：宿、水、换牲口。
- 军事力量：无，靠盐车自带的护卫。
- 与周边的关系：白港的盐车从这儿进，原上的石车从这儿出。
- 特殊之处：走廊无险，谁都拦得住——所以行会从来不在这儿谈价，只在这儿数车。

## 四、地形地貌生态

### 子区域：石台地
- 植被类型：石生苔与稀草。
- 主要植物：石苔、岩艾、刺草。
- 主要动物：石鼠、岩鸽。
- 魔物分布：石背蜥，伏在石缝里晒太阳。
- 生态链：石苔—石鼠—岩鸽。
- 季节变化：冬落灰，石面滑；夏晒，正午无人上工。
- 资源产出：石料、石粉、井水。
- 生态威胁：井枯、塌方、石崩。
- 与人文的关系：采石人以「一斗盐换一车石」记账，认契约不认人。

### 子区域：盐碱河床
- 植被类型：盐生草与碱蓬。
- 主要植物：碱蓬、盐蒿、白刺。
- 主要动物：盐鸦、滩蟹。
- 魔物分布：盐壳下的钻沙虫，踩破壳才现身。
- 生态链：碱蓬—滩蟹—盐鸦。
- 季节变化：雨季过水，其余时候泛白。
- 资源产出：碱、盐霜、硝。
- 生态威胁：钻沙虫、盐雾伤眼。
- 与人文的关系：河床是路也是盐，穷户刮碱卖，够买半斗盐。

## 五、地下城与魔物分布

### 地下城：七十二眼
- 位置：台原北缘天坑群，最大一眼的坑底。
- 类型：塌陷竖井群与旧王朝库房。
- 简介：旧王朝在坑底存盐与账，塌后无人下去，只有绳索够长的行会偶尔取物。
- 结构：主井七十二步，横巷四条，一巷通旧库房，一巷通冷泉。
- 魔物分布：白蛭、石化的旧库吏、钻沙虫巢。
- 陷阱与机关：朽绞盘、塌井、旧库房的落石闸。
- 宝藏与资源：旧王朝盐引、未兑的旧契约、冷泉。
- 势力介入：行会把库房当契约存档处；白港派人来抄过一次名录。
- 危险等级：中偏高。

## 六、与周边地区的衔接

### 熔渣渠
- 边界地形过渡：南缘焦渣岭一路抬升，灰白台原转为矿渣陡坡。
- 生态变化：石生苔绝迹，耐硫苔与锈草上来。
- 交通线与关隘：运石索道，日夜运石；石价由行会定，铁价由工坊定。
- 人文与政治互动：工坊低价收石，行会攥着三张未兑盐票，谁先兑谁吃亏。

### 白港
- 边界地形过渡：东南沿盐碱河床缓降，台原落为盐田与滩涂。
- 生态变化：石鼠岩鸽不见，盐鸦与滩蟹上来，水多了。
- 交通线与关隘：盐道走廊，无险，三处水源站。
- 人文与政治互动：白港高价卖盐，石工欠盐债，公会借此压石价；走廊一断，原上先断粮。
