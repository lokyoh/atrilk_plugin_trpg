# 盐沼渡

## 一、地区概览
- 地区名称：盐沼渡
- 大致形状：东南一小片被水道切碎的沼泽三角洲，地图上只有指甲盖大，却卡着两条水路。
- 主要地形：咸水沼泽、芦苇荡、可通平底船的潮沟，涨潮时四成陆地消失。
- 国都：无都城，只有浮村「桩上」，四百口人住在打桩的平台上。
- 特殊地区：沉盐塘。旧盐仓沉没处，水下还捞得到结块盐砖。
- 当前政治局势：五条船帮靠分账维系，头目阮九娘握着白港三名税吏的账，公会几次清剿都中途收手。
- 在世界推力中的位置：水路的闸门。真盐、私盐、货与消息都从这儿过，谁握桩谁定价。

## 二、详细地形分布

### 子区域：芦苇荡
- 位置范围：三角洲外缘，环一圈约十五里。
- 地形类型：咸水芦苇荡。
- 海拔与地势：与潮位齐平，涨潮即没。
- 气候特征：闷湿，蚊虫成团。
- 主要地貌：苇墙、泥滩、鸟巢。
- 水源分布：全境都是水，淡水靠接雨。
- 与周边子区域的过渡：向内渐深为潮沟，向外出海口散为沙洲。
- 交通难度：只通平底船，认得水路才敢走。

### 子区域：潮沟
- 位置范围：三条主水道，交汇于三岔桩。
- 地形类型：潮汐通道。
- 海拔与地势：深一丈到三丈，随潮涨落。
- 气候特征：一日两涨落，落时见泥。
- 主要地貌：分水口、暗桩、沉船。
- 水源分布：咸淡交汇，盐度一日三变。
- 与周边子区域的过渡：上溯通盐霜河，下流出海，西接泥渡栈道。
- 交通难度：涨潮行船，落潮走泥，错一时辰就得等半天。

### 子区域：泥渡栈道
- 位置范围：西出三角洲，通往灰烬台。
- 地形类型：半没水的木栈道。
- 海拔与地势：栈面高泥面三尺，半数泡在水里。
- 气候特征：雾重，栈木终年湿。
- 主要地貌：朽桩、断板、浮屋。
- 水源分布：无淡水，靠船送。
- 与周边子区域的过渡：东接潮沟，西端抬升为灰烬台的泥岸。
- 交通难度：单人可行，驮货要等落潮，断板处须绕。

## 三、城镇据点

### 据点：三岔桩
- 据点类型：分水口交割处，桩即是账房。
- 地理位置：三条潮沟交汇，一根黑木桩立在水中央。
- 面积：桩周水面半亩，岸上棚屋三间。
- 人口：常住二十，交割日逾百。
- 势力归属：五船帮共认，谁也不许独占。
- 势力结构：桩首一人（轮流），五帮各派一记账人。
- 经济基础：交割抽头、押金、卖消息。
- 军事力量：无建制，五帮各带十来条船，打起来就是水战。
- 与周边的关系：只认桩不认旗；白港的税吏来查过账，回去后三人的名字都上了桩。
- 特殊之处：欠债的把名字刻上桩，还清才刮掉；桩上刻得最深的三个名字，正是白港那三名税吏。

### 据点：桩上
- 据点类型：浮村，四百口人住在打桩的平台上。
- 地理位置：潮沟北岸，三岔桩上游二里。
- 面积：平台三十七座，用板桥连。
- 人口：四百一十，八姓共居。
- 势力归属：五船帮混居，阮九娘说话最算数。
- 势力结构：八姓各推一老，老中推一「桩老」。
- 经济基础：打鱼、运货、刮盐、领港。
- 军事力量：无兵，家家有鱼叉与短刀，妇女也会摇船冲撞。
- 与周边的关系：与霜牙岭换皮货，替走私客藏货，被公会通缉却从未被清掉。
- 特殊之处：通行靠一句「潮退三分」，答错的就是外来的；涨潮时整村浮起来半尺。

### 据点：泥渡栈道口
- 据点类型：栈道头的换货棚。
- 地理位置：泥渡栈道东端，接潮沟。
- 面积：三亩，一半泡水。
- 人口：常住三十五，多为船夫与挑夫。
- 势力归属：五船帮共管，教团近日常来设站。
- 势力结构：棚头一人、挑夫二十、教团执事偶尔驻两人。
- 经济基础：换货、挑运、卖符。
- 军事力量：无，只有看棚的两条狗。
- 与周边的关系：往西是灰烬台的泥岸，往东是三岔桩，谁设站谁收盐。
- 特殊之处：教团的人近常来栈道口化缘，船帮不拦也不帮；栈道断一次，水路就误一日。

## 四、地形地貌生态

### 子区域：芦苇荡
- 植被类型：芦苇与咸水草。
- 主要植物：芦苇、咸草、水蓼。
- 主要动物：水鸟、滩蟹、水蛇。
- 魔物分布：沼泽蛰蛇，藏在苇根，咬了不疼只麻。
- 生态链：咸草—滩蟹—水鸟；苇根—水蛇。
- 季节变化：涨潮四成陆地消失，退潮见泥路。
- 资源产出：芦苇、鱼、蟹、盐霜。
- 生态威胁：涨潮迷路、蛰蛇、疟气。
- 与人文的关系：芦苇能编席能盖顶，也是藏船最好的地方。

### 子区域：潮沟
- 植被类型：水下藻与浮萍。
- 主要植物：绿藻、浮萍、咸水苔。
- 主要动物：鲻鱼、白虾、水獭。
- 魔物分布：沟底白蛭，落水即附。
- 生态链：藻—白虾—鲻鱼—水獭。
- 季节变化：冬水咸，鱼往上游；夏水暖，白蛭最凶。
- 资源产出：鱼虾、盐卤、冲上来的沉货。
- 生态威胁：白蛭、暗桩、潮水卷人。
- 与人文的关系：船帮按潮记时，「潮退三分」就是开门的口令。

## 五、地下城与魔物分布

### 地下城：沉盐塘
- 位置：旧盐仓沉没处，潮沟西侧水下。
- 类型：沉没的盐仓与窖。
- 简介：三十年前大潮一夜沉了仓，账上写「全损」，水下盐砖还在。
- 结构：仓房三间半埋泥中，一窖门可开，一窖已塌。
- 魔物分布：白蛭巢、守着盐砖的沉尸。
- 陷阱与机关：塌窖、泥陷、退潮时的急流。
- 宝藏与资源：结块盐砖数千、沉仓旧账、锈死的仓印。
- 势力介入：船帮按潮下去搬，公会只当不知道；教团说这是「神沉下的赎罪物」。
- 危险等级：中（退潮可下，涨潮必死）。

## 六、与周边地区的衔接

### 霜牙岭
- 边界地形过渡：北面盐霜河出山，冻土让位淤泥与芦苇。
- 生态变化：霜狼雪隼不见，水鸟与滩蟹上来。
- 交通线与关隘：盐霜河，只通平底船，冰期可涉。
- 人文与政治互动：船帮用盐换皮货，部盟南下时这里就是他们的水道。

### 灰烬台
- 边界地形过渡：西面泥渡栈道，栈木半泡水，尽头是覆灰的泥岸。
- 生态变化：芦苇渐稀，灰蛾进来，水变涩。
- 交通线与关隘：泥渡栈道，单人可行，断板须绕。
- 人文与政治互动：教团沿栈道口设点劝捐收「净心钱」，走私客照走不误；点设一次，盐运就慢三日。
