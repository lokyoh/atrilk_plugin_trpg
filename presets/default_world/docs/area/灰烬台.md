# 灰烬台

## 一、地区概览
- 地区名称：灰烬台
- 大致形状：中部一块被灰烬覆盖的高台，四周是缓坡，从远处看像一只倒扣的黑碗。
- 主要地形：灰烬台地、年年加深的灰沟、被灰埋掉半截的旧城基，落灰最厚处能没到膝盖。
- 国都：灰台城。环天罚柱而建，屋顶全做成斜面好让灰滑落，街上每十步有一口刮灰的槽。
- 特殊地区：落灰带。常年落灰的无人区，走一日要换三次滤布。
- 当前政治局势：大祭司竺无咎称灰是神罚、盐是赎罪之物，向白港索「灰税」；守灰军的军械出自熔渣工坊。
- 在世界推力中的位置：人心的一半。教团握着解释落灰的那套话，灰税与赎罪盐都从这句话里来。

## 二、详细地形分布

### 子区域：台心
- 位置范围：高台正中，方圆二里。
- 地形类型：被踩实的灰壳地。
- 海拔与地势：全境最高，中央再起九级殿阶。
- 气候特征：风自台心向外吹，灰不积在柱下而积成环。
- 主要地貌：天罚柱、殿阶、环灰。
- 水源分布：无地表水，靠城北引灰水滤三遍。
- 与周边子区域的过渡：向四周缓降，灰由薄变厚。
- 交通难度：无遮无拦，风起三步不见人。

### 子区域：灰沟
- 位置范围：自台心放射的七条深沟，最长十二里。
- 地形类型：被灰水冲出的沟壑。
- 海拔与地势：沟深一到三丈，年年加深。
- 气候特征：沟里闷，灰面浮着一层壳。
- 主要地貌：沟桥、灰瀑、半埋的旧城基。
- 水源分布：雨季过灰水，其余时候干。
- 与周边子区域的过渡：沟间是台地，沟尾散入落灰带。
- 交通难度：只能走桥，桥面一落灰就滑。

### 子区域：落灰带
- 位置范围：台地外缘一圈，宽五到十里不等。
- 地形类型：常年落灰的无人区。
- 海拔与地势：缓缓向外降，灰没到膝盖。
- 气候特征：无风也落灰，滤布一时辰即堵。
- 主要地貌：灰丘、埋掉的旧路、露出的屋脊。
- 水源分布：无，露水也带灰。
- 与周边子区域的过渡：向外渐薄，接白港盐田与盐沼渡泥岸。
- 交通难度：走一日要换三次滤布，无滤布三日咳血。

## 三、城镇据点

### 据点：灰烬台圣灰广场
- 据点类型：城镇据点（广场），朝圣与交易的实际中心。
- 地理位置：灰台城内城，圣殿前，殿阶下九级。
- 面积：圆场约六亩，四面回廊。
- 人口：常住百余，朝圣日逾千。
- 势力归属：灰烬教团直辖，灰卫日夜巡。
- 势力结构：净灰执事三人轮值、灰卫十二、香市由教团抽头。
- 经济基础：赎罪盐、香市、捐灰、记名的愿牌。
- 军事力量：灰卫十二人，持杖与短刀，可召守灰军一哨。
- 与周边的关系：白港斥之为赎罪券，教团反指公会卖的盐不净；互设禁售，货却照走。
- 特殊之处：像肩不落灰，池水浮油；愿墙上有同一个名字写了十七次，牌背刻着白港仓号。

### 据点：灰台城
- 据点类型：国都，环柱而建的城。
- 地理位置：台心四周，环天罚柱一圈。
- 面积：四百亩，环城两道。
- 人口：一万一千，教士与灰工占三成。
- 势力归属：教团独掌，大祭司竺无咎。
- 势力结构：大祭司—执事—灰卫三级，行会只剩刮灰与滤布两行。
- 经济基础：灰税、赎罪盐、朝圣捐、守灰军的军械津贴。
- 军事力量：守灰军八百，持矛与短铳，军械出自熔渣工坊。
- 与周边的关系：向白港索灰税，向熔渣渠买刀，与霜牙岭萨满的旧约已裂。
- 特殊之处：屋顶全做成斜面好让灰滑落，街上每十步有一口刮灰的槽；晨昏敲灰钟，钟响须停步低头。

### 据点：灰门
- 据点类型：南向关城，白港来路。
- 地理位置：台地南缘，出落灰带即灰烬关。
- 面积：二十亩，石关一道。
- 人口：常住二百，朝圣季增一倍。
- 势力归属：教团守南门，公会派十人共守。
- 势力结构：教团关尹一人、守灰军一哨，公会验票员十人。
- 经济基础：入城捐、验票、滤布与刮灰具。
- 军事力量：守灰军一哨百人，公会十人只管票不管刀。
- 与周边的关系：朝圣队从此入，盐车也从此入，两边各扣过对方的货。
- 特殊之处：关门两侧覆灰，越东越厚；教团在关口设点收捐，过关的盐车与朝圣者都得停一次。

## 四、地形地貌生态

### 子区域：落灰带
- 植被类型：几乎无，只有灰下枯根。
- 主要植物：灰藓、耐灰的硬草。
- 主要动物：灰蛾、灰鼠、灰下的虫。
- 魔物分布：灰行者（埋在灰下的旧城居民），风起时立起来。
- 生态链：灰藓—灰虫—灰蛾；灰鼠吃虫，灰行者吃活物。
- 季节变化：秋冬落得最厚，春夏稍薄。
- 资源产出：圣灰（教团专用）、旧城遗物。
- 生态威胁：灰肺、迷路、灰行者。
- 与人文的关系：走一日换三次滤布；教团说灰是神罚，灰工说灰是活计。

### 子区域：灰沟
- 植被类型：沟壁的灰苔。
- 主要植物：灰苔、沟边硬草。
- 主要动物：灰鼠、沟鸦。
- 魔物分布：沟底灰蟒，吞过整支朝圣队。
- 生态链：灰苔—灰虫—沟鸦；灰蟒居顶。
- 季节变化：雨季成灰水，旱季见半埋的旧城基。
- 资源产出：旧城砖、埋掉的旧器、沟底细灰。
- 生态威胁：沟蟒、塌灰、桥断。
- 与人文的关系：刮灰工沿沟作业，挖出旧王朝的东西要上交，私下卖的也不少。

## 五、地下城与魔物分布

### 地下城：圣殿地窖
- 位置：圣殿之下，圣像基座的风口通进去。
- 类型：教团的地下库房与净灰池的排水层。
- 简介：账上写「藏灰处」，实际存着历年赎罪盐与不愿见光的名册。
- 结构：前厅一、库房三、最深一间通旧城下水道。
- 魔物分布：灰行者、守窖的哑仆（活人，从小养在地窖里）。
- 陷阱与机关：风口闸门、落灰口、名册房的火槽。
- 宝藏与资源：历年赎罪盐、教团名册、白港仓号对照表。
- 势力介入：教团独占；公会雇过人下去，没出来。
- 危险等级：高。

## 六、与周边地区的衔接

### 熔渣渠
- 边界地形过渡：西南越断炉隘口下坡，浮灰渐薄，露出焦渣与炉烟。
- 生态变化：灰蛾让位铁喙鸦，灰下活物换成熟硫的虫。
- 交通线与关隘：断炉隘口，守灰军的军械从此过，两边各派一人共守。
- 人文与政治互动：教团要军械，工坊要订单；军械一断，守灰军先散。

### 霜牙岭
- 边界地形过渡：北沿灰风谷上行，灰渐薄，冻土露头。
- 生态变化：灰藓退去，霜草与针茅出现。
- 交通线与关隘：灰风谷，风大日短，一次只过一队。
- 人文与政治互动：萨满与教团的旧约已裂；部盟怕灰落进牧场，教团称那是神在挑拣。

### 盐沼渡
- 边界地形过渡：东南沿泥渡栈道下到泥岸，灰与泥混成灰浆。
- 生态变化：灰蛾与芦苇的水鸟各占一半。
- 交通线与关隘：泥渡栈道，断板处须绕；教团在栈道口设点收「净心钱」。
- 人文与政治互动：教团沿栈道收捐，走私客照走不误；点设一次，盐运就慢三日。

### 白港
- 边界地形过渡：南面越落灰带，灰渐薄，盐田与滩涂露出来。
- 生态变化：灰行者不见，盐鸦与滩蟹上来。
- 交通线与关隘：灰烬关，教团守南门，公会派十人共守。
- 人文与政治互动：教团索灰税，公会斥赎罪券，双方互设禁售却互扣货物；朝圣季这条路最挤，灰税也收得最勤。
