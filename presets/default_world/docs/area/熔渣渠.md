# 熔渣渠

## 一、地区概览
- 地区名称：熔渣渠
- 大致形状：西南一道斜长的裂谷，像被烙铁划开的旧疤，窄处只容一队车马并行。
- 主要地形：焦黑矿渣坡、连片废炉群、半凝固的熔岩沟，沟底终年冒硫气。
- 国都：渣城。围着中央大炉建起，街道用冷却的炉渣铺成，踩上去沙沙作响。
- 特殊地区：灰肺坑。塌陷的旧矿脉，坑壁渗白雾，下去的人多半咳着上来。
- 当前政治局势：四位炉主互不通婚，只靠军械订单维系同盟；炉主李砧欠公会三万张票，渠里认铁片不认盐票。
- 在世界推力中的位置：铁与军械的本位。灰岩原的石、白港的订单都压在同一批炉子上，渠里既靠矿吃饭，也靠订单吃饭。

## 二、详细地形分布

### 子区域：废炉群
- 位置范围：裂谷中段两岸，延七里。
- 地形类型：废弃炉体与渣堆。
- 海拔与地势：谷底至坡顶三十丈，坡面松散。
- 气候特征：终年热，硫气刺鼻。
- 主要地貌：炉壳、渣山、凝铁沟。
- 水源分布：硫泉两眼，不可饮。
- 与周边子区域的过渡：向南渐窄入熔岩沟，向北抬升为焦渣岭。
- 交通难度：渣路可行车，雨后成泥浆。

### 子区域：熔岩沟
- 位置范围：裂谷南段底部，长四里。
- 地形类型：半凝固熔岩沟。
- 海拔与地势：全境最低处，沟底龟裂。
- 气候特征：热雾贴地，夜可见红光。
- 主要地貌：凝壳、气喷口、铁壳桥。
- 水源分布：无，雨水即沸。
- 与周边子区域的过渡：北接废炉群，南转窄出黑水渠。
- 交通难度：只走铁壳桥，桥面烫脚。

### 子区域：焦渣岭
- 位置范围：西北边界，接灰岩原。
- 地形类型：矿渣堆积的陡坡。
- 海拔与地势：坡陡四十度，顶有索道站。
- 气候特征：风大，灰往南吹。
- 主要地貌：渣坡、索道塔、运石斗。
- 水源分布：季节性浊流。
- 与周边子区域的过渡：东南落入废炉群，越顶即灰岩原台地。
- 交通难度：只通运石索道，人攀极险。

## 三、城镇据点

### 据点：三闸关
- 据点类型：关隘兼验票站，入渠必经。
- 地理位置：东南黑水渠下游，三道闸门自南向北排开。
- 面积：十二亩，三闸各一院。
- 人口：常住一百二，日间逾三百。
- 势力归属：名义归公会，第三闸实由熔渣工坊把守。
- 势力结构：闸吏六人、工坊护闸队二十，另有公会派的验票员两人。
- 经济基础：过闸费、铁货验票、私收的「加急钱」。
- 军事力量：护闸队二十人，持短铳与铁叉。
- 与周边的关系：公会想收回第三闸，工坊拿李砧的欠票单抵着不放。
- 特殊之处：闸底石缝里卡着半枚旧铜印，是早年盐引的印模；闸簿第三页单记李砧一个人的欠票。

### 据点：渣城
- 据点类型：国都，炉业与集市。
- 地理位置：裂谷中段，围着中央大炉。
- 面积：三百亩，无城墙，以炉为界。
- 人口：两万四千，学徒占三成。
- 势力归属：四炉主分区而治，中央大炉轮值。
- 势力结构：四炉各领工坊，学徒按疤计年资，行会只在断铁价时凑齐。
- 经济基础：铁、煤、军械、炉渣砖。
- 军事力量：炉丁六百，持锤与铁叉，战时即兵。
- 与周边的关系：吃灰岩原的石，卖灰烬台的军械，欠白港的票。
- 特殊之处：中央大炉的火三百年未熄，炉主议事就在炉口，说话得喊。

### 据点：千炉塔
- 据点类型：地标兼钟楼，炉市绕塔而开。
- 地理位置：废炉群北端，九层铁塔。
- 面积：塔基半亩，塔周市占六亩。
- 人口：常住四十，日间数百。
- 势力归属：无主，四炉共同认这块钟表。
- 势力结构：守塔人一职由最老的炉匠轮，塔下市由行会抽头。
- 经济基础：铁器零卖、报时、寄存。
- 军事力量：无建制，塔上有铜铳两杆。
- 与周边的关系：全境按塔烟计时，盐票兑付也照它。
- 特殊之处：夜里仍在冒烟，是全境最准的钟；塔顶能看见白港的蓝火。

## 四、地形地貌生态

### 子区域：熔岩沟
- 植被类型：耐硫苔藓。
- 主要植物：硫苔、铁线草。
- 主要动物：灰鼠、硫蝇、渣蜥。
- 魔物分布：熔渣蜥，昼伏夜出，护喷口。
- 生态链：硫苔—灰鼠—渣蜥。
- 季节变化：冬日落灰，沟面结壳可走人。
- 资源产出：铁、煤、硫、凝壳。
- 生态威胁：沟底喷气，久留伤肺。
- 与人文的关系：沟底班是学徒最苦的一班，疤最深的人从那儿出来。

### 子区域：废炉群
- 植被类型：几乎无，只炉缝里有灰藓。
- 主要植物：灰藓、锈草。
- 主要动物：炉鼠、铁喙鸦。
- 魔物分布：锈甲虫群，啃铁也啃人。
- 生态链：锈草—锈甲虫—铁喙鸦。
- 季节变化：雨季渣坡塌，炉体移位。
- 资源产出：废铁、炉渣、铜件。
- 生态威胁：塌方、硫气聚洼。
- 与人文的关系：孩子靠捡废铁换票，捡到铜件就算发财。

## 五、地下城与魔物分布

### 地下城：灰肺坑
- 位置：废炉群北端塌陷处，坑口半掩。
- 类型：塌陷的旧矿脉。
- 简介：三十年前采空后塌，账上写「已闭」，其实一直有人下去。
- 结构：三层斜井，二层通废炉底，底层积白雾。
- 魔物分布：灰肺蛭群、闷死矿工的怨影。
- 陷阱与机关：朽撑木、塌陷面、雾窝（进去即失方向）。
- 宝藏与资源：未采尽的铁矿脉、旧班名册、私铸的废票版。
- 势力介入：工坊拿它当废料场，白港的人来查过一次就没再来。
- 危险等级：中偏高。

## 六、与周边地区的衔接

### 灰岩原
- 边界地形过渡：焦渣岭一路抬升，渣坡转为灰白石台。
- 生态变化：耐硫苔绝迹，换成石生苔与稀草。
- 交通线与关隘：运石索道，日夜不停；人走要攀四时辰。
- 人文与政治互动：工坊低价收石，行会攥着三张未兑盐票，石价与票价互为抵押。

### 白港
- 边界地形过渡：熔岩沟转窄成黑水渠，渣坡让位盐田与芦苇。
- 生态变化：硫气散尽，咸腥上来，盐鸦替了铁喙鸦。
- 交通线与关隘：三闸，第三闸归工坊；盐票与铁货都在这儿验。
- 人文与政治互动：公会压铁价，工坊便卡闸；李砧的三万张票是双方都不提的底牌。

### 灰烬台
- 边界地形过渡：东北越断炉隘口抬升，渣地覆上一层浮灰。
- 生态变化：炉鼠不见，只剩灰蛾与灰下活物。
- 交通线与关隘：断炉隘口，守灰军的军械从此过。
- 人文与政治互动：教团索灰税，工坊要军械订单，两家在隘口各设一人共守。
