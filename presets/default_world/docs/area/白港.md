# 白港

## 一、地区概览
- 地区名称：白港
- 大致形状：内海凹湾，城沿湾口堆成半月。
- 主要地形：深水湾、盐田、石堤、滩涂。
- 国都：白港城，上城盐仓、下城码头。
- 特殊地区：盐票厅，唯一印发盐票处。
- 当前政治局势：会长商承弼专权二十年，教团禁售令使东市盐价翻倍。
- 在世界推力中的位置：盐票印钞口，四国都要看它脸色。

## 二、详细地形分布

### 子区域：湾口深水区
- 位置范围：湾心至外海，宽两里。
- 地形类型：天然深水湾。
- 海拔与地势：最深处十二寻。
- 气候特征：多雾，秋冬有盐飓。
- 主要地貌：水下礁脊、沉船区。
- 水源分布：外海潮汐。
- 与周边子区域的过渡：向西渐浅为滩涂。
- 交通难度：须引水员，夜航禁行。

### 子区域：西盐田
- 位置范围：城西至黑水渠口，九里。
- 地形类型：人工盐田。
- 海拔与地势：低平，潮涨半没。
- 气候特征：日晒强，风大。
- 主要地貌：盐池、卤水沟。
- 水源分布：渠水混海水，卤度不稳。
- 与周边子区域的过渡：北接石堤，南连芦苇荡。
- 交通难度：堤路通车，池间单人。

## 三、城镇据点

### 据点：盐仓码头
- 据点类型：码头兼盐仓，开局场景。
- 地理位置：下城北岸，贴盐田出水口。
- 面积：四十亩，七座石仓。
- 人口：常住三百，日间逾千。
- 势力归属：公会直辖，仓正裴有光实管。
- 势力结构：验盐吏九人、雇工两百，阮九娘的线人混在其中。
- 经济基础：盐砖中转、盐票兑付。
- 军事力量：护仓队三十人，持短铳。
- 与周边的关系：上城嫌它脏，教团立过三次禁售牌都被拆。
- 特殊之处：三号仓地窖有暗门，钥匙在裴有光腰上；他欠阮九娘四百张票。

### 据点：渡鸦渡口
- 据点类型：内河渡口兼黑市。
- 地理位置：城东南三里，灰烬关来路河口。
- 面积：八亩，木栈浮屋。
- 人口：常住八十，夜里翻倍。
- 势力归属：名义归公会，实由走私客与教团共管。
- 势力结构：渡头老鸦陈收泊位钱，教团执事竺明每旬收灰税。
- 经济基础：渡船、私盐、卖消息。
- 军事力量：无建制，十二名渡夫。
- 与周边的关系：公会想封，教团想留，都不先动手。
- 特殊之处：账簿两套，另一套记谁运过灰烬。

## 四、地形地貌生态

### 子区域：西盐田
- 植被类型：盐生草本。
- 主要植物：盐蒿、碱蓬。
- 主要动物：盐鸦、滩涂蟹。
- 魔物分布：卤水沟白蛭，不主动伤人。
- 生态链：盐蒿—蟹—盐鸦。
- 季节变化：盐飓后盐池必修。
- 资源产出：粗盐、卤水、芦苇。
- 生态威胁：卤水渗井，水变咸。
- 与人文的关系：盐工按池计酬，坏池要赔。

## 五、地下城与魔物分布

### 地下城：旧盐井
- 位置：盐仓区下方，入口在三号仓地窖。
- 类型：废弃矿盐井。
- 简介：三十年前塌方封井，账上写「已填」。
- 结构：三层竖井、四条横巷，底层通海。
- 魔物分布：白蛭母体、失明旧矿工。
- 陷阱与机关：盐桥易塌、卤水闸。
- 宝藏与资源：岩盐两千石、旧账册一箱。
- 势力介入：裴有光私搬盐，教团称井底为神的伤口。
- 危险等级：中。

## 六、与周边地区的衔接

### 熔渣渠
- 边界地形过渡：渠下游转窄，盐田变焦渣坡。
- 生态变化：盐生植物绝迹，生耐硫苔。
- 交通线与关隘：三闸，第三闸归工坊。
- 人文与政治互动：工坊以铁换票，公会压价便卡闸。

### 霜牙岭
- 边界地形过渡：白喉隘以北抬升为冻土。
- 生态变化：芦苇让位盐霜草。
- 交通线与关隘：隘口设卡，收过霜钱。
- 人文与政治互动：公会扶两部压其余五部。

### 灰岩原
- 边界地形过渡：走廊向西北升，淤泥转石屑。
- 生态变化：草木转稀，多石生苔。
- 交通线与关隘：无险，三处水源站。
- 人文与政治互动：石工欠盐债，公会借此压石价。

### 灰烬台
- 边界地形过渡：关门两侧覆灰，越东越厚。
- 生态变化：盐田生物消失，只剩灰蛾。
- 交通线与关隘：公会与教团各派十人共守。
- 人文与政治互动：教团索灰税，双方互扣货物。
