# atrilk_plugin_trpg

ATRI-LK 的跑团插件：DND 5e 角色卡（0~9 环法术、48 子职、1~20 级）+ 由 DM Agent
主持的冒险（世界与场景按需生成、战斗与施法逐回合结算、倒地与死亡豁免、自动攒复盘）。

> 本项目是 [ATRI-LK](https://github.com/lokyoh/ATRI-LK) 的插件，仅支持 OneBot 适配器。

## 指令

所有指令都挂在主指令「跑团」之下，不占用顶层通用词。

| 指令 | 说明 | 示例 |
| --- | --- | --- |
| `/跑团.建卡` | 按步骤引导生成角色卡 | `/跑团.建卡`、`/跑团.建卡 精灵`（带上一步回答） |
| `/跑团.看卡` | 查看已保存的角色卡 | `/跑团.看卡` |
| `/跑团.骰` | 掷骰表达式，多个用逗号分隔 | `/跑团.骰 2d6+3`、`/跑团.骰 1d20, 4d6` |
| `/跑团.检定` | 技能 / 属性 / 豁免检定 | `/跑团.检定 察觉 DC15 优势`、`/跑团.检定 力量豁免 DC20` |
| `/跑团.改卡` | 重做建卡中的一步 | `/跑团.改卡 种族`、`/跑团.改卡 子职 刺客` |
| `/跑团.查` | 查规则 / 数据 / 子职等，优先返回图片 | `/跑团.查 子职 刺客`、`/跑团.查 法术 火球术` |
| `/跑团.开局` | 准备一局：选世界与故事（世界库为空时自动装内置预设），建存档并绑定会话（还不开局） | `/跑团.开局`、`/跑团.开局 2`、`/跑团.开局 生成 低魔中世纪` |
| `/跑团.加入` | 加入本会话准备中的存档 | `/跑团.加入`、`/跑团.加入 save_20261017_ab12` |
| `/跑团.开始` | 人都到齐后正式开局（跑开场白），任意已加入玩家可发 | `/跑团.开始` |
| `/跑团.继续` | 继续一局暂停中的冒险（重新绑定会话） | `/跑团.继续`、`/跑团.继续 save_20261017_ab12` |
| `/跑团.存档` | 查看当前存档（玩家名单、角色状态、本局用量）或列出全部存档 | `/跑团.存档` |
| `/跑团.结档` | 告诉 DM 本局可以收尾，由 DM 在剧情里写出结局 | `/跑团.结档` |

> 场景切换**没有玩家指令**：去哪里、何时离场入场由 DM 决定并在叙述里交代。

### 建卡流程

选择模式 → **等级** → roll 属性 → 背景 → **背景属性提升** → 种族 → 语言 → 职业 →
**子职** → 技能 → **1 级特性** → 装备包 → 选法术 → **属性加点** → **阵营** → 完成。

- **等级**（1~20，默认 1 级）：决定生命上限、熟练加值、法术位与起始经验（落在该等级
  的累计阈值上）。3 级起要选子职；4/8/12/16 级各做一次属性加点（战士另有 6/14、
  游荡者另有 10）；**19 级给的是传奇恩惠，不是加点**。
- **生命上限**：1 级满生命骰 + 体质，之后每级取平均值 + 体质，**每级至少 +1**
  （体质为负也不倒扣）。想让升级更「活」，DM 可用 `update_character` 的「掷血」
  字段掷一次生命骰，`/跑团.看卡` 会显示「Lv.2 掷 7、Lv.3 掷 9」。
- **属性**：回复「roll」掷 5 组（4d6 取最高三颗），或「标准数组」用 15/14/13/12/10/8；
  挑一组后按「力 / 敏 / 体 / 智 / 感 / 魅」顺序落位。
- **背景属性提升**（2024）：属性加值只来自背景 —— 选完背景后从其三项属性里选
  「一项 +2、另一项 +1」或「三项各 +1」，合计 +3、单项不超 20。**种族不提供属性加值**。
- **背景给起源专长**：每个背景固定给一项（侍僧→魔法学徒、士兵→凶蛮打手…），自动记进
  卡的「专长」栏；会算数的由系统结算（健壮 +2 生命/级、矮人 +1 生命/级）。
- **语言**与**阵营**：语言在种族之后单独选（通用语之外 2 门，人类 3 门）；阵营是末步，
  **纯扮演标记、无机械效果**，可回「跳过」。
- **子职**（3 级起）：2024 的 **48 个子职**（12 职业 × 4），**所有职业统一 3 级**获得。
  回复序号或子职名（「狂战士」「狂战士道途」都认），选完列出**到当前等级已解锁的特性**。
  其中几条进引擎自动结算：勇士的**暴击阈值**（19 / 18）、战斗大师的**卓越骰**、
  **每回合首次命中的额外伤害**（狂战士狂怒 / 狂热者神性之怒 / 妖精漫游者哀惧灵袭）、
  生命领域的**治疗加成**（+2+环阶、治了别人自己也回、治疗骰取满）、勇气学院的
  **额外攻击**（6 级起每动作 2 次）、防护师的**奥术守御**（防护法术建结界、受伤先吸收）、
  战争领域的**常驻抗性**（17 级：钝击 / 穿刺 / 挥砍）、勇士的**生还者**（18 级：死亡豁免
  优势、18~20 当天然 20、浴血时回合开始回血）；
  其余由 DM 按原文裁定。`/跑团.查 子职 刺客` 随时查。
- **1 级特性**（只有需要选的职业出现）：牧师圣职 / 德鲁伊原初职能 / 战士战斗风格 /
  魔契师魔能祈唤 / 游荡者专精 / 五职业的武器精通；背景给魔法学徒时（侍僧 / 向导 /
  智者）再选 2 戏法 + 1 道一环法术。
- **选法术**：施法职业才出现（野蛮人 / 战士 / 武僧 / 游荡者跳过；圣武士 / 游侠 1 级
  就有施法，只选 2 个一环）。数量按**等级查职业表**（8 级法师 = 4 戏法 + 20 条法术书），
  可选上限由法术位决定；回复序号 / 法术名，或「自动」（从高环往下填）。
- **升级选择会话**：升级后若还欠玩家决定（3 级子职、属性加点、这一级新得的法术），
  系统自动开一个会话逐项问（结算文本里带提示），答完写回角色卡并回到游戏；
  回「取消」跳过，之后用 `/跑团.改卡` 的子职 / 属性加点 / 法术 补。**只问这三件**。
- 会话实时落盘到 `data/plugins/跑团/sessions/`，整条流程由磁盘驱动（不依赖 60 秒过期
  的临时交互）：跨小时、跨天、重启后都能接着走，重发 `/跑团.建卡` 也会回到当前步骤；
  超过一天未继续的会话在启动时清理。角色卡存 `data/plugins/跑团/cards/<user_id>.json`。
- **角色名默认用 lk 插件里绑定的名称**（没绑定时是「冒险者 + QQ 尾号」）；跑团内部仍按
  QQ 号索引玩家，换绑不影响已有存档。

### 改卡

`/跑团.改卡` 列出可重做的步骤，`/跑团.改卡 <步骤>` 后按提示给新选择（也可直接带上，
如 `/跑团.改卡 职业 法师`）。可重做：`等级` `属性` `背景` `属性提升` `种族` `语言`
`职业` `子职` `技能` `特性` `装备` `法术` `属性加点` `阵营`。

- 改 `属性` 要先「roll」或「标准数组」，再回复序号挑一组 —— 只掷不挑不会把旧属性存成结果。
- 改职业会清掉新职业没有的技能、换回默认装备、清空法术**与准备名单**（旧名单指向的
  法术已不在卡上），改成非施法职业则法术为空。

## 冒险（DM 主持）

1. `/跑团.建卡` 建好角色卡。
2. `/跑团.开局` **准备**一局（只建存档，不跑开场）。世界库可以并存多个世界，
   每个世界里可以有多个故事：
   - 没有任何世界时，直接在后台跑入场流程（生成**地图 + 第一个故事**），分阶段汇报
     进度（① 世界地图 ② 世界起点与推力 ③ 建存档等人加入），完成后绑定本会话。
   - 已有世界时先列出世界（名称 + 一句话简介）：`/跑团.开局 <序号|世界名>` 选一个，
     `/跑团.开局 生成 [主题]` 生成**新世界**（不覆盖现有）；选中世界后再按同样方式
     选故事或生成新故事。世界还没有故事时自动生成第一个。
   - 选择状态保留 10 分钟；世界**所有存档共享**，每局存档记录自己引用的世界与故事。
   - 区域 / 城镇 / 地点 / 地下城 / 场景**不预生成**，DM 决定玩家去某处时才按需补齐。
   - 每人**每个群同时只能开一局**（自己建的那局），要换得先删旧存档。
3. `/跑团.加入` 加入（本群不带存档 ID 就加入当前这一局）；`/跑团.存档` 看名单。
4. 人齐后由**任意已加入玩家**发 `/跑团.开始`：DM 跑开场白并带大家进第一个场景。
   开局之前 @ 机器人不会触发 DM。
5. **@ 机器人**描述行动，行动**按轮推进**：规则判断器先把关（不合规则打回、信息不足
   追问），通过后先记进本轮，再由 DM **立刻只结算这名玩家的行动**（不总结全场），
   并在后面提示还在等谁；等这一轮的**等待名单**（DM 用 `await_players` 决定，开局默认
   全员）都提交后，DM 再输出一条**整轮总结**。
   - 整轮总结之前，玩家可以再 @ 覆盖自己这一轮的行动（会重新结算这一次）。
   - 每轮等谁由 DM 决定；倒地 / 阵亡的玩家会被自动跳过，不会因为某人不发言卡住。
   - 单人局提交后直接就是整轮结果。逐人结算可关（见「插件设置」），关掉后回到
     「全员提交 → DM 一次性主持」，每轮从 n 次模型调用降回 1 次；人少（默认 <3 人）
     也自动走这条省成本的路。
   - DM 自行调用掷骰 / 检定 / 查规则 / 查数据 / 改卡等功能；逐人结算时只为当前玩家
     结算，整轮总结时用 `player` 指明为谁改卡 / 检定。
   - **骰点单独回显**：叙述后附一段「🎲 判定」，写明谁做了什么检定、掷了多少、对抗多少、
     成功与否；DM 用 `secret_roll` 掷的暗骰不出现在这里。
   - 建卡续接（回复建卡问题）优先于 DM，不会互相打断。
6. **场景切换完全由 DM 决定**：玩家提出想去某处时，DM 用 `move_scene` 按需生成该地点的
   **通用场景**，再用**场景构建器**改造成**本局专属场景**存进存档；叙述里必须先交代
   **离场**、再描述**入场**。写回世界库的各级文档**一律不带故事**（世界库是骨架，
   本局专属化只在存档副本里做）；场景被玩坏时用 `update_scene` 追加到副本末尾，
   单纯「进 / 出场景」不记录。提示词里只放**场景简介**，完整副本由 `get_scene` 按需查。
7. **本局何时结束由玩家决定**：发 `/跑团.结档` 之后 DM 才把剧情推向收束、写出结局
   （收官后自动解绑会话，存档与复盘保留）。玩家没表态时 DM 不能自行结束，最多提醒一句。
   「结档状态」这段**只在真要收尾时注入**提示词（省 token）。
   `/跑团.结束` 是**暂停**：立刻停手（不写结局），存档原样保留，并汇报本局用量；
   `/跑团.继续` 接着玩，`/跑团.结束 删除` 才丢存档。暂停后 @ 不会触发 DM。

### 世界生成（程序定地理，模型填内容）

早期做法是让模型「一边编故事一边编地图」再正则解析它写的相邻关系，于是常出现链状走廊、
孤立地区、A 说和 B 相邻但 B 不认。现在**地理交给程序**（`core/dnd/world_topology.py`，
纯本地、不调用模型）：

- 网格上最远点采样撒种子，多源 BFS 划地 → 每块地都是**连续一整片**，没有飞地；
- 邻接 = 共享一条边 → 天然对称、平面、无孤立点，也不会「隔海相邻」；
- 顺带算出方位、角色（枢纽 / 普通 / 边陲）与格数，写进给模型的「地区布局」；
- 同一 `seed` 可复现同一张图（`render()` 能打印 ASCII 拓扑，方便排查）。

模型只负责**起名与写设定**，正文末尾给一段 JSON 索引作为解析依据。生成后跑一次自检
（`lint_world`）：名字数量、重名、邻接有没有写进正文 —— **只记警告不自动重试**
（为一个错再生成整个世界太贵），警告进日志与 `WorldMapResult.warnings`。

### 内置预设世界「阿塞尔提姆」

`presets/default_world/` 是一整套写好的内容（2024 口径、全铁系，不设盐主题）：1 篇世界、
**6 个王国**（炉心 / 霜牙 / 石冢原 / 泊银湾 / 钟楼国 / 卡兰提尔）、12 个省、35 处城镇 /
地点 / 地下城、124 个场景、14 份预写事件（按玩家落地的省装进存档）。

- 世界库为空时**开局自动装上**（不调用模型，秒装）；装过就复用，之后在世界列表里选。
- 装的是**文档**不是存档：预设目录与世界库里的世界目录**完全同构**
  （`index.json` + `docs/<kind>/<key>.md`），安装就是按索引原样重放 —— 走的和生成 agent
  落库同一条代码路径，所以装完的世界与「现生成」没有区别。
- **进区零生成**：每个省的第一个据点都配了同名场景，DM 说「去某地」时一步命中。
- **世界层不带剧情**：世界 / 王国 / 省 / 地点 / 场景里只写**本地事件**（本地的债、
  本地的走私、本地的关卡），不含任何故事线专有名词。
- 改预设：直接编辑文件，**改完把 `index.json` 的 `version` 提到当天**（六位日期，
  如 `261024`）。版本号一变，下次开局就按新版就地重装；忘了改会被
  `tests/test_dnd_preset_seed.py` 拦下，也可跑 `python scripts/bump_preset_version.py`
  （该脚本不进版本库）。索引里写了的文档磁盘上必须有，缺文件直接报错。
- 自检：`poetry run python tests/_scratch_trpg_preset.py`（校验索引一致、邻接对称、
  进区零生成、世界层不含剧情词，并真装一次验圣经播种）。
- 把 `data/plugins/跑团/world/worlds/<世界>/` 整个目录拷进 `presets/` 就是一份新预设，
  格式零转换。

### 世界圣经（命名与事实的唯一来源）

地图、故事、区域、场景是**不同的模型调用**，各写各的很容易同一个人在这份文档里叫
「商承弼」、那份里叫「沈万三」。世界圣经（`core/dnd/world_bible.py`，落盘
`worlds/<key>/bible.json`）是为此存在的锚点：

- **实体登记**：人物 / 势力 / 地名 / 物品各记一条（规范名、别名、地区、备注、出处），
  按 `(名字, 种类)` 去重合并，先来者是正史；
- **能不调模型就不调**：地区表、「」地标、故事的势力 / 关键节点、场景的在场者，全部由
  **程序**从已落库的文档里提取；模型只在生成世界 / 故事时顺带补齐程序提不出的人物势力；
- **消费**：`bible_text()` 生成有字数上限的紧凑文本，注入 DM 每轮提示词与按需生成的输入；
- 预设装完即**播种圣经**；**战斗中不注入**（砍一刀用不上几百字人名地名）；
- 字数上限在插件设置里调（`world_bible_max_chars`，默认 800，超限从尾部丢实体）。

### 用量与花费

每次模型调用都把 token 用量记到**当次这一局**的存档上（`progress.billing`，按模型分项）：

- 覆盖 DM 主持、场景构建、按需生成、开局生成世界与开场白等**所有**跑团调用；
- 花费按 `data/config/system/provider.yml` 里填的单价（每百万 token）换算，与 WebUI
  口径一致；没配单价的模型只统计 token，并在汇报里注明「这部分费用未计入」；
- DM 的功能调用各用自己的存档副本、之后整份写回，落盘前会把最新累计并回去，避免刚记上
  的用量被旧对象覆盖；
- 汇报点：`/跑团.结束`、`/跑团.结档` 收官那轮、`/跑团.存档` 详情。换算出的是**估算值**。

### 插件设置（省模型成本）

WebUI「插件设置 → 跑团」（`config.py` 的 `TrpgConfig`，改完即时生效）：

| 设置 | 默认 | 作用 |
|---|---|---|
| 逐人结算 | 开 | 关掉后回到「全员提交 → 一次性主持」，每轮调用从 n 次降回 1 次 |
| 逐人结算最少人数 | 3 | 人数不足自动走一次性主持（2 人局最省），填 99 等于彻底关闭 |
| 最近事件条数 | 5 | 每轮塞给 DM 的历史条数，逐人结算时再减半，单条超 160 字截断 |
| NPC 名单条数 | 6 | 提示词里最多列几名具名 NPC |
| 每轮附战场地图 | 关 | 关着时只在**站位或地形变化**那一轮重画，其余轮只给坐标与距离 |
| 世界圣经字数 | 800 | 每轮注入的专有名词块上限，超限从尾部丢实体 |
| 敌人回合自动结算 | 开 | 系统替敌人挑目标 / 靠近 / 选招 / 掷骰扣血；关掉后敌人不再自动出手 |

写死在代码里的省法：剧情 / 战斗各只下发该用的功能子集（剧情 20 个、战斗 19 个，
而不是全部 24 个；两种形态**共有的排前面**，切形态时缓存前缀不会整段作废）、功能说明
每条压成一行、多人局非焦点玩家的角色卡压成一行、「结档状态」只在收尾时注入、工具返回
超 600 字截断（`get_scene` / `start_combat` 等少数放宽）、单轮思考上限 8 步、
叙述硬指标（整轮 250 字 / 逐人 150 字 / 战斗 200 字，每轮只推进一个动作或一个信息点）。

### 复盘（story.md）

每局自动攒一份**给人看**的剧情流水：`saves/<存档ID>/story.md`。

- **只在整轮总结时写**，每条记玩家输入、系统裁定摘要（检定 / 攻击 / 法术位等工具输出）
  与 DM 的整轮叙述；给玩家看的「接下来你们可以：」不写进来；
- 标题按场景分节（`## 场景：后巷`），场景里打起来时降一级（`### 战斗：后巷伏击`）；
- 单卷超 **10 MiB** 自动滚到 `story-2.md`，新卷补上卷号与当前场景标题；
- 结档时文末落一条 `**🏁 本局就此结档。**`；
- 它与 `events.jsonl` 是两回事：后者喂给 DM 当 history，前者留给玩家。

## 战斗（逐回合）

### 开战、换人与自动回合

DM 用 `start_combat` 列出敌人后，系统会：

- 从**怪物数据表**（531 只，按中文名 / 英文名 / 别名取）取 AC、生命骰、攻击与特性，
  与玩家先攻一起掷出**先攻顺序**（首发是顺序里排最前的玩家，同类怪共用一次先攻），
  落盘 `combat.json`；
- 剧情里的角色写成 **`名字:档位`** 即可参战（`平民` / `士兵` / `老兵` / `首领`，
  `打手x2:士兵` 也行），数值按**队伍等级**现算（经验另按档位表给）；也可以直接用怪物
  模板（`卡尔:匪帮首领`）。具名 NPC 会**留档**到 `npcs.json`（旧伤、状态、关系、
  最后出现的地点），下次遇到沿用；杂兵不留档；
- 把本轮的等待名单换成「当前该行动的玩家」，**只有他能提交**；该回合结束后推进到下一名
  玩家，中间夹着的**敌人回合由系统自动打完**：挑目标（专攻目标 → 最近 → 同距打血最少的）
  → 够不着就按格子走过去 → 选一招够得着的 → 按数据卡的「多重攻击」打够次数 → 掷骰扣血，
  结果直接拼进这一轮叙述。DM 侧**没有**敌人攻击 / 改敌人状态的功能：特殊动作
  （吐息 / 撤退 / 抓人质）写进叙述，要落伤害就 `heal` 写负值；
- 玩家攻击用 `attack`（按卡上武器算加值，可指定武器 / 优势 / 劣势）、施法用 `cast_spell`、
  挪位置用 `move`；**战斗中 `update_npc` 一律不可用**（参战者血量只认战场，边打边写
  会两套账）；战斗未结束不能 `move_scene`；
- 敌人全部退场或**全队阵亡**时自动结束（后者不结算经验战利品），DM 也可用 `end_combat`
  收尾（撤退、议和、投降）。战斗一结束就自动同步回 `npcs.json`。

### 战场：距离、地形、掩体、光照

- **棋盘**：按敌人数量定边长（9~19 格）、按场景类型选地形模板（石街窄巷 / 室内厅堂 /
  林地 / 洞窟 / 水岸 / 旷野），双方隔开 15~25 尺列阵，随机铺障碍、半掩体、四分之三掩体、
  困难地形、危险地形与浅水。**不额外调用模型**；地形以开战时那张为准，途中砸墙 / 点火
  写在叙述里。地图默认**只在布局变化时**重画。
- **距离是硬的**：1 格 5 尺、斜向同算 5 尺；`attack` / `cast_spell`（敌人自动回合同样）
  都校验射程与视线，够不着会被打回并告诉你还差多少尺；超出**常规射程**自动带劣势。
- **掩体**：半掩体 +2、四分之三 +5（AC 与**敏捷豁免**都加），障碍挡通行也挡视线
  （Bresenham 连线近似）；`move` 用 Dijkstra 算路径与消耗（困难地形 / 浅水一格算两格），
  按**速度**扣预算，超了等下一回合。
- **光照**：`start_combat(light=明亮/微光/黑暗)` 定亮度（留空按日光推），黑暗里看不见
  目标的一方攻击带劣势；**黑暗视觉**把黑暗当微光、**盲视 / 震颤感知**在射程内不靠光、
  **真实视觉**一律看穿。战斗块会写出当前光照与后果。
- 开战后会给 DM 强要求：**第一段叙述先把战场讲清楚**（地形光线、掩体障碍、双方站位与
  距离），再写谁先动手。

### 动作经济与战术动作

- 每回合 1 动作 + 1 附赠动作 + 1 反应 + 一次移动。系统按 DM 调用的工具**自动记账**
  （`attack` 与「1 动作」法术记动作，附赠 / 反应法术各记各的，描述里出现移动就记一次），
  战斗块显示「本回合已用：…」，新回合清空。这只是**提示**：用完了工具多回一句提醒但
  **不拦截**，最终裁决权在 DM。
- `tactic` 一个入口管九件事：
  - **回避**：挂「回避」状态（被打劣势、敏捷豁免优势），到下回合开始自动摘；速度 0 或
    失能时拒绝。
  - **躲藏**：敏捷（隐匿）**DC 15**（2024 固定 DC），成功挂「隐形」；**出手即暴露**。
  - **预备**：把触发条件记在参战者身上（战斗块显示「⏳ 已预备」），触发时由 DM 用反应
    执行，下回合开始作废。
  - **借机攻击**：花**反应**打一次近战（玩家 `attack`、敌人 `enemy_attack`）。
  - **上马 / 下马**：扣一半速度的移动力。
  - **狂暴 / 回气 / 疾风步 / 患者防御 / 鲁莽攻击 / 卓越骰**：见下节。
- **武器熟练是硬的**：卡上没有某武器的熟练项就不加熟练加值（法师抡长剑只剩力量调整值）；
  徒手打击人人有熟练项。**捕网**另有规定（2024 已归冒险用品）：攻击检定**永远不加熟练**，
  命中也不掷伤害，只判「束缚」。

### 职业资源（次数与恢复）

「有几发」在 `res/dnd/class_resources.yaml`（手册第三章职业表的数值列，法师没有可消耗
资源）；**卓越骰**是子职给的，上限读 `res/dnd/subclasses.yaml` 的 `superiority` 成长表。

| 职业 | 资源 | 恢复 |
| - | - | - |
| 野蛮人 | 狂暴 2~6 次、狂暴伤害 +2/+3/+4 | 短休回 1 次 |
| 战士 | 回气 2~4 次、动作如潮 1~2 次 | 短休全回 |
| 武僧 | 功力 0~20 点（2 级起） | 短休全回 |
| 牧师 / 圣武士 | 引导神力 2~4 次 | 短休回 1 次 |
| 德鲁伊 | 荒野形态 2~4 次 | 短休回 1 次 |
| 术士 | 术法点 2~20 点 | 只有长休 |
| 游侠 | 宿敌 2~6 次 | 只有长休 |
| 战士（战斗大师） | 卓越骰 4d8 → 6d12 | 短休全回 |

进结算的六条（都在 `tactic` 里选，**不新增工具**）：

- **狂暴**：花 1 次 + 附赠动作，挂「狂暴」状态 —— 力量攻击伤害 +2/+3/+4（灵巧武器只有
  力量不低于敏捷时才加，远程不加）、对钝击 / 穿刺 / 挥砍**抗性**、力量检定与豁免优势。
  穿重甲进不去；**战斗外也能用**（战前开狂暴）。
- **鲁莽攻击**（2 级，**不花动作**）：本回合力量攻击自动带优势，而到它下个回合开始前
  **打它的攻击也带优势** —— 敌人回合自动结算会读这个标记，所以是实打实的代价。
- **回气**：附赠动作回 `1d10 + 战士等级`（倒地者会被救醒）。
- **疾风步**：1 功力 + 附赠动作 → 本回合多打 2 次徒手，**不占动作**。
- **患者防御**：1 功力 + 附赠动作 → 回避。
- **卓越骰**（战斗大师）：`action` 写「卓越骰 精确攻击」—— 扣 1 粒并掷出点数写进回执，
  15 种战技的具体结算仍按原文由 DM 裁定。

卡上 `resources` 记的是**已用次数**，卡面写「资源 回气 2/3」；休息按上表自动恢复并在回执
里逐条列出（长休一律清空）。固定数值类（武艺骰 d6→d12、诗人骰、偷袭 1~10d6、无甲移动、
武器精通可选数、契约法术位）不进记账，只按等级查出来给 DM 用。DM 也可用 `update_character`
的「资源」字段手工增减（`术法点 +2` / `狂暴 -1` / `术法点=3` / `满`）。

### 倒地与死亡豁免

- **全队阵亡 = 本局结档**：所有玩家都死亡时系统自动进入收尾 —— DM 先写结局并 `wrap_up`；
  万一没来得及（比如最后一击在它这次叙述里），系统兜底结档（清战斗、解绑、复盘末尾落
  一条「全员阵亡」）。想重来用 `/跑团.开局`。
- 生命值降到 **0 即倒地濒死**：轮到他的回合由**系统自动掷死亡豁免**（d20 无加值、DC 10）
  —— ≥10 记 1 次成功、≤9 记 1 次失败，**天然 20** 回 1 点生命并清醒，**天然 1** 记 2 次
  失败；**3 次成功 = 伤势稳定**（仍昏迷，不再掷），**3 次失败 = 死亡**（想回来得靠复活术
  这类剧情手段，DM 用 `update_character` 的「死亡豁免」字段裁决）。
- 倒地期间再挨打会累计失败（普通 +1、**暴击 +2**）；单次伤害达到或超过生命上限则**当场
  死亡**。敌人补刀是合法的，也是死亡豁免走向死亡的正常途径。
- **任何治疗**都会立刻恢复意识、回血并**清空死亡豁免进度**；伤势稳定者保持昏迷，等治疗
  或长休。进度记在角色卡上（`/跑团.看卡` 的「生存状态」），跨战斗、跨场景不丢。
- 倒地 / 阵亡的玩家仍可 @ 说话，但提交会被标注成「呓语 / 遗言」交给 DM，等待名单里自动
  跳过 —— **全队倒下时剧情也不会卡住**。

## 法术（0~9 环全覆盖）

- 法术表共 **396 个**（戏法 35 / 一环 65 / 二环 64 / 三环 54 / 四环 41 / 五环 48 /
  六环 34 / 七环 21 / 八环 18 / 九环 16），按中文名 / 英文名 / 键取用；
  `query_data` 的 `法术` 表可列全表，给职业名则报该职业各环数量 + 0~3 环明细。
  0~3 环是手工校对版，更高的环阶由 XPHB 补齐；**职业归属全表都有**。
- 卡上记**已知法术**与**法术位**。施法属性由职业决定，派生**法术攻击加值** = 熟练 +
  施法属性调整值，**豁免 DC** = 8 + 熟练 + 施法属性调整值。
- 法术位分三档：全施法（法师 / 牧师 / 德鲁伊 / 术士 / 吟游诗人）、半施法（圣武士 / 游侠，
  **1 级就有 2 个一环位**）、契约魔法（魔契师，**短休**回满）。戏法不消耗法术位。
- **准备法术**：2024 **八个施法职业全是准备制**，可准备数是**职业表里查的固定值**
  （法师 1 级 4 / 20 级 25、牧师 4 / 22、圣武士 2 / 15），与属性无关。区别只在何时能改：
  牧师 / 德鲁伊 / 法师长休任意换，圣武士 / 游侠长休换一个，吟游诗人 / 术士 / 魔契师
  升级换一个。**法师另有法术书**（1 级 6 条、每级 +2），准备时从书里挑。名单由 DM 用
  `update_character` 的「准备」字段写入（认不出的法术名会点名退回）；施放**列表外**的
  法术给 DM 一条提示但**不拦截**；卡上没记列表就当作「未管理」，不做校验 —— 宁可松。
- **数量随等级涨**：建卡按等级查表挑，能挑的最高环阶由法术位决定（不会「5 级法师挑九环」）；
  升级时只问这一级新得的几个（候选只列卡上没有的、高环在前），挑完**追加**不覆盖。
- `cast_spell` 结算：法术攻击自动对抗 AC，需豁免的自动算 DC 并掷目标豁免（成功按规则
  减半或免伤），治疗 / 临时生命自动结算，法术位自动扣，**不够会被打回**。不指定环阶时
  自动用最低可用位，也可显式升环（伤害按「每升一环 +NdM」自动加骰）。
- **控制类法术会把状态真挂上**：数据里的 `conditions`（定身人类 → 麻痹、恐惧 → 恐慌、
  蛛网 → 束缚、命令术 → 倒地…）在豁免失败时写到敌人身上或角色卡里，`condition_rounds`
  到点自动解除。挂上之后失能的敌人真的跳过回合、被麻痹的目标近战命中按暴击算。
- **恐慌的敌人会自己跑**：轮到它时不攻击、往最远处撤；无路可退就当场退出战斗，并按严格
  5e **不给经验**（撤销击败记录）。
- **法术会改地形**：`terrain` 字段（蛛网术 / 纠缠 → 困难地形）在豁免失败时改掉目标脚下
  那格并落盘；DM 侧没有改地形的功能。
- `rest` 处理休息：长休回满生命与法术位（倒地者醒来、死亡豁免清零），短休只回契约法术位。
