# DND 跑团规则（Agent 专用）

## 规则口径（2024，先读这里）

**全项目规则以《玩家手册（2024）》为准**（2026-10-24 裁定）；怪物数据用 **2025 图鉴**
（5etools 中文包，xmm 为主，mm / dosi / lmop 补充；兽人等 2025 删掉的从 2014 图鉴补录，
出处标 MM，算数据补录不算口径回退）。

- **2014 与 2024 说法不一 → 一律 2024**。已按此落地的四处：**旅行步调**（快速 = 感知
  检定与隐匿劣势、普通 = 隐匿劣势、慢速 = 感知优势）、**力竭**（每级所有 d20 检定 −2、
  速度 −5 尺、6 级死亡、长休减 1 级且不要求进食）、**突袭**（遭袭者先攻检定劣势，
  不是首回合禁言）、**属性加值**（建卡只来自背景的三项属性，**种族不加属性**）。
- **PHB 2024 没有明文时**：沿用两版通用的旧规则（同调、法术位表、武器词条、币制等），
  或按房规处理并在正文标注「房规」。
- **房规只有两条**（别处看到「按 5e」的都是真规则）：① **挨饿计时**沿用 2014 的
  「3 + 体质调整值」天（2024 实为「吃不足半量过 DC10 体质豁免」）；② **24 小时没长休**
  过一次 DC 10 体质豁免，失败 +1 级力竭（两版手册都没有这条）。
  「中毒每回合扣 1 血」曾是房规，**已移除**。
- **2014 字样只允许出现在三种地方**：标注「已不采用 / 已不适用」的对照说明、数据出处的
  provenance 注记、本裁定本身。别处看到 2014，按 bug 报。
- **起源专长**（第五章）：每个**背景**固定给一项（恰好 10 项），自动落进卡的「专长」栏；
  会算数的由引擎结算（健壮 +2 生命/级、魔法学徒给 2 戏法 + 1 道一环法术），其余按原文
  由你裁定。种族的每级生命加值（矮人 +1）同样自动结算。**阵营**是纯扮演标记，
  没有机械效果，可留空。
- **子职**（第三章）：**所有职业统一在 3 级**获得（2014 的「牧师 1 级 / 法师 2 级」作废），
  共 **48 个**（12 职业 × 4），特性原文已收录（`query_data subclass` 可查）。
  **引擎只结算下面这几条**，其余按原文由你裁定：
  - **暴击阈值**：勇士「精通重击」19 起、「高效重击」18 起，攻击结算自动认；
  - **卓越骰**：战斗大师 4d8 → 5d8 → 5d10 → 6d10 → 6d12（按等级），短休回满；
    `tactic` 写「卓越骰 精确攻击」扣 1 粒并掷点数，15 种战技的效果仍按原文裁定；
  - **每回合首次命中的额外伤害**（每回合只一次，暴击时骰数翻倍）：
    狂战士**狂怒**（狂暴 + 本回合鲁莽 + 用力量 + 近战，掷「狂暴伤害」个 d6，类型同武器）、
    狂热者**神性之怒**（狂暴中，`1d6 + 等级的一半`，光耀 / 暗蚀由玩家选）、
    妖精漫游者**哀惧灵袭**（用**武器**命中即给，1d4，11 级起 1d6，心灵伤害）；
  - **生命领域的治疗加成**：**生命门徒**（用法术位治疗时每个目标多回 `2 + 环阶`）、
    **神佑医者**（治了别人，你自己也回 `2 + 环阶`）、**极效治疗**（治疗骰一律取满）；
  - **勇气学院的额外攻击**（6 级）：一个攻击动作能打 2 次 —— 与职业表给的那条
    **取大者，不叠加**（吟游诗人本来 1 次，有它才是 2 次）；
  - **防护师的奥术守御**（3 级）：消耗法术位施展**防护学派**法术时建起结界
    （上限 = 法师等级 ×2 + 智力调整值），之后每次再放防护法术回 `环阶 × 2` 点、
    **不重建**；你受伤时先算抗性 / 易伤，剩下的由结界吸收，结界空了才轮到生命值；
    结界到长休才消失。
  - **战争领域的常驻抗性**（17 级）：对钝击 / 穿刺 / 挥砍伤害有抗性（并进抗性表，
    显示与结算都自动带上）；
  - **勇士的生还者**（18 级）：死亡豁免**有优势**，且掷到 **18~20 都按天然 20**
    处理（回 1 点生命并清醒）；回合开始时若**浴血**（生命不超过上限一半）且还有
    至少 1 点生命，自动回 `5 + 体质调整值`。
  - **先攻优势**：勇士「运动健将」（3 级）与刺客「暗杀」（3 级）的**先攻掷骰有优势**，
    与突袭劣势互相抵消（结算先攻时自动读）。
  - **防护师的法术抗性**（14 级）：对抗**法术**的豁免有优势，**法术造成的伤害减半**
    （先按伤害类型算抗性 / 易伤，再按「法术来源」减半，最后才轮到奥术守御）。
    引擎只在**法术结算**里打这个标记 —— 敌人施法不由引擎结伤，那种场合由你按原文裁定。
- **职业等级特性**（第三章）：12 职业 × 1~20 级共 283 条原文已收录
  （`res/dnd/class_features.yaml`；`query_data class_feature` 写「战士 5」看该级全部、
  写特性名看原文）。进战斗结算的只有两条，代码按 `grants` 标记算、不按中文名认：
  **额外攻击**（战士 5/11/20 级 2/3/4 次，野蛮人 / 武僧 / 圣武士 / 游侠 5 级 2 次 ——
  同一动作连打不重复扣动作）与**动作如潮**（战士 2 级起，`tactic` 里选，本回合 +1 动作、
  短休恢复）。其余特性仍按原文由你裁定。
- **职业资源**（`res/dnd/class_resources.yaml`，卡上 `resources` 记**已用次数**）：
  - **狂暴**（野蛮人 1 级 2 次 → 17 级 6 次）：`tactic` 选「狂暴」，花 1 次 + 附赠动作挂
    「狂暴」状态 —— 力量攻击**伤害 +2/+3/+4**（1/9/16 级）、对钝击 / 穿刺 / 挥砍**抗性**、
    力量检定与豁免**优势**。未着装重甲才能进；短休回 1 次、长休回满。
    「一整轮既没攻击也没受伤就结束」由你按叙述摘状态。
  - **鲁莽攻击**（野蛮人 2 级，**不花动作**）：本回合它的力量攻击自动带优势；到它下个
    回合开始前，**打它的攻击也带优势**（敌人攻击结算会读 `Combatant.reckless`，
    回合结束自动清空）。
  - **回气**（战士 1 级 2 次 → 10 级 4 次）：附赠动作回 `1d10 + 战士等级`，短休全回。
  - **疾风步 / 患者防御**（武僧，功力 2 级 2 点 → 20 级 20 点）：各花 1 点 + 附赠动作，
    前者本回合**多打 2 次徒手**（不占动作），后者换一次「回避」。功力短休全回。
  - 其余资源（引导神力 2~4 次、荒野形态 2~4 次、术法点、宿敌）**已记账、已按口径恢复**，
    但具体效果仍由你按原文裁定（引导神力各领域差异太大）。
  - 非消耗类数值（武艺骰 d6~d12、诗人骰、偷袭 1~10d6、无甲移动、武器精通可选数、
    契约法术位）只按等级查出供参考，不进「已用」记账。
- **升级后的玩家选择**：升到 3 级（子职）、属性提升等级（加点）、施法者这一级新得的法术
  —— 系统会自动开升级选择会话逐项问（结算文本里带提示），答完写回角色卡；回复「取消」
  跳过，稍后用 `/跑团.改卡` 补。**只问这三件**，技能 / 装备 / 阵营不重问。
  升级附带的**职业新特性**由你按 `query_data class_feature` 的原文叙述落实。
- **高等级开卡**：等级决定生命上限、熟练加值、法术位与起始经验；**属性提升（ASI）**
  按 4/8/12/16 级在建卡时逐次分配（战士另有 6/14、游荡者另有 10），**19 级给传奇恩惠**。
- **兼职**（第三章）：先决是「新职业 + **每个现有职业**的主要属性都 ≥13」。**总等级**管
  熟练加值与经验，**职业等级**管特性 / 资源 / 法术数量；生命骰按每一级所属职业算（只有
  角色第 1 级拿满骰）；法术位走「兼职施法者」表（全职全算、圣武士 / 游侠减半向上、
  奥法骑士 / 诡术师三分之一向下），**魔契师的契约位单列**；额外攻击**不叠加**，兼职
  **不给豁免熟练**。细节见「十九、升级 → 兼职（多职业）」。
- **已知未对齐项**（已登记，排期另议）：武器「精通」只记词条、**效果由你按词条裁定**；
  冒险用品表转录自 2014 快速参考；通用 / 战斗风格 / 传奇恩惠三类专长未收录（只收了背景
  给的 10 项起源专长）；升级只问这一级新得几个法术，不替你挑。

## 一、核心判定

- 有难度的行动掷 **1d20** + 相关调整值，与 DC 比较：**≥ DC 成功，< DC 失败**。
- **自然 20 / 自然 1 的特殊规则只作用于攻击检定与死亡豁免**：攻击掷出自然 20 必中且暴击、
  自然 1 必失；死亡豁免自然 20 回 1 血、自然 1 计两次失败。
  **属性检定与豁免没有大成功 / 大失败** —— 自然 20 只是很好的结果（20 + 调整值 vs DC）。

## 二、属性与调整值

- 六大属性：**力量、敏捷、体质、智力、感知、魅力**，通常在 1–20 之间。
- 调整值 =（属性值 − 10）÷ 2，向下取整；属性每 +2，调整值 +1。
- **属性提升只来自背景**：背景给三项属性，建卡时选「一项 +2、另一项 +1」或「三项各 +1」
  （合计 +3，单项不超 20）。**种族不提供属性加值** —— 玩家表里种族只有速度、体型、
  特性与语言。背景还给一项起源专长与两项技能；语言来自独立的「选择语言」步。

## 三、常用检定

- **力量**：攀爬、推拉、破坏、负重。**敏捷**：潜行、躲闪、开锁、先攻。
- **体质**：抗毒、抗病、耐力、维持专注。**智力**：回忆知识、分析、调查、推理。
- **感知**：察觉、洞察、追踪、直觉。**魅力**：游说、欺骗、威吓、表演。

## 四、技能检定

技能检定 = 1d20 + 属性调整值 + 熟练加值（若熟练）；**熟练加值**由等级决定：
1–4 级 +2、5–8 级 +3、9–12 级 +4、13–16 级 +5、17–20 级 +6。

### 卡上的「1 级特性选择」怎么算

2024 的 1 级特性里有 6 处要建卡时挑，选完记在卡上。**哪些已经算好了**：

- **专精**（游荡者）：这些技能的熟练加值**已翻倍**并算进技能加值，查卡时不要重复加。
- **战斗风格**（战士）：**防御**（着装护甲时 AC +1）与**箭术**（远程攻击 +2）已进结算；
  其余（对决 / 巨武器 / 双武器 / 投掷 / 徒手 / 盲斗 / 拦截 / 守护）只记在卡上。
- **圣职 / 原初职能**：选「守护者」给的额外护甲 / 武器受训已并进受训列表；
  「施法者 / 术士」多出来的那一个戏法**没有**自动加，需要时由你补给玩家。
- **武器精通**：卡上只记录选了哪几件武器，**精通词条的效果不结算**，按装备表的
  「武器精通」列裁定。

## 五、优势与劣势

- **优势**掷 2d20 取高、**劣势**掷 2d20 取低；两者同时存在则抵消，正常掷 1d20。
- 多次优势 / 劣势不叠加，只取一次。
- 有优势 / 劣势时，能让你「重骰」的效果**只重掷其中一颗**（由玩家选），不是两颗都重。

### 英雄激励

- **一次只有一个**（再获得不叠加，2024 允许转赠给没有激励的队友）。
- **怎么用**：掷完任何骰子后消耗它重掷一次，**必须采用新结果**（可能更差）。
- **什么时候消耗由玩家决定**：只有行动里写明「重骰 / 重投」才消耗并重掷；没写就不动，
  写了却没掷骰也不消耗。
- **人类每日一个**：人类角色每次完成长休后获得 1 个；其他来源由你授予 —— 做出英雄之举、
  符合角色的扮演、让局面更有趣，都值得给。
- **吟游诗人激励不是这个**：它给的是「一次 d20 检定额外加一枚骰」（1d6 起，5 级 d8、
  10 级 d10、15 级 d12，次数 = 魅力调整值），本局没有实现。遇到时按「+1d6 到那次检定」
  裁定，用 `roll_dice` 掷。

## 六、战斗流程

1. **确定先攻**：每人掷 1d20 + 敏捷调整值，从高到低排序（遭突袭者先攻劣势；勇士
   「运动健将」/ 刺客「暗杀」给先攻优势，两者同时存在则抵消成普通）。
2. **回合行动**：1 个**动作** + 1 个**附赠动作**（若可用）+ 1 次**移动**（不超速度）
   + 1 次**自由交互**。
3. **动作常用选项**（2024 动作表）：**攻击**（武器 / 徒手，含擒抱、推撞这类特殊近战
   攻击）、**疾走**（额外获得等于速度的移动力）、**撤离**（本回合移动不引发借机攻击）、
   **回避**（到下回合开始打你有劣势、你的敏捷豁免有优势；失能或速度归零时失效）＝旧称
   「闪避 / 躲避」、**协助**（帮别人那次检定有优势，或做急救）、**躲藏**（敏捷（隐匿））
   ＝旧称「隐藏」、**影响**（魅力（欺瞒 / 威吓 / 表演 / 游说）或感知（驯兽），改变一个
   生物的态度）、**魔法**（施法、使用魔法物品）、**预备**（定好触发条件，用反应执行）
   ＝旧称「准备」、**搜索**（感知（洞悉 / 医药 / 察觉 / 求生））、**研究**（智力（奥秘 /
   历史 / 调查 / 自然 / 宗教））、**操作**（用一个非魔法物件）＝旧称「使用物品」。
   战斗中回避 / 躲藏 / 预备 / 借机攻击 / 上下坐骑由 `tactic` 结算；战斗外的躲藏 / 骑乘
   用 `check` 掷骰后叙述；影响 / 研究 / 搜索 / 操作照常用 `check`。
4. **攻击判定**：1d20 + 属性调整值 + 熟练加值（若熟练），对抗目标 AC；命中后按武器或
   法术描述掷伤害。

## 七、护甲等级（AC）

- AC = 基础护甲值 + 敏捷调整值（受护甲类型限制）+ 盾牌加值 + 其他加值；攻击结果 ≥ AC
  命中，< AC 未命中。
- **掩护**：半掩护 = AC 与**敏捷豁免** +2；四分之三掩护 = AC 与**敏捷豁免** +5；
  全掩护 = 不能被直接选作目标。棋盘上有掩体格时系统自动结算（吐息 / 爆炸都吃得到）。

## 八、生命值与死亡

- 初始生命值 = 生命骰最大值 + 体质调整值；升级时 = 生命骰掷骰结果（或平均值）+ 体质
  调整值，**每级至少 +1**。
- 生命值降到 **0**：立即**昏迷倒地**（无法行动、5 尺内被近战命中即暴击、失去专注），
  进入**濒死**，每回合开始掷 **死亡豁免**（1d20 无加值）：
  ≥ 10 成功 1 次；< 10 失败 1 次；自然 20 恢复 1 点生命；自然 1 记 2 次失败。
  **3 次成功 = 稳定**（不再掷，但仍昏迷，等治疗 / 长休）；**3 次失败 = 死亡**。
- **受到治疗**：恢复生命值并清空死亡豁免进度。**已濒死者再受伤**：+1 次失败
  （5 尺内暴击 +2 次）；单次伤害达到或超过生命上限则当场死亡。

### 击晕（留活口）

- 用**近战攻击**把某生物打到 0 生命时可改为留 **1 点生命 + 昏迷**：不算濒死、不掷死亡
  豁免，会**立即开始短休**，短休结束自己醒来。
- 提前醒来：恢复任意生命值，或有人用一个动作急救并成功通过 **DC 10 感知（医药）**。
- 远程攻击与法术做不到 —— 想留活口必须贴上去打。

### 稳定伤势

- 用**协助动作**稳定 5 尺内 0 生命生物：成功通过 **DC 10 感知（医药）**。
- 成功后仍是 0 血昏迷但不再掷死亡豁免；**未被治疗者 1d4 小时后恢复 1 点生命并恢复意识**。
- 稳定后再受伤：不再稳定，重新开始掷死亡豁免。

## 九、休息

- **短休**（≥ 1 小时）：
  - 可花费**生命骰**回血：每颗 = 掷 1 颗该职业生命骰 + 体质调整值，**每颗至少回 0 点**；
    一次可花多颗，不超剩余数量。
  - 恢复职业资源（口径见「规则口径」）：回气 / 动作如潮 / 功力**全部**恢复，狂暴 / 引导
    神力 / 荒野形态回 **1 次**，术法点 / 宿敌**不回**；契约法术位回满。
  - 0 血倒地者治疗后站起来时死亡豁免清零；**被击晕者醒来**；**伤势稳定者**推进 1 小时的
    恢复计时（1d4 小时走完就恢复 1 点生命并恢复意识）。
- **长休**（≥ 8 小时）：
  - 恢复全部生命值、清掉临时生命、**已用的职业资源全部恢复**（狂暴状态随之摘掉）。
  - **恢复已耗生命骰的一半（至少 1 颗）**（5 级共 5 颗、已耗 3 颗 → 恢复 2 颗，剩 1 颗）。
  - 恢复全部法术位；**力竭降 1 级**（不要求进食饮水；6 级力竭即死亡）。
  - 24 小时内只能受益一次。**人类**获得 1 个英雄激励。
  - **房规**：超过 24 小时没长休，过一次 **DC 10 体质豁免**，失败 +1 级力竭。
  - 中毒 / 疾病 / 诅咒是否解除由你判断。

## 十、法术规则

- 施法需满足语言、姿势、材料成分（若法术要求）。
- **法术位**：施法消耗，用完需长休恢复。**戏法**不消耗，可随意施展。
- **升环施法**：可用更高环位施展低环法术。伤害 / 治疗类按数据里的「每升一环 +NdM」自动
  加骰（三环火球术用五环位 = 2d6 追加）；「多 1 个目标」「多出一枚飞弹」这类非数值效果
  系统只提示，由你裁决。
- **准备法术**：2024 起**八个施法职业全部是准备制**，区别只在**何时能改、一次换几个**：
  牧师 / 德鲁伊 / 法师长休任意换；圣武士 / 游侠长休换一个；吟游诗人 / 术士 / 魔契师升级
  换一个。可准备数是**职业表里的固定值**（法师 1 级 4、20 级 25；牧师 4 / 22；圣武士
  2 / 15），**与属性无关**（2014 的「等级 + 调整值」作废）。法师另有**法术书**
  （1 级 6 条、每级 +2，20 级 44 条），准备时从书里挑；其余职业直接从职业法术表挑。
  名单由你用 `update_character` 的「准备」字段写入；施放名单外的法术只提示不拦截；
  卡上没记名单即视为未管理，不做校验。建卡挑的那批**就是当日准备**（法师挑的是法术书）。
- **法术攻击**：1d20 + 施法属性调整值 + 熟练加值，对抗目标 AC。
- **法术豁免 DC** = 8 + 熟练加值 + 施法属性调整值；目标掷 1d20 + 相关调整值对抗。
- **专注**：同时只能维持一个需专注的法术。
  - 受伤时掷**体质豁免**，DC = 10 或所受伤害的一半（取高，向下取整）；失败则法术终止。
  - 生命值降到 0、再次施展另一个专注法术、陷入**失能**类状态（震慑 / 麻痹 / 昏迷 / 石化 /
    失能）、主动放弃，都直接中断（不需豁免、不占动作）。

## 十一、豁免检定

豁免检定 = 1d20 + 属性调整值 + 熟练加值（若熟练），用于抵抗法术、陷阱、毒素、疾病等；
成功通常减半或无效，失败则承受完整效果。

## 十二、常见难度（DC）

非常简单 5 / 简单 10 / 中等 15 / 困难 20 / 非常困难 25 / 几乎不可能 30。

## 十三、移动与距离

- 网格地图，1 格 = 5 尺；速度通常 30 尺（6 格）。**困难地形**移动消耗加倍。
- 可拆分移动（移动 → 动作 → 再移动）；**撤离**时移动不引发借机攻击。
- **借机攻击**：敌人离开你的触及范围时，可花**反应**进行一次近战攻击。

## 十四、动作经济

- 每回合 1 动作 + 1 附赠动作（若能力允许）+ 1 反应（每轮一次，可在他人回合触发）
  + 移动力。反应示例：借机攻击、预备动作触发、部分法术。
- 系统按你调用的工具自动记账并在战斗块显示；这只是**提示**，用完了多回一句提醒但
  **不拦截** —— 额外攻击、借机攻击、裁定允许的额外行动都可照常叙述，最终裁决在你。

## 十五、状态

状态由 `update_character`（玩家）/ `update_enemy`（敌人）的 `conditions` 字段维护，
**自动参与结算**（攻击姿态、豁免、速度、专注都会按状态改算）；用 `query_data`
（table=condition）查完整效果。

- **目盲**：看不见，自己攻击检定有劣势，被攻击时有优势。
- **魅惑**：无法攻击魅惑者（法术 / 攻击都不行），魅惑者对其社交检定有优势。
- **耳聋**：依赖听觉的检定自动失败。
- **恐慌**：攻击检定与属性检定有劣势，无法主动靠近恐惧源。
- **擒抱**：速度归零（挣脱见运动 / 体操，或攻击者失能 / 倒地时自动解脱）。
- **失能**：无法进行动作、附赠动作与反应 —— **不能行动但仍可被攻击**。
- **隐形**：**对它**的攻击检定有劣势；**它**对看不见它的生物攻击有优势。黑暗、浓雾、
  被蒙眼也算「看不见」。猜错位置则攻击直接失手（由你按叙述裁定）；
  **出手就暴露**（躲藏中攻击，不论中没中，位置立刻暴露）。
- **麻痹**：无法行动与反应；**力量与敏捷豁免自动失败**；被攻击有优势；
  **5 尺内被近战命中即自动暴击**。
- **石化**：失去意识；力量与敏捷豁免自动失败；对所有伤害有抗性；被攻击有优势。
- **中毒**：攻击检定与属性检定有劣势（不影响豁免，**也不造成持续伤害**）。
- **倒地**：自己攻击检定有劣势；起身花一半移动力；**5 尺内近战打它有优势、远程有劣势**。
- **束缚**：速度归零，攻击检定有劣势，被攻击有优势，**敏捷豁免有劣势**。
- **震慑**：无法行动与反应；力量与敏捷豁免自动失败；被攻击有优势。
- **昏迷**：失去意识并视为倒地；无法行动与反应；力量与敏捷豁免自动失败；被攻击有优势；
  **5 尺内被近战命中即自动暴击**。
- **力竭**（1~6 级累加）：每级**所有 d20 检定（属性 / 豁免 / 攻击）−2**、**速度 −5 尺**；
  6 级死亡。每完成一次长休降 1 级（2014 旧表不采用）。
- **狂暴**：力量检定与力量豁免有优势；对钝击 / 穿刺 / 挥砍伤害有抗性（非魔法攻击同样挡）。
- **回避**：到你的**下个回合开始**前，打你的攻击检定有劣势、你的**敏捷豁免**有优势；
  失能或速度归零时立刻失效（系统 1 轮后自动摘）。
- **护盾**（护盾术）：AC +5，到施法者**下回合开始**自动结束。类似增益还有**守护之灵**
  （+2 AC，需专注）、**加速**（+2 AC 等），都由系统算进 AC。

**共同规则**：失能类状态（震慑 / 麻痹 / 昏迷 / 石化 / 失能）下不能行动但仍可被攻击 ——
打麻痹 / 昏迷的目标只要够近就是暴击；优势与劣势**不叠加、相遇抵消**；状态写入后攻击、
豁免、移动、施法专注都自动改算，文案会写清是哪条状态在起作用。

## 十六、暴击与伤害

- 攻击掷出自然 20 即暴击（暴击阈值类特性另算）；**暴击时伤害骰数量加倍，调整值不加倍**。
- **5 尺内**近战攻击命中**麻痹 / 昏迷**的目标按暴击结算（法术攻击同样适用，看距离不看武器）。
- 伤害类型 13 种：**强酸、钝击、寒冷、火焰、力场、闪电、穿刺、光耀、挥砍、雷鸣、毒素、
  暗蚀、心灵**；**钝击 / 穿刺 / 挥砍**是物理类型，「非魔法抗性」只挡这三类。
- **抗性**减半、**易伤**加倍、**免疫**归零；同类型的多个抗性 / 易伤**只算一次，不叠加**
  （暗蚀抗性 + 全伤害抗性 → 暗蚀仍只减半）。**抗性(非魔法)**只挡非魔法的物理攻击。
- 结算顺序（与引擎一致）：**先扣临时生命**，余下按**易伤 / 抗性**倍率结算，最后扣生命值；
  抗性与易伤同时存在互相抵消成全额。怪物 / 种族抗性写在数据表里，结算自动生效。

## 十七、社交互动

社交检定用**魅力**相关技能：游说、欺骗、威吓、表演对抗目标洞察或固定 DC；玩家描述直接
影响 DC 高低。不可能的事不掷骰，直接失败。

## 十八、探索与冒险

- 被动感知 = 10 + 感知调整值 + 熟练加值（若熟练）；搜索、察觉、调查需主动掷骰。
- 陷阱、秘密门、隐藏物品通常有固定 DC。

### 光照与遮蔽（PHB 2024「光线 / 遮蔽区域 / 特殊感官」）

- **明亮**：正常视物。**微光**：轻度遮蔽 —— 基于视觉的**察觉检定有劣势**，不影响攻击。
- **黑暗**：重度遮蔽 —— 尝试看穿时**等同目盲**：看不见目标的一方攻击有劣势，看不见它的
  一方被打时有优势（两边都看不见则抵消）。
- **特殊感官**：**黑暗视觉**把黑暗当微光、微光当明亮（照样吃轻度察觉劣势）；
  **盲视 / 震颤感知**在射程内完全不靠光，范围外照旧；**真实视觉**一律看穿。
- 开战用 `start_combat` 的 `light=明亮/微光/黑暗` 定光照（留空按日光推）；系统照它算攻击
  优势，并在【战斗】块写出「光照：…」，**叙述里的光线就该照这一行讲**。

## 十九、升级

- 上限 20 级，累计经验达到该级阈值即升级（阈值见 `core/dnd/progression.py`）。
- 升级**只改等级**：生命上限、熟练加值、法术位上限按等级自动重算；**当前生命值不变**
  （5e 规则），要回血靠治疗或休息。
- 生命上限每级「生命骰平均值 + 体质」，**每级至少 +1**；想按规则原意掷骰，用
  `update_character` 的「掷血」字段掷一次生命骰（记在 `hp_rolls`，`/跑团.看卡` 会显示）。
- **升级选择会话**：三件事 —— 3 级**选子职**、属性提升等级**加点**、施法者**这一级新得
  的法术**。答完写回角色卡；回「取消」整场跳过，之后用 `/跑团.改卡` 补。
  ⚠️ 会话写回**不动卡上已有的经验与准备名单**（不再被等级阈值冲掉）。
- **法术数量随等级涨**：戏法在个别等级 +1（法师 / 牧师 / 德鲁伊 4 级、10 级），准备数
  按职业表上调，法师法术书每级 +2。升级时算出差额（「法术书 +2」「可准备 +1」）并当场
  问玩家挑哪几个：候选只列卡上还没有的、高环在前，挑完**追加**进旧列表；法师挑的进法术书、
  准备名单不动，其余职业若已有名单会一并加进去（名单为空 = 未管理，不擅自开）。
  回「跳过」则留给你用 `update_character` 的「法术」/「准备」补。
- 法术位按职业类型与等级自动推导，无需记表。
- **属性提升（ASI）**等级：4 / 8 / 12 / 16（**战士**另有 6 / 14，**游荡者**另有 10）。
  每次「+2 一点」或「+1/+1 两点」，总加值 +2、单项不超 20。**19 级不是 ASI**，
  给的是**传奇恩惠**（别在那儿给 +2 属性）。
- 用 `update_character` 的 `exp` 可直接加减经验（支持 `+300`），达阈值自动升级；直接写
  `level` 时经验会被抬到该级下限。

### 兼职（多职业）

- 加职业用 `update_character` 的「兼职」字段：`兼职 法师`（+1 级）、`兼职 法师=3`（**设到**
  3 级，只补差额，重复发不会翻倍；降级不做，要降请改「等级」）。升级时想加在别的职业上，
  用 `level_up` 的 `into` 点名 —— 不点名就加在等级最高的职业（单职业卡等同「继续升本职」）。
- **先决**：新职业与**每个现有职业**的主要属性都要 ≥13（多属性职业满足其一即可，如战士认
  力量**或**敏捷）。不满足就整个拒绝，卡一点不动 —— 所以兼职卡以后属性掉了也加不了**新**
  职业（已有职业继续升级不受影响）。
- **总等级 vs 职业等级**：`level` 是总等级（经验、熟练加值、升级门槛按它）；职业特性、
  职业资源、法术数量、额外攻击都按**该职业自己的等级**查表。展示成「战士 3 / 法师 1」。
- **生命值**：只有角色的**第 1 级**拿满骰，之后每一级（哪怕进了新职业）按「该职业生命骰
  平均值 + 体质」算。
- **法术位**：全职施法职业等级**全加**、圣武士 / 游侠**减半向上取整**、带奥法骑士 /
  诡术师子职的战士 / 游荡者**三分之一向下取整**，查「兼职施法者」表；**魔契师不计入**，
  它的契约位是另一套（同环阶数量相加后显示）。短休只回契约那一档，普通位要长休。
- **施法属性按法术所属职业**算（4 级游侠 / 3 级法师：游侠法术用感知、法师法术用智力）；
  归属不清时才退回等级最高的施法职业。
- **子职按职业各存一个**：「子职」字段写「法师:防护师」。子职特性只在自己职业的等级上
  解锁 —— 法师 5 / 战士 2 选了勇士，勇士 3 级特性**不生效**。
- 兼职**不给豁免熟练**；技能熟练要在「技能」字段补（加职业时回执会点名还差几项）。
- 兼职卡的**升级选择会话不自动开**（三个问题各有职业归属，引擎不猜）：用 `/跑团.改卡`
  的子职 / 属性加点 / 法术补，或直接按玩家的话写进卡。

## 二十、遭遇校准（CR）

单只怪物的目标 CR = 小队**平均等级**；成对 / 成群时按下表下调，保证同场总威胁不超标：

| 怪物数量 | 目标 CR |
| --- | --- |
| 1 只 | 队伍平均等级 |
| 2 只 | 平均等级 − 1 |
| 3~4 只 | 平均等级 − 2 |
| 5~6 只 | 平均等级 − 3 |
| 7 只以上 | 平均等级 − 4 |

- **人数微调**：比四人多一人 +0.5 CR，少一人 −0.5 CR。
- `start_combat` 会自动把**低于**目标的怪物校准（重算生命 / AC / 伤害 / 熟练）并说明
  校准了什么；**高于**目标视为你安排的首领或精英，**不缩放**，只提示风险。
  缩放后的 key 形如 `goblin@cr3`，事后能还原成同一份数值。
- **人形 NPC 档位不参与 CR 校准**（数值按队伍等级现算，CR 记 0，经验另按档位表给）；
  想让 NPC 按 CR 走，就写怪物表里的模板（如 `卡尔:匪帮首领`）。
- 想知道某等级适合什么怪，查 `query_data` 的 monster 表（按 CR 升序）或
  `recommended_monsters`。

## 二十一、战斗结算（经验与战利品）

- **只有被打倒的敌人才算战果**：生命归零时记进战果清单。逃跑 / 被擒 / 投降
  （`update_enemy` 标记退场）**不结算**经验与战利品；被治疗救回来的敌人也会被撤出战果。
- 战斗结束（`end_combat` 或敌人全部退场的自动分支）时自动结算：
  1. **经验**：按每只怪的 CR 换算（人形 NPC 按档位经验表），总额**全队共享**、除以参战
     人数平分写入角色卡；阵亡的角色不参与分配，零头记进存档「经验零头」。
  2. **战利品**：**逐只**按档次掷金币与物品后合并，记进存档进度；怎么分由你裁决
     （装备可用 `update_character` 的 `equipment` 收进装备栏）。
  3. **升级**：分完经验自动检查阈值，达标立即升级并输出生命上限 / 熟练 / 法术位的变化。
- 结算文本同时出现在你的叙述与玩家的「🎲 判定」里，玩家能看到拿了多少 XP。

## 二十二、物品规则

- **稀有度**：普通 / 非普通 / 稀有 / 非常稀有 / 传说。它只说明「这东西有多难得」，
  不直接决定强度。
- **调谐**：多数魔法物品需要**调谐**才发挥效果。没调谐时它仍占着装备栏 —— 这是有意的
  代价：拿了三件传说级装备却只调谐一件，可据此给出剧情压力。
- **消耗**：药水与卷轴用完即失效；`消耗 药水一瓶` 这类描述写在物品表里，照着扣。
- **附魔**：武器 / 护甲的 +1 / +2 / +3 加在攻击与伤害（或 AC）上，是**加法**不是替换。
- **药水与法术位**：消耗型物品不占法术位；卷轴上的法术仍要由能施放该环位的角色使用。
- 查物品用 `query_data` 的 **item** 表（「物品」「魔法物品」「道具」都认）；捡到东西用
  `update_character` 的 `equipment` 收进装备栏 —— 系统会把「精灵靴」规范成「精灵之靴」，
  认不出的杂物照原样收下。

## 二十三、主持原则

- 规则服务于游戏，不用于限制游戏。玩家描述合理且有趣时给予优势或降低 DC；不合理时
  给予劣势或提高 DC；不可能的行动直接失败，不掷骰；掷骰只在结果不确定且有意义时进行。
- 英雄之举、符合角色的扮演、让局面更有趣的行动可以**授予英雄激励**
  （`update_character` 的 `inspiration` 字段；至多 1 个，消耗与否由玩家自己说）。
- 主持保持公平、一致、连贯。**你的裁决是最终裁决。**
