# DND 跑团规则（Agent 专用）

## 规则口径（2024，先读这里）

**本局规则以《玩家手册（2024）》为准**（2026-10-24 裁定）：

- **规则文本**：PHB 2024。凡 2014 与 2024 说法不一，一律以 2024 为准。已按此改过的条目：
  **旅行步调**（快速=感知+隐匿劣势、普通=隐匿劣势、慢速=感知优势）、
  **力竭**（每级所有 d20 检定 -2、速度 -5 尺、6 级死亡、长休减 1 级不要求进食）、
  **突袭**（遭袭者先攻检定劣势，不是首回合禁言）、
  **属性加值**（建卡时只来自背景的三项属性，+2/+1 或各 +1；**种族不加属性**，
  旧书种族加值一律无视 —— 见第二章审计 A1）。
- **怪物数据**：2025 图鉴（5etools 中文包，xmm 为主，mm / dosi / lmop 补充）。
  兽人等 2025 删掉的条目从 2014 图鉴补录（出处标 MM）；怪物数值以数据卡为准。
- **PHB 2024 没有明文时**：沿用两版通用的旧规则（同调、法术位表、武器词条、币制等
  2014/2024 相同的条目），或按本局房规处理——房规在正文里标注「房规」。
- **本局房规（只有这两条，别处再看到「按 5e」的都是真规则）**：
  ① **挨饿计时**沿用 2014 的「3 + 体质调整值」天（2024 实为「吃不足半量过 DC10」）；
  ② **24 小时没长休**：过一次 DC 10 体质豁免，失败 +1 级力竭（PHB 两版都没有这条）。
  「中毒每回合扣 1 血」也是自定的，**已不采用**（2026-10-25 移除）。
- **2014 的旧说法只在两种地方出现**：标注「已不采用 / 已不适用」的对照说明，
  以及数据出处的 provenance 注记。看到别的 2014 字样，按 bug 报。
- **已知未对齐项**（不影响序章 / 第一章核心循环，排期另议）：
  2024 新增的武器「精通」特性未实现；冒险用品表数据转录自 2014 快速参考；
  法术表暂只到 3 环；挨饿计时为房规（沿用 2014「3 + 体质调整值」口径，
  2024 实为「吃不足半量过 DC10 体质豁免」）。

## 一、核心判定

- 所有有难度的行动均需掷骰判定。
- 默认掷 **1d20**，加相关调整值，与目标难度（DC）比较。
- **结果 ≥ DC**：成功。
- **结果 < DC**：失败。
- **自然 20 / 自然 1 的特殊规则只作用于攻击检定与死亡豁免**：
  攻击掷出自然 20 必中且暴击，自然 1 必失；死亡豁免自然 20 回 1 血、自然 1 计两次失败。
  **属性检定与豁免没有大成功 / 大失败**——自然 20 只是很好的结果（20 + 调整值 vs DC），自然 1 只是很糟的结果（1 + 调整值 vs DC），都不自动成功或失败。
  （2014 有「天然 20 一律大成功」的旧说法，已不采用。）

## 二、属性与调整值

- 六大属性：**力量、敏捷、体质、智力、感知、魅力**。
- 属性值范围通常为 1–20。
- 调整值 =（属性值 − 10）÷ 2，向下取整。
- 属性值每提升 2 点，调整值 +1。
- **属性提升只来自背景**（PHB 2024）：背景给三项属性，建卡时选「一项 +2、另一项 +1」
  或「三项各 +1」（合计 +3，单项不超过 20）。**种族不提供属性加值** —— 旧书的种族加值
  一律无视；玩家表里种族只有速度、体型、特性与语言。

## 三、常用检定

- **力量**：攀爬、推拉、破坏、负重。
- **敏捷**：潜行、躲闪、开锁、先攻。
- **体质**：抗毒、抗病、耐力、维持专注。
- **智力**：回忆知识、分析、调查、推理。
- **感知**：察觉、洞察、追踪、直觉。
- **魅力**：说服、欺骗、威吓、表演。

## 四、技能检定

- 技能检定 = 1d20 + 属性调整值 + 熟练加值（若熟练）。
- **熟练加值**由等级决定：
  - 1–4 级：+2
  - 5–8 级：+3
  - 9–12 级：+4
  - 13–16 级：+5
  - 17–20 级：+6
- 未熟练则不加熟练加值。

### 卡上的「1 级特性选择」怎么算

2024 的 1 级特性里有 6 处要玩家在建卡时挑，选完记在角色卡上。**哪些系统已经算好了**：

- **专精**（游荡者，`expertise`）：这些技能的熟练加值**已经翻倍**并算进技能加值，
  查卡时不要重复加。
- **战斗风格**（战士，`feature_choices.fighting_style`）：
  **防御**（着装护甲时 AC +1）与**箭术**（远程攻击 +2）已经进结算；
  其余（对决 / 巨武器 / 双武器 / 投掷 / 徒手 / 盲斗 / 拦截 / 守护）只记在卡上，按描述由你裁定。
- **圣职 / 原初职能**（`divine_order` / `primal_order`）：选「守护者」给的额外护甲 / 武器受训
  已经并进卡的受训列表；「施法者 / 术士」多出来的那一个戏法**没有**自动加，需要时由你补给玩家。
- **武器精通**（`weapon_masteries`）：卡上只记录选了哪几件武器，**精通词条的效果不结算**，
  由你按装备表的「武器精通」列裁定。

## 五、优势与劣势

- **优势**：掷 2d20，取较高结果。
- **劣势**：掷 2d20，取较低结果。
- **优势与劣势同时存在**：互相抵消，正常掷 1d20。
- 多次优势或多次劣势不叠加，只取一次。
- 有优势/劣势时，能让你「重骰」的效果**只重掷其中一颗**（由玩家选哪颗），不是两颗都重。

### 英雄激励

- **一次只有一个**：手上有激励时再获得，不能叠加（2024 规则：可转赠给没有激励的队友）。
- **怎么用**：掷完任何骰子后消耗它重掷一次，**必须采用新结果**（可能更差，不能挑好的留）。
- **什么时候消耗由玩家决定**：只有在玩家的行动里写明「重骰」或「重投」时才消耗并重掷；
  没写就不动它（写了却没掷骰，也不消耗）。
- **人类每日一个**：人类角色每次完成长休后获得 1 个英雄激励；其他来源由你（DM）授予
  ——做出英雄之举、符合角色的扮演、让局面更有趣，都值得给。
- **吟游诗人的「吟游诗人激励」不是这个**：它给的是「一次 d20 检定额外加一枚 1d6 起
  的骰子」（5 级 d8 / 10 级 d10 / 15 级 d12，次数 = 魅力调整值），本局没有实现
  （状态表里也没有「激励」这条——曾经有一条写错的，已删）。
  遇到吟游诗人激励时由你按「+1d6 到那次检定」裁定，用 `roll_dice` 掷。

## 六、战斗流程

1. **确定先攻**：每人掷 1d20 + 敏捷调整值，从高到低排序。
2. **回合行动**：每回合可进行：
   - 1 个**动作**
   - 1 个**附赠动作**（若可用）
   - 1 次**移动**（不超过速度）
   - 1 次**自由交互**
3. **动作常用选项**（PHB 2024 动作表，名称以 2024 为准）：
   **攻击**（武器 / 徒手，可含擒抱、推撞这类特殊近战攻击）、
   **疾走**（本回合额外获得等于速度的移动力）、
   **撤离**（本回合的移动不引发借机攻击）、
   **回避**（到下个回合开始，打你有劣势、你的敏捷豁免有优势；失能或速度归零时失效）＝旧称「闪避 / 躲避」、
   **协助**（帮别人那次检定有优势，或做急救）、
   **躲藏**（敏捷（隐匿）检定）＝旧称「隐藏」、
   **影响**（魅力（欺瞒 / 威吓 / 表演 / 游说）或感知（驯兽）检定，改变一个生物的态度）、
   **魔法**（施展法术、使用魔法物品或魔法特性）、
   **预备**（定好触发条件，用反应执行那个动作）＝旧称「准备」、
   **搜索**（感知（洞悉 / 医药 / 察觉 / 求生）检定）、
   **研究**（智力（奥秘 / 历史 / 调查 / 自然 / 宗教）检定）、
   **操作**（用一个非魔法物件）＝旧称「使用物品」。
   战斗中回避 / 躲藏 / 预备 / 借机攻击 / 上下坐骑由 `tactic` 工具结算（见它的说明）；
   战斗外的躲藏 / 骑乘用 `check` 掷骰后叙述；影响 / 研究 / 搜索 / 操作照常用 `check`。
4. **攻击判定**：1d20 + 属性调整值 + 熟练加值（若熟练），对抗目标 AC。
5. **命中后掷伤害**：按武器或法术描述掷骰。
6. **回合结束**。

## 七、护甲等级（AC）

- AC = 基础护甲值 + 敏捷调整值（受护甲类型限制）+ 盾牌加值 + 其他加值。
- 攻击结果 ≥ AC 则命中。
- 攻击结果 < AC 则未命中。
- **掩护**（PHB 2024）：半掩护 = AC 与**敏捷豁免** +2；四分之三掩护 = AC 与**敏捷豁免** +5；
  全掩护 = 不能被直接选作目标。棋盘上有掩体格时系统自动结算（含敏捷豁免，吐息 / 爆炸都吃得到）。

## 八、生命值与死亡

- 初始生命值 = 生命骰最大值 + 体质调整值。
- 升级时生命值增加 = 生命骰掷骰结果（或取平均值）+ 体质调整值。
- 生命值降至 **0** 时：
  - 立即**昏迷倒地**：无法行动，5 尺内被近战命中即暴击，同时失去当前专注。
  - 进入**濒死**状态，每回合开始掷 **死亡豁免**（1d20）：
    - ≥ 10：成功 1 次。
    - < 10：失败 1 次。
    - 自然 20：恢复 1 点生命值。
    - 自然 1：失败 2 次。
    - 累计 **3 次成功**：稳定，不再掷死亡豁免（但仍昏迷，要等治疗 / 长休）。
  - 累计 **3 次失败**：死亡。
- 受到治疗：恢复生命值并移除濒死状态（死亡豁免进度清零）。
- 已濒死者再受伤害：直接增加 1 次死亡豁免失败（攻击距离 5 尺内的暴击造成 2 次）。

### 击晕（留活口）

- 用**近战攻击**把某个生物打到 0 生命值时，可以改为让它**留 1 点生命并陷入昏迷**。
- 它不算濒死、不掷死亡豁免；会**立即开始短休**，短休结束时自己醒来。
- 提前醒来的两种情况：恢复任意生命值（治疗即可），
  或有人用一个动作急救并成功通过 **DC 10 感知（医药）**检定。
- 远程攻击与法术做不到——想留活口必须贴上去打。

### 稳定伤势

- 用**协助动作**尝试稳定 5 尺内 0 生命生物的伤势：成功通过 **DC 10 感知（医药）**检定。
- 成功后仍是 0 血昏迷，但不再掷死亡豁免；
  **未被治疗者 1d4 小时后恢复 1 点生命并恢复意识**。
- 稳定后再受伤害：不再稳定，重新开始掷死亡豁免。

## 九、休息

- **短休**：至少 1 小时。
  - 可花费**生命骰**恢复生命值：每颗 = 掷 1 颗该职业的生命骰 + 体质调整值，**每颗至少回 0 点**。
  - 一次短休可以花多颗，总共不超过还剩的生命骰数量。
  - 恢复部分职业资源（契约法术位回满等）。
  - 0 血倒地者治疗后站起来时，死亡豁免进度清零。
  - **被击晕者醒来**（见「八、击晕」）；**伤势稳定者**推进 1 小时的恢复计时
    （稳定时掷的 1d4 小时走完了就恢复 1 点生命并恢复意识）。
- **长休**：至少 8 小时。
  - 恢复全部生命值，清掉临时生命。
  - **恢复已耗生命骰的一半（至少 1 颗）**：比如 5 级角色共 5 颗、已耗 3 颗，长休后恢复 2 颗（5 ÷ 2 向下取整），剩 1 颗已耗。
  - 恢复全部法术位。
  - **力竭降低 1 级**（2024 起不要求进食饮水；6 级力竭即死亡，救不回来）。
  - 24 小时内只能受益于一次长休。
  - **房规**：超过 24 小时没长休时，系统会让角色过一次 **DC 10 体质豁免**，
    失败 +1 级力竭（PHB 两版都没有这条，是本局为了让「连续赶路不睡觉」有代价加的）。
  - **人类**：获得 1 个英雄激励（至多持有 1 个，见「五、优势与劣势」里的英雄激励）。
  - 中毒 / 疾病 / 诅咒是否解除由 DM 判断。

## 十、法术规则

- 施法需满足：语言、姿势、材料成分（若法术要求）。
- **法术位**：施法消耗法术位，用完需长休恢复。
- **升环施法**：可以用更高环位的法术位施展低环法术（例如三环的火球术用五环位放）。
  伤害 / 治疗类法术按数据里的「每升一环 +NdM」自动加骰（二环雷鸣波是 3d8）；
  写的是「多 1 个目标」「多出一枚飞弹」这类非数值效果时，系统按原文提示，由你裁决。
- **戏法**：不消耗法术位，可随意施展。
- **法术攻击**：1d20 + 施法属性调整值 + 熟练加值，对抗目标 AC。
- **法术豁免**：目标掷 1d20 + 相关调整值，对抗施法者豁免 DC。
- **豁免 DC** = 8 + 熟练加值 + 施法属性调整值。
- **专注**：同时只能维持一个需专注的法术。
  - 受到伤害时需掷**体质豁免**，DC = 10 或所受伤害的一半（取较高者，向下取整）。
  - 豁免失败则法术终止；生命值降至 0 也直接终止（不掷豁免）。
  - **再次施展另一个专注法术**：旧法术立即被顶替而中断，不需要豁免。
  - 陷入**失能**类状态（震慑 / 麻痹 / 昏迷 / 石化 / 失能）同样直接中断专注。
  - 主动放弃专注（如「我不维持了」）也立即终止，不占动作。
- 生命值降至 **0** 时立即昏迷倒地（见「生命值与死亡」），此时也会失去专注。

## 十一、豁免检定

- 豁免检定 = 1d20 + 属性调整值 + 熟练加值（若熟练）。
- 用于抵抗法术、陷阱、毒素、疾病等效果。
- 成功通常减半或无效，失败则承受完整效果。

## 十二、常见难度（DC）

- 非常简单：5
- 简单：10
- 中等：15
- 困难：20
- 非常困难：25
- 几乎不可能：30

## 十三、移动与距离

- 默认使用网格地图，1 格 = 5 尺。
- 速度通常为 30 尺（6 格）。
- 困难地形：移动消耗加倍。
- 可拆分移动：移动、动作、再移动。
- 撤离：移动时不引发借机攻击。
- 借机攻击：敌人离开你的触及范围时，你可消耗反应进行一次近战攻击。

## 十四、动作经济

- 每回合拥有：
  - 1 个动作
  - 1 个附赠动作（若能力允许）
  - 1 个反应（每轮一次，可在他人回合触发）
  - 移动力
- 反应示例：借机攻击、准备动作触发、部分法术。

## 十五、状态

状态由 `update_character`（玩家）/ `update_enemy`（敌人）的 `conditions` 字段维护，**自动参与结算**：攻击姿态、豁免、移动速度、专注都会按状态改算，不需要 DM 手算。可用 `query_data`（table=condition）查任意状态的完整效果。

- **目盲**：看不见，自己的攻击检定有劣势，被攻击时有优势。
- **魅惑**：无法攻击魅惑者（法术 / 攻击都不行），魅惑者对其社交检定有优势。
- **耳聋**：听不见，依赖听觉的检定自动失败。
- **恐慌**：攻击检定与属性检定有劣势，无法主动靠近恐惧源。
- **擒抱**：速度归零（挣脱见运动 / 体操检定，或攻击者失能 / 倒地时自动解脱）。
- **失能**：无法进行动作、附赠动作与反应——**不能行动但仍可被攻击**。
- **隐形**（PHB 2024「不可见的攻击者与目标」）：**对它**的攻击检定有劣势；
  **它**对看不见它的生物攻击有优势。看不见不一定是隐形——黑暗里、浓雾里、
  被蒙住眼都算。
  - 看不见的一方若猜错位置，攻击直接失手（由 DM 按叙述裁定）。
  - **出手就暴露**：躲藏中发动攻击的，不论中没中，位置立刻暴露（隐形状态随之失效）。
- **麻痹**：无法行动与反应；**力量与敏捷豁免自动失败**；被攻击有优势；**5 尺内被近战攻击命中即自动暴击**。
- **石化**：变成石头，失去意识；力量与敏捷豁免自动失败；对所有伤害有抗性；被攻击有优势。
- **中毒**：攻击检定与属性检定有劣势（不影响豁免，**也不造成持续伤害**）。
- **倒地**：自己的攻击检定有劣势；起身要花一半移动力；**5 尺内的近战打它有优势、远程打它有劣势**。
- **束缚**：速度归零，攻击检定有劣势，被攻击有优势，**敏捷豁免有劣势**。
- **震慑**：无法行动与反应；力量与敏捷豁免自动失败；被攻击有优势。
- **昏迷**：失去意识并视为倒地；无法行动与反应；力量与敏捷豁免自动失败；被攻击有优势；**5 尺内被近战攻击命中即自动暴击**。
- **力竭**（2024 口径，1~6 级累加）：每级**所有 d20 检定（属性 / 豁免 / 攻击）-2**、
  **速度 -5 尺**；6 级死亡。
  - 每完成一次长休降 1 级（不再要求同时进食饮水），到 0 级状态结束。
  - 2014 旧表（检定劣势→速度减半→攻击与豁免劣势→生命上限减半→速度归零→死亡）不采用。
- **狂暴**（野蛮人）：力量检定与力量豁免有优势；对钝击 / 穿刺 / 挥砍伤害有抗性（非魔法攻击同样挡）。
- **回避**（回避动作）：到你的**下个回合开始**前，打你的攻击检定有劣势、你的
  **敏捷豁免**有优势；你失能或速度归零时立刻失效（系统 1 轮后自动摘）。
- **护盾**（护盾术，反应）：AC +5，到施法者**下回合开始**时自动结束（1 轮）。
  类似的增益还有**守护之灵**（+2 AC，需专注）、**加速**（+2 AC 等）——都由系统直接算进 AC。

**共同规则**：
- 失能类状态（震慑 / 麻痹 / 昏迷 / 石化 / 失能）下角色**不能行动**，但仍然可以被攻击——打麻痹 / 昏迷的目标只要够近就是暴击。
- 优势与劣势**不叠加、相遇抵消**：状态给的劣势和场景给的优势撞上时按普通结算。
- 状态写在角色卡 / 战斗态上后，攻击、豁免、移动、施法专注都会自动按上表改算；文案里会写清是哪条状态在起作用。

## 十六、暴击与伤害

- 攻击掷出自然 20：暴击。
- 暴击时：伤害骰数量加倍，调整值不加倍。
- **5 尺内**近战攻击命中**麻痹 / 昏迷**的目标，按暴击结算（法术攻击同样适用，看的是距离不是武器）。
- 伤害类型共 13 种：**强酸、钝击、寒冷、火焰、力场、闪电、穿刺、光耀、挥砍、雷鸣、毒素、暗蚀、心灵**。其中**钝击 / 穿刺 / 挥砍**是物理类型，「非魔法抗性」只挡这三类。
- **抗性**：受到该类型伤害**减半**（每次受击结算一次）。
- **易伤**：受到该类型伤害**加倍**。
- **免疫**：不受该类型伤害。
- 同类型的多个抗性 / 易伤**只算一次，不叠加**（暗蚀抗性 + 全伤害抗性 → 暗蚀仍只减半）。
- **抗性(非魔法)**：只挡非魔法的物理攻击，魔法武器 / 法术伤害照常全额结算。
- 伤害结算顺序（与引擎一致）：**先扣临时生命吸收**，余下的伤害再按**易伤 / 抗性**倍率结算，最后才扣生命值；抗性与易伤同时存在时互相抵消成全额。
- 怪物 / 种族的抗性写在数据表里（`query_data` 的 monster / race 表会列出），结算时自动生效，DM 不需要手算。

## 十七、社交互动

- 社交检定通常使用**魅力**相关技能。
- 说服、欺骗、威吓、表演对抗目标洞察或固定 DC。
- 玩家角色描述直接影响 DC 高低。
- 不可能的事不掷骰，直接失败。

## 十八、探索与冒险

- 被动感知 = 10 + 感知调整值 + 熟练加值（若熟练）。
- 搜索、察觉、调查需主动掷骰。
- 陷阱、秘密门、隐藏物品通常有固定 DC。
### 光照与遮蔽（PHB 2024「光线 / 遮蔽区域 / 特殊感官」）

- **明亮**：正常视物。
- **微光**：轻度遮蔽——**基于视觉的感知（察觉）检定有劣势**；不影响攻击。
- **黑暗**：重度遮蔽——尝试看穿时**等同目盲**：看不见目标的一方攻击检定有劣势，
  看不见它的一方被打时有优势（两边都看不见则相遇抵消）。
- **特殊感官**：
  - **黑暗视觉**：黑暗当微光、微光当明亮（照样吃「轻度的察觉劣势」）。
  - **盲视 / 震颤感知**：射程内完全不靠光，范围外照旧。
  - **真实视觉**：一律看穿，不受光照与遮蔽影响。
- 开战用 `start_combat` 的 `light=明亮/微光/黑暗` 定下战场光照；留空按日光推
  （有日光 = 明亮，没日光 = 黑暗）。系统会照它算攻击优势，并在【战斗】块里
  写出「光照：…」，**叙述里的光线就该照这一行讲**。

## 十九、升级

- 等级上限为 20 级；升级需要累计经验值达到该级阈值（阈值表见 `core/dnd/progression.py` 的 `LEVEL_XP_THRESHOLDS`）。
- 升级**只改等级**：生命上限、熟练加值、法术位上限都按等级自动重算；当前生命值不变（5e 规则），要回血得靠治疗或休息。
- 每次升级生命上限增加「1d10 生命骰的平均值 + 体质调整值」（按平均值而非最大值结算）。
- 熟练加值每 4 级 +1（Lv1-4 +2、Lv5-8 +3、Lv9-12 +4、Lv13-16 +5、Lv17-20 +6）。
- 法术位按职业类型与等级自动推导，无需手动记表。
- **属性提升（ASI）等级**：4 / 8 / 12 / 16 级（**战士**另有 6 / 14，**游荡者**另有 10）。
  每次升到这些等级时由 DM 主持分配（+2 一点，或 +1/+1 两点，或用一项专长），
  并用 `update_character` 的 features 字段落盘。
- **19 级不是属性提升**：19 级给一项**传奇恩惠**（Epic Boon，见第五章）。
  2024 没有「19 级 ASI」——别在那儿给 +2 属性。
- 用 `update_character` 的 `exp` 字段可直接加减经验，达阈值会自动结算升级；直接写 `level` 时经验会被抬到该级下限。

## 二十、遭遇校准（CR）

- **单只普通怪物**：目标 CR = 小队**平均等级**（`party_level` 取全体角色卡等级的平均值）。
- **成对 / 成群**：目标 CR 随数量下调，保证同场遭遇总威胁不超标：

  | 怪物数量 | 目标 CR |
  | --- | --- |
  | 1 只 | 队伍平均等级 |
  | 2 只 | 队伍平均等级 − 1 |
  | 3~4 只 | 队伍平均等级 − 2 |
  | 5~6 只 | 队伍平均等级 − 3 |
  | 7 只以上 | 队伍平均等级 − 4 |

- **人数微调**：比四人多一人 +0.5 CR，少一人 −0.5 CR。
- 开战时 `start_combat` 会自动按此规则校准**低于**目标的怪物（重算生命 / AC / 伤害 / 熟练），并在返回文本里告诉 DM 校准了什么。
- 怪物 CR **高于**目标时视为 DM 有意安排的首领或精英，**不缩放**，只在开战提示里提示风险。
- 缩放后的怪物落盘 key 形如 `goblin@cr3`，事后能原样还原成同一份数值。
- **人形 NPC 档位不参与 CR 校准**：它们的数值本就按队伍等级现算，不是图鉴条目（CR 记 0），经验另按档位表给。想让某个 NPC 按 CR 走，就写怪物表里的模板（如 `卡尔:匪帮首领`）。
- 想知道某个等级适合什么怪，可查 `query_data` 的 monster 表（按 CR 升序列出），或看 `recommended_monsters` 的推荐。

## 二十一、战斗结算（经验与战利品）

- **只有被打倒的敌人才算战果**：敌人**生命归零**时记进战斗状态的战果清单。逃跑 / 被擒 / 投降（DM 用 `update_enemy` 标记退场）**不结算**经验与战利品；被治疗救回来的敌人也会被撤出战果。
- 战斗结束（`end_combat`，或敌人全部退场的自动分支）时自动结算：
  1. **经验**：每只被击败怪物的经验按其 CR 换算（人形 NPC 档位不是图鉴条目，按档位经验表给），总额**由全队共享**，除以参战人数平分给每位玩家并写入角色卡；阵亡的角色不参与分配，除不尽的零头记进存档「经验零头」。
  2. **战利品**：**逐只**按档次掷金币与物品后合并，结果记进存档进度的「战利品」字段；具体怎么分由 DM 裁决（装备类物品可用 `update_character` 的 `equipment` 字段收进装备栏）。
  3. **升级**：分完经验后自动检查阈值，达标的立即升级并输出生命上限 / 熟练加值 / 法术位的变化。
- 结算文本会同时出现在 DM 的叙述与玩家的「🎲 判定」里，玩家能看到自己拿了多少 XP、升没升级。
- DM 手动加经验用 `update_character` 的 `exp` 字段（支持 `+300` 这样的增量写法）。

## 二十二、物品规则

- **稀有度**：普通 / 非常稀有 / 稀有 / 非常稀有 / 传说。稀有度只说明「这东西有多难得」，不直接决定强度。
- **调谐**（attunement）：多数魔法物品需要**调谐**才能发挥效果。没调谐时它仍然占着装备栏——这是有意的代价：拿了三件传说级装备却只调谐一件，DM 可以据此给出剧情压力。
- **消耗**：药水与卷轴用完即失效；`消耗 药水一瓶` 这类描述写在物品表里，DM 照着扣。
- **附魔**：武器 / 护甲的 +1 / +2 / +3 加在攻击与伤害（或 AC）上。附魔值是**加法**，不是替换。
- **药水与法术位**：消耗型物品不占法术位；卷轴上写的法术仍要由能施放该环位的角色使用。
- 想知道某个物品是什么、能做什么，查 `query_data` 的 **item** 表（中文表名「物品」「魔法物品」「道具」都认）。
- 捡到东西用 `update_character` 的 `equipment` 字段收进装备栏——系统会把「精灵靴」规范成「精灵之靴」，认不出的杂物照原样收下（不会凭空消失）。

## 二十三、主持原则

- 规则用于服务游戏，不用于限制游戏。
- 玩家描述合理且有趣时，可给予优势或降低 DC。
- 做出英雄之举、符合角色的扮演、或让局面更有趣的行动，可以**授予英雄激励**
  （`update_character` 的 `inspiration` 字段；至多 1 个，消耗与否由玩家自己说——见第五节）。
- 玩家描述不合理时，可给予劣势或提高 DC。
- 不可能的行动直接判定失败，不掷骰。
- 掷骰只在结果不确定且有意义时进行。
- 主持应保持公平、一致、连贯。
- 主持裁决为最终裁决。
